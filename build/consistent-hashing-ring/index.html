Consistent Hashing Ring with Virtual Nodes

Maps keys to nodes so that adding or removing a node moves only about 1/N of the keys, not nearly all of them.

const ring = new HashRing({ vnodesPerWeight: 128 });
ring.addNode('A').addNode('B').addNode('C', { weight: 2 });
ring.getNode('user:42');        // 'C'
ring.getNodes('user:42', 3);    // ['C', 'A', 'B'], a replica preference list of distinct nodes
ring.ownership();               // { A: 0.25.., B: 0.24.., C: 0.51.. }, exact share of the hash space

The problem and where it shows up

With node = hash(key) % N, changing N from 4 to 5 remaps about 1 - 1/5 = 80% of keys (the demo measures

79.7%). For a cache fleet that is a mass cold-miss event. For a datastore it is a mass data migration.

Consistent hashing puts both keys and nodes on a circle, and a key belongs to the next node clockwise.

A membership change only affects the arcs next to the changed node. It's used in:

  • Amazon Dynamo / DynamoDB-lineage stores and Riak: partitioning and replica preference lists.
  • Apache Cassandra: token ring. Each node owns num_tokens vnodes (the default dropped from 256 to 16
    • in 4.0, with a token-allocation algorithm to keep balance).
  • Memcached clients (libketama, spymemcached): client-side key-to-server selection.
  • Load balancers: Envoy RING_HASH and MAGLEV, NGINX hash ... consistent, HAProxy hash-type consistent,
    • for session affinity and cache locality.
  • Discord, Akamai and others: routing users or objects to shards and cache servers.

Design

0 / 2^32
         A#7 .   . B#2
     C#1 .           . A#3        key k: h = md5(k)[0..4] as uint32
        .      ring     .          owner = first vnode with point >= h (wrap to index 0)
     B#9 .           . C#4
          C#0 .   . A#1
  • Hash space: uint32. The default hash is the first 4 bytes of MD5, as libketama does. Any (string) => uint32 can be injected; the tests use one that places points at chosen positions.
  • Virtual nodes: node X of weight w gets round(vnodesPerWeight * w) points (at least 1), at hash("X#0") ... hash("X#k-1").
    • Many small arcs per node average out the randomness of arc lengths.
  • Storage: two parallel sorted arrays, points[] and owners[]. Lookup is a lower-bound binary search,
    • and a hash past the last point wraps to index 0. A point exactly equal to the key hash owns the key.
  • Collisions: if two vnodes hash to the same point, the node with the smaller id wins. Ties are
    • broken the same way everywhere, so every process builds a byte-identical ring (tested).
  • Preference list (getNodes(key, n)): walk clockwise from the key's position and skip vnodes whose
    • physical node was already chosen. This returns min(n, size) distinct nodes, which is the Dynamo "skip positions to ensure distinct physical nodes" rule.
  • Ownership: the arc (points[i-1], points[i]] belongs to owners[i], and index 0 also owns the wrap
    • arc. ownership() sums the arcs exactly, so it doesn't need sampling.
  • Movement stats: assignments(keys) snapshots key→node. movementStats(before, after) returns
    • the moved count, the fraction, and the from->to flow matrix.

Invariants (all tested)

  1. Adding node X: every key that moves, moves to X.
  2. Removing node X: every key that moves, moves from X. The number moved equals X's key count.
  3. Reweighting X only moves keys to or from X, because X's vnode set grows or shrinks as a prefix X#0..k.
  4. Preference lists contain distinct nodes, and element 0 is getNode(key).
  5. Removing a replica keeps the other replicas in the same relative order. Only the tail changes.
  6. Ownership shares sum to 1. Binary search agrees with a linear scan.

Complexity

OperationTimeSpace
getNodeO(log V)
getNodes(key, n)O(log V + steps). Steps are coupon-collector-like, ≈ N·(H_N − H_{N−n}), which is a handful for small n. Worst case O(V)O(n)
addNode / removeNode / setWeightO(V log V) full rebuildO(V)
ownershipO(V)O(N)
V = total vnodes, N = physical nodes. The rebuild is deliberately simple. Membership changes are rare

compared with lookups, and an incremental sorted merge would be O(V).

Failure modes and trade-offs

  • Too few vnodes: hot nodes get 2x their share. Too many: memory, rebuild time, and (in Cassandra)
    • repair and streaming overhead per token range. That is why Cassandra reduced its default.
  • Hot keys are not fixed by hashing: a single viral key still lands on one node. Mitigate with key
    • salting or splitting, replica reads, or a local cache in front.
  • Membership disagreement: if clients hold different rings (for example, one hasn't seen a node leave),
    • the same key routes to different nodes. Real systems spread ring state by gossip or a coordination service, and tolerate a convergence window (hinted handoff, read repair).
  • Cascading failure: when a node dies, its whole load moves to its clockwise successors. With vnodes it
    • is spread over many successors, which is one of the main reasons for vnodes.
  • Replicas in the same failure domain: distinct nodes aren't distinct racks/AZs. Production preference
    • lists also skip nodes in an already-used rack (Cassandra's NetworkTopologyStrategy).
  • Weights are approximate: shares converge to the weight ratio only as vnodes grow (the demo's 2x node gets 52.2%, not 50%).

How production systems do it

  • libketama (memcached): each server gets about 160 points weighted by memory. Each MD5 digest yields
    • 4 32-bit points, so it runs 40 digests per server.
  • Cassandra: Murmur3Partitioner with a signed 64-bit token space. Since 4.0, num_tokens: 16 plus
    • allocate_tokens_for_local_replication_factor places tokens to minimize imbalance instead of choosing them at random.
  • Dynamo (2007 paper): evolved from random tokens per node (strategy 1) to Q equal-sized fixed partitions
    • with tokens assigned to nodes (strategy 3), which decouples partitioning from placement and makes bootstrap and recovery simpler. Preference lists skip positions so replicas land on distinct physical nodes.
  • Envoy: RING_HASH (configurable minimum_ring_size, default 1024) or MAGLEV (a 65537-entry lookup
    • table, O(1) lookup, near-perfect balance, slightly more disruption on change).
  • Jump consistent hash (Google, 2014): no ring and no memory, O(log N), perfect balance, but only for
    • numbered buckets that are added or removed at the end.
  • Rendezvous (HRW) hashing: score every node with hash(key, node) and take the max. O(N) per lookup,
    • no vnodes needed, and a natural top-k preference list.

Extension exercises

  1. Rack-aware preference lists: give nodes a zone and make getNodes skip nodes whose zone is already used,
    2. falling back to reusing zones only when there are fewer zones than replicas.
  2. Incremental add/remove: replace the full rebuild with an O(V) sorted merge or filter, and benchmark both at 10k vnodes.
  3. Bounded loads (Google/Vimeo, 2017): cap each node at (1+ε) * average load and send overflow clockwise. Measure the max load under a Zipf workload.
  4. Rendezvous vs ring: implement HRW, then compare movement, balance and lookup cost at N = 5, 50 and 500.
  5. Ketama-compatible mode: 4 points per MD5 digest and weight-proportional point counts. Check your ring matches a known libketama server list.
ring.js 
'use strict';
/**
 * Consistent hash ring with virtual nodes and weights.
 *
 * The hash space is the 32-bit circle [0, 2^32). Each physical node owns
 * round(vnodesPerWeight * weight) points ("virtual nodes") on the circle. A key is
 * owned by the first point clockwise from hash(key) (wrapping past 2^32 - 1 to 0).
 *
 * Storage: two parallel sorted arrays (points: Uint32 hash, owners: node id), so a
 * lookup is a single lower-bound binary search: O(log V), V = total virtual nodes.
 */
const crypto = require('node:crypto');

const SPACE = 2 ** 32;

/** Default hash: first 4 bytes of MD5, big-endian (the same idea as libketama). */
function md5Hash32(str) {
  return crypto.createHash('md5').update(str).digest().readUInt32BE(0);
}

class HashRing {
  /**
   * @param {object} [opts]
   * @param {number} [opts.vnodesPerWeight=128] virtual nodes for a node of weight 1
   * @param {(s: string) => number} [opts.hash] must return an integer in [0, 2^32)
   */
  constructor({ vnodesPerWeight = 128, hash = md5Hash32 } = {}) {
    if (!Number.isInteger(vnodesPerWeight) || vnodesPerWeight < 1) {
      throw new RangeError('vnodesPerWeight must be a positive integer');
    }
    if (typeof hash !== 'function') throw new TypeError('hash must be a function');
    this.vnodesPerWeight = vnodesPerWeight;
    this.hash = hash;
    this.nodes = new Map(); // id -> { weight, vnodes }
    this.points = [];       // sorted ascending
    this.owners = [];       // owners[i] owns points[i]
  }

  _hashOf(str) {
    const h = this.hash(str);
    if (!Number.isInteger(h) || h < 0 || h >= SPACE) throw new RangeError(`hash returned ${h}, expected uint32`);
    return h;
  }

  get size() { return this.nodes.size; }
  get vnodeCount() { return this.points.length; }

  /** Add a node. Weight scales its number of virtual nodes (and so its share of keys). */
  addNode(id, { weight = 1 } = {}) {
    if (typeof id !== 'string' || id.length === 0) throw new TypeError('node id must be a non-empty string');
    if (this.nodes.has(id)) throw new Error(`node ${id} already exists`);
    if (typeof weight !== 'number' || !Number.isFinite(weight) || weight <= 0) {
      throw new RangeError('weight must be a positive finite number');
    }
    const vnodes = Math.max(1, Math.round(this.vnodesPerWeight * weight));
    this.nodes.set(id, { weight, vnodes });
    this._rebuild();
    return this;
  }

  removeNode(id) {
    if (!this.nodes.delete(id)) return false;
    this._rebuild();
    return true;
  }

  setWeight(id, weight) {
    if (!this.nodes.has(id)) throw new Error(`unknown node ${id}`);
    this.nodes.delete(id);
    return this.addNode(id, { weight });
  }

  /**
   * Rebuild the sorted arrays: O(V log V). Membership changes are rare compared with lookups,
   * so a full rebuild keeps the code simple. Hash collisions between vnodes are broken
   * deterministically by node id, so every process builds an identical ring.
   */
  _rebuild() {
    const entries = [];
    for (const [id, { vnodes }] of this.nodes) {
      for (let i = 0; i < vnodes; i++) entries.push([this._hashOf(`${id}#${i}`), id]);
    }
    entries.sort((a, b) => a[0] - b[0] || (a[1] < b[1] ? -1 : a[1] > b[1] ? 1 : 0));
    // Drop exact duplicate points (keep the first owner by id): a point can only have one owner.
    this.points = [];
    this.owners = [];
    for (const [p, id] of entries) {
      if (this.points.length && this.points[this.points.length - 1] === p) continue;
      this.points.push(p);
      this.owners.push(id);
    }
  }

  /** Index of the first point >= h, wrapping to 0. Classic lower-bound binary search. */
  _successor(h) {
    let lo = 0, hi = this.points.length; // search in [lo, hi)
    while (lo < hi) {
      const mid = (lo + hi) >>> 1;
      if (this.points[mid] < h) lo = mid + 1; else hi = mid;
    }
    return lo === this.points.length ? 0 : lo;
  }

  _keyHash(key) {
    if (typeof key !== 'string') throw new TypeError('key must be a string');
    return this._hashOf(key);
  }

  /** Owner of key, or null if the ring is empty. */
  getNode(key) {
    const h = this._keyHash(key);
    if (this.points.length === 0) return null;
    return this.owners[this._successor(h)];
  }

  /**
   * Preference list (Dynamo-style): walk clockwise from the key, collecting the first n
   * DISTINCT physical nodes. Virtual nodes of an already-chosen node are skipped, so replicas
   * never land twice on the same machine. Returns min(n, size) nodes; the first is the owner.
   */
  getNodes(key, n) {
    if (!Number.isInteger(n) || n < 1) throw new RangeError('n must be a positive integer');
    const h = this._keyHash(key);
    const want = Math.min(n, this.nodes.size);
    const out = [];
    if (want === 0) return out;
    const seen = new Set();
    const start = this._successor(h);
    for (let step = 0; step < this.points.length && out.length < want; step++) {
      const id = this.owners[(start + step) % this.points.length];
      if (!seen.has(id)) { seen.add(id); out.push(id); }
    }
    return out;
  }

  /**
   * Exact fraction of the hash circle owned by each node. The arc (points[i-1], points[i]]
   * belongs to owners[i]; the first point also owns the wrap-around arc from the last point.
   */
  ownership() {
    const share = Object.fromEntries([...this.nodes.keys()].map((id) => [id, 0]));
    const P = this.points, n = P.length;
    for (let i = 0; i < n; i++) {
      const prev = i === 0 ? P[n - 1] - SPACE : P[i - 1];
      share[this.owners[i]] += (P[i] - prev) / SPACE;
    }
    return share;
  }

  /** Count keys per node for a given key list. */
  distribution(keys) {
    const counts = Object.fromEntries([...this.nodes.keys()].map((id) => [id, 0]));
    for (const k of keys) counts[this.getNode(k)]++;
    return counts;
  }

  /** Snapshot key -> owner, for comparing before/after a membership change. */
  assignments(keys) {
    const m = new Map();
    for (const k of keys) m.set(k, this.getNode(k));
    return m;
  }
}

/**
 * Compare two assignment maps (from ring.assignments or any key -> node map).
 * Returns { total, moved, fraction, flows: { "a->b": count } }.
 */
function movementStats(before, after) {
  let moved = 0, total = 0;
  const flows = {};
  for (const [k, from] of before) {
    if (!after.has(k)) continue;
    total++;
    const to = after.get(k);
    if (from !== to) {
      moved++;
      const f = `${from}->${to}`;
      flows[f] = (flows[f] || 0) + 1;
    }
  }
  return { total, moved, fraction: total ? moved / total : 0, flows };
}

/** Coefficient of variation (stddev / mean) of a counts object: 0 = perfectly even. */
function imbalance(counts) {
  const v = Object.values(counts);
  const mean = v.reduce((a, b) => a + b, 0) / v.length;
  const variance = v.reduce((a, b) => a + (b - mean) ** 2, 0) / v.length;
  return Math.sqrt(variance) / mean;
}

module.exports = { HashRing, movementStats, imbalance, md5Hash32 };
demo.js 
'use strict';
const { HashRing, movementStats, imbalance, md5Hash32 } = require('./ring');

const KEYS = Array.from({ length: 100_000 }, (_, i) => `user:${i}`);
const pct = (x) => (100 * x).toFixed(1) + '%';
const fmt = (counts) => Object.entries(counts).map(([k, v]) => `${k}=${v}`).join('  ');

console.log('=== 1. Why virtual nodes: balance vs number of points per node ===');
for (const v of [1, 8, 32, 128, 512]) {
  const r = new HashRing({ vnodesPerWeight: v });
  ['A', 'B', 'C', 'D'].forEach((n) => r.addNode(n));
  const own = r.ownership();
  const max = Math.max(...Object.values(own));
  console.log(`vnodes/node=${String(v).padStart(3)}  ring points=${String(r.vnodeCount).padStart(4)}  ` +
    `largest share=${pct(max).padStart(6)} (ideal 25.0%)  CV of key counts=${imbalance(r.distribution(KEYS)).toFixed(3)}`);
}

console.log('\n=== 2. Adding a node moves ~1/N of keys, and only onto the new node ===');
const ring = new HashRing({ vnodesPerWeight: 128 });
['A', 'B', 'C', 'D'].forEach((n) => ring.addNode(n));
const before = ring.assignments(KEYS);
ring.addNode('E');
const afterAdd = ring.assignments(KEYS);
const add = movementStats(before, afterAdd);
console.log(`4 -> 5 nodes: moved ${add.moved}/${add.total} = ${pct(add.fraction)} (ideal 1/5 = 20.0%)`);
console.log('flows:', fmt(add.flows));

// Contrast: naive hash(key) % N.
const modN = (n) => new Map(KEYS.map((k) => [k, 'n' + (md5Hash32(k) % n)]));
const mod = movementStats(modN(4), modN(5));
console.log(`hash % N, 4 -> 5 nodes: moved ${pct(mod.fraction)} (theory 1 - 1/5 = 80%)`);

console.log('\n=== 3. Removing a node moves only its keys, spread across the survivors ===');
ring.removeNode('B');
const rem = movementStats(afterAdd, ring.assignments(KEYS));
console.log(`remove B: moved ${pct(rem.fraction)}; flows: ${fmt(rem.flows)}`);

console.log('\n=== 4. Weights: a 2x machine gets ~2x the keys ===');
const w = new HashRing({ vnodesPerWeight: 128 });
w.addNode('small-1').addNode('small-2').addNode('big', { weight: 2 });
const own = w.ownership();
console.log('ownership of hash space:', Object.entries(own).map(([k, v]) => `${k}=${pct(v)}`).join('  '), '(ideal 25/25/50)');
console.log('keys:', fmt(w.distribution(KEYS)));

console.log('\n=== 5. Replica preference list (N=3, distinct physical nodes) ===');
const rep = new HashRing({ vnodesPerWeight: 64 });
['n1', 'n2', 'n3', 'n4', 'n5'].forEach((n) => rep.addNode(n));
for (const k of ['cart:alice', 'cart:bob', 'session:42']) {
  console.log(`${k.padEnd(11)} -> [${rep.getNodes(k, 3).join(', ')}]  (first = coordinator; walk skips repeat vnodes)`);
}
const k = 'cart:alice';
const prefBefore = rep.getNodes(k, 3);
rep.removeNode(prefBefore[0]);
console.log(`remove ${prefBefore[0]} -> [${rep.getNodes(k, 3).join(', ')}]  (the two survivors keep their order; a new third joins)`);

console.log('\n=== 6. Lookup cost ===');
console.log(`${ring.vnodeCount} points -> each lookup is a binary search of <= ${Math.ceil(Math.log2(ring.vnodeCount + 1))} comparisons`);
test.js 
'use strict';
const assert = require('node:assert/strict');
const { HashRing, movementStats, imbalance } = require('./ring');

let failed = 0, passed = 0;
function test(name, fn) {
  try { fn(); passed++; console.log('✓ ' + name); }
  catch (e) { failed++; console.log('✗ ' + name + '\n    ' + (e && e.stack || e)); }
}
const KEYS = Array.from({ length: 20000 }, (_, i) => `k${i}`);
const ringOf = (ids, opts) => { const r = new HashRing(opts); ids.forEach((id) => r.addNode(id)); return r; };

// Controllable hash for exact-position tests: "name@123" hashes to 123.
const posHash = (s) => {
  const m = /@(\d+)/.exec(s);
  if (m) return Number(m[1]);
  // vnode ids look like "A#0": place node X's i-th vnode at table[X][i]
  const [id, i] = s.split('#');
  return { A: [100, 300], B: [200, 400] }[id][Number(i)];
};

test('empty ring returns null / [] and ownership is empty', () => {
  const r = new HashRing();
  assert.equal(r.getNode('x'), null);
  assert.deepEqual(r.getNodes('x', 3), []);
  assert.deepEqual(r.ownership(), {});
});

test('key maps to first vnode clockwise, inclusive, with wrap-around past the top', () => {
  const r = ringOf(['A', 'B'], { vnodesPerWeight: 2, hash: posHash }); // A:100,300  B:200,400
  assert.equal(r.getNode('k@0'), 'A');
  assert.equal(r.getNode('k@100'), 'A');   // exactly on a point -> that point
  assert.equal(r.getNode('k@101'), 'B');
  assert.equal(r.getNode('k@350'), 'B');
  assert.equal(r.getNode('k@401'), 'A');   // past the last point -> wraps to first
  assert.equal(r.getNode(`k@${2 ** 32 - 1}`), 'A');
});

test('ownership is the exact arc length and sums to 1', () => {
  const r = ringOf(['A', 'B'], { vnodesPerWeight: 2, hash: posHash });
  const own = r.ownership();
  const S = 2 ** 32;
  assert.equal(own.B, 200 / S);             // (100,200] + (300,400]
  assert.equal(own.A, (S - 200) / S);        // (0..100] + (200,300] + wrap (400, 2^32)
  const big = ringOf(['a', 'b', 'c', 'd', 'e']);
  const sum = Object.values(big.ownership()).reduce((x, y) => x + y, 0);
  assert.ok(Math.abs(sum - 1) < 1e-12);
});

test('binary search agrees with a linear scan on random hashes', () => {
  const r = ringOf(['n1', 'n2', 'n3', 'n4', 'n5', 'n6'], { vnodesPerWeight: 50 });
  let seed = 3;
  for (let i = 0; i < 5000; i++) {
    seed = (seed * 1664525 + 1013904223) >>> 0;
    const idx = r._successor(seed);
    let lin = r.points.findIndex((p) => p >= seed);
    if (lin === -1) lin = 0;
    assert.equal(idx, lin);
  }
  // Points really are sorted and unique.
  for (let i = 1; i < r.points.length; i++) assert.ok(r.points[i] > r.points[i - 1]);
});

test('virtual nodes improve balance (more vnodes -> lower imbalance)', () => {
  const ids = ['a', 'b', 'c', 'd', 'e'];
  const cv1 = imbalance(ringOf(ids, { vnodesPerWeight: 1 }).distribution(KEYS));
  const cv256 = imbalance(ringOf(ids, { vnodesPerWeight: 256 }).distribution(KEYS));
  assert.ok(cv256 < cv1, `${cv256} !< ${cv1}`);
  assert.ok(cv256 < 0.1, `cv with 256 vnodes = ${cv256}`);
});

test('adding a node moves ~1/N keys and ONLY onto the new node', () => {
  const r = ringOf(['a', 'b', 'c', 'd']);
  const before = r.assignments(KEYS);
  r.addNode('e');
  const s = movementStats(before, r.assignments(KEYS));
  for (const flow of Object.keys(s.flows)) assert.ok(flow.endsWith('->e'), flow);
  assert.ok(s.fraction > 0.12 && s.fraction < 0.28, `moved ${s.fraction}`);
});

test('removing a node moves ONLY its keys; others stay put', () => {
  const r = ringOf(['a', 'b', 'c', 'd', 'e']);
  const before = r.assignments(KEYS);
  const ownedByC = [...before.values()].filter((n) => n === 'c').length;
  assert.equal(r.removeNode('c'), true);
  assert.equal(r.removeNode('c'), false);
  const s = movementStats(before, r.assignments(KEYS));
  for (const flow of Object.keys(s.flows)) assert.ok(flow.startsWith('c->'), flow);
  assert.equal(s.moved, ownedByC);
});

test('weights: share of hash space is proportional to weight', () => {
  const r = new HashRing({ vnodesPerWeight: 256 });
  r.addNode('w1', { weight: 1 }).addNode('w3', { weight: 3 });
  const own = r.ownership();
  assert.ok(Math.abs(own.w3 - 0.75) < 0.05, `w3 share ${own.w3}`);
  assert.equal(r.nodes.get('w3').vnodes, 768);
  // Fractional weights round to at least one vnode.
  r.addNode('tiny', { weight: 0.0001 });
  assert.equal(r.nodes.get('tiny').vnodes, 1);
});

test('setWeight only moves keys to/from the reweighted node', () => {
  const r = ringOf(['a', 'b', 'c']);
  const before = r.assignments(KEYS);
  r.setWeight('b', 2);
  const s1 = movementStats(before, r.assignments(KEYS));
  for (const f of Object.keys(s1.flows)) assert.ok(f.endsWith('->b'), f);
  const mid = r.assignments(KEYS);
  r.setWeight('b', 0.5);
  const s2 = movementStats(mid, r.assignments(KEYS));
  for (const f of Object.keys(s2.flows)) assert.ok(f.startsWith('b->'), f);
});

test('preference list: distinct nodes, owner first, capped at cluster size', () => {
  const r = ringOf(['a', 'b', 'c', 'd', 'e'], { vnodesPerWeight: 64 });

test('preference list follows ring order and skips repeat vnodes', () => {
  // A:100,300  B:200,400. From 50, clockwise: A(100) B(200) A(300) B(400).
  const r = ringOf(['A', 'B'], { vnodesPerWeight: 2, hash: posHash });
  assert.deepEqual(r.getNodes('k@50', 2), ['A', 'B']);
  assert.deepEqual(r.getNodes('k@250', 2), ['A', 'B']);   // 300 is A, then 400 is B
  assert.deepEqual(r.getNodes('k@350', 2), ['B', 'A']);   // 400 B, wrap to 100 A
});

test('removing a replica keeps survivors in the same relative order', () => {
  const r = ringOf(['a', 'b', 'c', 'd', 'e', 'f'], { vnodesPerWeight: 32 });

  }
});

test('vnode hash collisions are resolved deterministically by node id', () => {
