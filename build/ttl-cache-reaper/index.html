TTL Cache with a Redis-Style Adaptive Reaper

This is a key/value cache whose entries can expire. Reads must never return an

expired value, and memory held by expired keys must eventually be freed, even

for keys that nobody reads again. The work to free that memory should not make

the server stall.

Where it shows up

  • Session and token stores: login sessions, OAuth tokens, CSRF nonces (Redis SET ... PX).
  • Rate limiters and idempotency keys: counters and request ids that must disappear after a window.
  • Distributed locks and leases: a lock that expires if its holder dies (see the redis-redlock-and-fencing-tokens lesson).
  • Inventory holds: "held in cart for 10 minutes" in flash sales.

Design

Two mechanisms work together. Neither one is enough by itself.

1. Lazy (passive) expiry. Each entry stores an absolute deadline expiresAt = now + ttl. Every get/has/ttl/expire first checks expiresAt <= now and, if it has passed, deletes the entry before answering.

This means reads are always correct. It costs O(1) and needs no background

work. It does nothing for keys that are never read again. Demo step 2 writes

10,000 such keys, and they stay in memory forever.

2. Active sampling reaper. activeExpireCycle() follows the classic Redis algorithm: 
repeat:
    if no keys have a TTL:                 stop ("empty")
    sample 20 random keys that have a TTL; delete the expired ones
    if expired/20 <= 25%:                  stop ("threshold": the rest is probably clean)
    every 16 rounds, if elapsed >= budget: stop ("budget": continue next cycle)

Call it every 100 ms (Redis hz 10) with start(), or drive it by hand.

Sampling is adaptive. A mostly clean keyspace costs a single 20-key probe per

cycle. A keyspace that is full of garbage gets worked on until either the

sample looks clean or the time budget runs out.

Data structures. A Map holds key -> {value, expiresAt}. Keys that have

a TTL (Redis calls these "volatile" keys) are also kept in a dense array plus a

key -> index map. That gives O(1) uniform random sampling and O(1) removal:

swap the removed key with the last element, then pop. Persistent keys are

never sampled, just as Redis samples only its expires dict.

Invariants (checked by a randomized test against a reference model):
  1. A read never returns a value whose deadline has passed.
  2. volatile and volatileIndex describe exactly the set of stored keys with a finite deadline.
  3. Every stop reason is reachable, and one cycle does bounded work: at most
    4. budget plus 16 rounds of overshoot.
Injectable time and randomness. clock(), random() and the timer

functions are all constructor or start() parameters. The demo charges 10 µs

of simulated time per sample, which makes the budget visible without real

sleeping.

Failure modes and trade-offs

  • 25% is a stop heuristic, not a bound. A cycle ends at the first sample
    • that looks clean. When keys expire faster than one cycle can clean them, the stale share settles well above the threshold. In demo step 3, about 250 keys expire per 100 ms and the peak stale share is about 54%. A 10% threshold brings that down to about 39% but takes about 1.5x the samples. Less garbage costs more CPU.
  • Expiry waves. If 50k keys share one deadline (for example, all written by
    • a batch job with the same TTL), cleanup takes many cycles. The budget spreads that cost out (demo step 4: 20 cycles of at most about 26 ms each) instead of one 500 ms stall. The usual mitigation is to add jitter to TTLs at write time.
  • Memory is not reclaimed right away. size includes dead keys. If the
    • cache has a hard memory cap, eviction (LRU/LFU) must also consider expired keys. Redis's volatile-ttl policy does this.
  • Clock jumps. A wall-clock step forward expires everything early, and a
    • step backward keeps keys alive too long. Production code uses a monotonic clock (performance.now() or process.hrtime) for relative TTLs. Redis itself uses wall-clock deadlines, so that deadlines survive restarts and replication.
  • Replicas. A replica cannot expire keys on its own schedule without
    • diverging from the primary. Redis replicas do not reap. The primary sends an explicit DEL when a key expires, and since Redis 3.2 replicas hide logically expired keys from reads.

How production systems do it

  • Redis ≤ 5: expireIfNeeded() on every key lookup, plus
    • activeExpireCycle(). The SLOW cycle runs from serverCron at hz (default 10) with a budget of 25% of CPU, which is 25 ms per call. A FAST cycle of at most 1 ms runs in beforeSleep. Each cycle samples 20 keys per DB (ACTIVE_EXPIRE_CYCLE_LOOKUPS_PER_LOOP), repeats while more than 25% of them were expired, and checks the time every 16 iterations. This lab implements the SLOW cycle.
  • Redis ≥ 6.0: rewrote the cycle to walk hash-table buckets of the
    • expires dict with a cursor instead of sampling at random. It added active-expire-effort (1–10). Higher effort raises the keys per loop and the CPU share and lowers the acceptable stale share. At the default effort the target is about 10%.
  • Memcached: lazy expiry on fetch, plus the LRU crawler, a background
    • thread (on by default since 1.5) that walks the tails of the LRU lists and frees expired items.
  • Caffeine (Java): variable per-entry expiry uses a **hierarchical timer
    • wheel**, which gives O(1) scheduling and precise reclamation. Maintenance work is amortized onto reads and writes rather than run on a dedicated thread.
  • DynamoDB TTL: a background scanner deletes expired items, usually within
    • a few days. Until then reads can still return expired items, so queries should filter on the TTL attribute. Cassandra writes TTL'd cells as tombstones and purges them during compaction after gc_grace_seconds.

Extension exercises

  1. Implement the Redis 6 approach. Instead of random sampling, keep a cursor
    2. into volatile and scan forward a fixed number of slots per round. Compare the peak stale share and samples with the demo workload.
  2. Add a FAST cycle: run it on each set() or get() when the last SLOW cycle
    3. stopped with budget, capped at 1 ms and at most once per 2 ms.
  3. Add maxKeys with LRU eviction and a volatile-ttl policy (evict the key
    4. closest to expiring). Which should go first, a stale key or the LRU key?
  4. Replace sampling with a hierarchical timing wheel (like Caffeine or Kafka's
    5. purgatory) and measure the precision against CPU trade-off.
  5. Add TTL jitter (±10%) on set and show how much it shortens the expiry wave in demo step 4.
cache.js 
'use strict';
/**
 * TTL cache with two expiry mechanisms, modelled on Redis:
 *
 *  1. Lazy (passive) expiry: every read checks the key's deadline and deletes it
 *     if it has passed. A read therefore never returns a stale value.
 *  2. Active expiry: a periodic "reaper" samples keys at random from the set of
 *     keys that have a TTL. If more than `threshold` of the sample was expired it
 *     assumes lots of garbage remains and samples again. It stops when the
 *     sample looks clean, the key set is empty, or the time budget runs out.
 *     This bounds the CPU spent per cycle and still keeps memory used by dead
 *     keys roughly proportional to `threshold`.
 *
 * Time is injectable (`clock()` returns ms) so tests and demos are deterministic.
 */

/** Small deterministic PRNG (mulberry32). Returns floats in [0, 1). */
function mulberry32(seed) {
  let a = seed >>> 0;
  return function next() {
    a = (a + 0x6d2b79f5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

class TTLCache {
  /**
   * @param {object} [opts]
   * @param {() => number} [opts.clock=Date.now]  current time in ms
   * @param {() => number} [opts.random]          PRNG in [0,1), default seeded mulberry32(1)
   * @param {number} [opts.sampleSize=20]         keys examined per sampling round
   * @param {number} [opts.threshold=0.25]        repeat while expired/sampled > threshold
   * @param {number} [opts.timeBudgetMs=25]       max wall time per active cycle
   * @param {number} [opts.budgetCheckEvery=16]   check the clock every N rounds (clock reads cost CPU)
   */
  constructor(opts = {}) {
    this.clock = opts.clock ?? Date.now;
    this.random = opts.random ?? mulberry32(1);
    this.sampleSize = opts.sampleSize ?? 20;
    this.threshold = opts.threshold ?? 0.25;
    this.timeBudgetMs = opts.timeBudgetMs ?? 25;
    this.budgetCheckEvery = opts.budgetCheckEvery ?? 16;
    if (typeof this.clock !== 'function') throw new TypeError('clock must be a function');
    if (!Number.isInteger(this.sampleSize) || this.sampleSize < 1) throw new RangeError('sampleSize must be a positive integer');
    if (!(this.threshold >= 0 && this.threshold < 1)) throw new RangeError('threshold must be in [0, 1)');
    if (!(this.timeBudgetMs > 0)) throw new RangeError('timeBudgetMs must be > 0');

    this.store = new Map();   // key -> { value, expiresAt (ms) | Infinity }
    // Keys with a TTL live in a dense array (+ index map) so we can sample one
    // uniformly at random in O(1) and remove one in O(1) by swapping it with the last.
    this.volatile = [];
    this.volatileIndex = new Map(); // key -> position in this.volatile
    this.timer = null;
    this.stats = {
      hits: 0, misses: 0, sets: 0, deletes: 0,
      expiredLazy: 0, expiredActive: 0,
      cycles: 0, rounds: 0, sampled: 0, budgetStops: 0,
      lastCycle: null,
    };
  }

  // --- internal bookkeeping ---------------------------------------------

  _trackVolatile(key) {
    if (this.volatileIndex.has(key)) return;
    this.volatileIndex.set(key, this.volatile.length);
    this.volatile.push(key);
  }

  _untrackVolatile(key) {
    const i = this.volatileIndex.get(key);
    if (i === undefined) return;
    const last = this.volatile.pop();
    if (i < this.volatile.length) { this.volatile[i] = last; this.volatileIndex.set(last, i); }
    this.volatileIndex.delete(key);
  }

  _remove(key) {
    this._untrackVolatile(key);
    return this.store.delete(key);
  }

  /** Returns the live entry or undefined, lazily expiring a dead one. */
  _live(key, now = this.clock()) {
    const e = this.store.get(key);
    if (e === undefined) return undefined;
    if (e.expiresAt <= now) { this._remove(key); this.stats.expiredLazy++; return undefined; }
    return e;
  }

  // --- public API --------------------------------------------------------

  /** set(key, value, { ttlMs }) — omit ttlMs for a key that never expires. */
  set(key, value, { ttlMs } = {}) {
    let expiresAt = Infinity;
    if (ttlMs !== undefined) {
      if (typeof ttlMs !== 'number' || !Number.isFinite(ttlMs)) throw new TypeError('ttlMs must be a finite number');
      // Like Redis SET with EX 0 / negative PX, a non-positive TTL deletes the key.
      if (ttlMs <= 0) { this.delete(key); return false; }
      expiresAt = this.clock() + ttlMs;
    }
    this.store.set(key, { value, expiresAt });
    if (expiresAt === Infinity) this._untrackVolatile(key); else this._trackVolatile(key);
    this.stats.sets++;
    return true;
  }

  get(key) {
    const e = this._live(key);
    if (e === undefined) { this.stats.misses++; return undefined; }
    this.stats.hits++;
    return e.value;
  }

  has(key) { return this._live(key) !== undefined; }

  delete(key) {
    const existed = this._live(key) !== undefined && this._remove(key);
    if (existed) this.stats.deletes++;
    return existed;
  }

  /** Remaining TTL in ms, -1 if the key has no TTL, -2 if missing (Redis PTTL semantics). */
  ttl(key) {
    const now = this.clock();
    const e = this._live(key, now);
    if (e === undefined) return -2;
    return e.expiresAt === Infinity ? -1 : e.expiresAt - now;
  }

  /** Set/replace the TTL of an existing key. Returns false if the key is missing. */
  expire(key, ttlMs) {
    const e = this._live(key);
    if (e === undefined) return false;
    if (typeof ttlMs !== 'number' || !Number.isFinite(ttlMs)) throw new TypeError('ttlMs must be a finite number');
    if (ttlMs <= 0) { this._remove(key); this.stats.deletes++; return true; }
    e.expiresAt = this.clock() + ttlMs;
    this._trackVolatile(key);
    return true;
  }

  /** Remove the TTL so the key lives forever (Redis PERSIST). */
  persist(key) {
    const e = this._live(key);
    if (e === undefined || e.expiresAt === Infinity) return false;
    e.expiresAt = Infinity;
    this._untrackVolatile(key);
    return true;
  }

  /**
   * Physical size: includes expired-but-not-yet-reaped keys. That gap is
   * exactly the memory the active reaper exists to reclaim.
   */
  get size() { return this.store.size; }

  /** Exact count of logically expired keys still in memory (O(n) — diagnostics only). */
  countStale() {
    const now = this.clock();
    let n = 0;
    for (const k of this.volatile) if (this.store.get(k).expiresAt <= now) n++;
    return n;
  }

  /**
   * One active expiry cycle. Returns a summary. Stop reasons:
   *   'empty'     — no keys with a TTL remain
   *   'threshold' — last sample had <= threshold expired: the rest is probably clean
   *   'budget'    — time budget exhausted (garbage may remain; next cycle continues)
   */
  activeExpireCycle({ timeBudgetMs = this.timeBudgetMs } = {}) {
    const start = this.clock();
    let rounds = 0, sampled = 0, expired = 0, stoppedBy = 'threshold';

    for (;;) {
      if (this.volatile.length === 0) { stoppedBy = 'empty'; break; }
      const now = this.clock();
      const n = Math.min(this.sampleSize, this.volatile.length);
      let roundExpired = 0;
      // Sampling with replacement, like Redis's dictGetRandomKey loop. A key
      // may be drawn twice in one round; once deleted it cannot be drawn again.
      for (let i = 0; i < n && this.volatile.length > 0; i++) {
        const key = this.volatile[Math.floor(this.random() * this.volatile.length)];
        sampled++;
        if (this.store.get(key).expiresAt <= now) { this._remove(key); roundExpired++; }
      }
      rounds++;
      expired += roundExpired;
      if (roundExpired / n <= this.threshold) { stoppedBy = 'threshold'; break; }
      if (rounds % this.budgetCheckEvery === 0 && this.clock() - start >= timeBudgetMs) {
        stoppedBy = 'budget'; break;
      }
    }

    const s = this.stats;
    s.cycles++; s.rounds += rounds; s.sampled += sampled; s.expiredActive += expired;
    if (stoppedBy === 'budget') s.budgetStops++;
    s.lastCycle = { rounds, sampled, expired, stoppedBy, elapsedMs: this.clock() - start };
    return s.lastCycle;
  }

  /**
   * Run activeExpireCycle every `intervalMs` (Redis: hz=10 -> every 100 ms).
   * Timer functions are injectable; the timer is unref'd so it never keeps
   * the process alive on its own.
   */
  start(intervalMs = 100, { setInterval: si = setInterval, clearInterval: ci = clearInterval } = {}) {
    if (this.timer) return this;
    if (!(intervalMs > 0)) throw new RangeError('intervalMs must be > 0');
    this.timer = si(() => this.activeExpireCycle(), intervalMs);
    if (this.timer && typeof this.timer.unref === 'function') this.timer.unref();
    this._clear = ci;
    return this;
  }

  stop() {
    if (this.timer) { this._clear(this.timer); this.timer = null; }
  }

  getStats() {
    const lookups = this.stats.hits + this.stats.misses;
    return {
      ...this.stats,
      size: this.store.size,
      volatileKeys: this.volatile.length,
      hitRate: lookups ? this.stats.hits / lookups : 0,
    };
  }
}

module.exports = { TTLCache, mulberry32 };

'use strict';
// Deterministic walkthrough with a simulated clock (no real sleeping).
const { TTLCache, mulberry32 } = require('./cache');

const line = (s = '') => console.log(s);
let now = 1_000_000;               // simulated ms
const clock = () => now;

line('1) Lazy expiry: reads never return stale data');
const c = new TTLCache({ clock });
c.set('session:1', { user: 'ada' }, { ttlMs: 500 });
c.set('config', 'v42');                         // no TTL
line(`   t=0     get(session:1) -> ${JSON.stringify(c.get('session:1'))}, pttl=${c.ttl('session:1')}ms, pttl(config)=${c.ttl('config')}`);
now += 500;
line(`   t=500   get(session:1) -> ${c.get('session:1')}   (deadline reached: deleted on read)`);
line(`   stats: expiredLazy=${c.stats.expiredLazy}, size=${c.size}`);
line();

line('2) Why lazy expiry alone leaks memory');
const rnd = mulberry32(7);
function populate(cache, count) {
  for (let i = 0; i < count; i++) cache.set(`k${i}`, i, { ttlMs: 1000 + Math.floor(rnd() * 4000) });
  for (let i = 0; i < count / 5; i++) cache.set(`perm${i}`, i); // 20% persistent keys
}
const lazyOnly = new TTLCache({ clock });
populate(lazyOnly, 10_000);
now += 6000; // every TTL key has expired, but nobody reads them
line(`   10,000 TTL keys written, nobody reads them, 6s pass...`);
line(`   size=${lazyOnly.size} of which stale=${lazyOnly.countStale()}  <- dead keys still hold memory`);
line();

line('3) Adaptive active reaper (sample 20, repeat while >25% expired)');
// Model CPU cost: each sampled key costs 10µs of simulated time, so the
// 25 ms budget buys ~2,500 samples per cycle.
const costlyRandom = (() => { const r = mulberry32(3); return () => { now += 0.01; return r(); }; })();
function workload(threshold, print) {
  const cache = new TTLCache({ clock, random: costlyRandom, timeBudgetMs: 25, threshold });
  now = 2_000_000;
  populate(cache, 10_000);
  let peak = 0;
  if (print) line('   tick     size  stale stale%  rounds sampled expired stop');
  for (let tick = 1; tick <= 60; tick++) {
    now = 2_000_000 + tick * 100; // hz=10: one cycle per 100 ms
    const r = cache.activeExpireCycle();
    const stale = cache.countStale(), vol = cache.volatile.length;
    if (vol) peak = Math.max(peak, stale / vol);
    if (print && tick % 6 === 0) {
      const stalePct = vol ? ((100 * stale) / vol).toFixed(0) + '%' : '-';
      line(`   ${String(tick * 100).padStart(4)}ms ${String(cache.size).padStart(6)} ${String(stale).padStart(6)} ${stalePct.padStart(6)}` +
           ` ${String(r.rounds).padStart(6)} ${String(r.sampled).padStart(7)} ${String(r.expired).padStart(7)}  ${r.stoppedBy}`);
    }
  }
  return { stats: cache.getStats(), peak };
}
const w25 = workload(0.25, true);
line(`   total: ${w25.stats.cycles} cycles, ${w25.stats.sampled} samples, ${w25.stats.expiredActive} reclaimed actively, ${w25.stats.budgetStops} budget stops`);
line('   25% is a *stop heuristic*, not a bound: ~250 keys expire per 100ms here, and the stale');
line('   share settles where the per-round chance of a "clean-looking" sample balances that rate.');
const w10 = workload(0.10, false);
line(`   peak stale share: threshold 25% -> ${(w25.peak * 100).toFixed(0)}%,  threshold 10% -> ${(w10.peak * 100).toFixed(0)}% ` +
     `(${w10.stats.sampled} vs ${w25.stats.sampled} samples: less garbage costs more CPU)`);
line();

line('4) Expiry wave: 50,000 keys die in the same millisecond');
const wave = new TTLCache({ clock, random: costlyRandom, timeBudgetMs: 25 });
now = 3_000_000;
for (let i = 0; i < 50_000; i++) wave.set(`w${i}`, i, { ttlMs: 1000 });
let cycles = 0;
now += 1000;
while (wave.volatile.length > 0 && cycles < 100) {
  const tickStart = now;
  const r = wave.activeExpireCycle();
  cycles++;
  if (cycles <= 3 || wave.volatile.length === 0) {
    line(`   cycle ${String(cycles).padStart(2)}: reclaimed ${String(r.expired).padStart(5)} in ${r.elapsedMs.toFixed(1)}ms (${r.stoppedBy}); ${wave.volatile.length} left`);
  } else if (cycles === 4) line('   ...');
  now = tickStart + 100;
}
line(`   The budget spread the work over ${cycles} cycles instead of one ~${(50_000 * 0.01).toFixed(0)}ms stall.`);
line();

line('5) TTL management (Redis-style semantics)');
const m = new TTLCache({ clock });
m.set('a', 1, { ttlMs: 1000 });

test.js 
'use strict';
const assert = require('node:assert');
const { TTLCache, mulberry32 } = require('./cache');

const tests = [];
const test = (name, fn) => tests.push({ name, fn });

function fakeClock(start = 1000) {
  const c = { t: start };
  c.now = () => c.t;
  return c;
}

/** Checks the volatile array / index map / store stay mutually consistent. */
function assertConsistent(cache) {
  assert.strictEqual(cache.volatile.length, cache.volatileIndex.size);
  cache.volatile.forEach((k, i) => {
    assert.strictEqual(cache.volatileIndex.get(k), i);
    assert.ok(cache.store.has(k));
    assert.notStrictEqual(cache.store.get(k).expiresAt, Infinity);
  });
  for (const [k, e] of cache.store) {
    assert.strictEqual(cache.volatileIndex.has(k), e.expiresAt !== Infinity);
  }
}

test('set/get with and without TTL', () => {
  const clk = fakeClock();
  const c = new TTLCache({ clock: clk.now });
  c.set('a', 1, { ttlMs: 100 });
  c.set('b', 2);
  assert.strictEqual(c.get('a'), 1);
  assert.strictEqual(c.get('b'), 2);
  assert.strictEqual(c.get('zzz'), undefined);
  clk.t += 1e9;
  assert.strictEqual(c.get('b'), 2, 'persistent key must survive');
});

test('lazy expiry: deadline is exclusive (expired at exactly expiresAt)', () => {
  const clk = fakeClock();
  const c = new TTLCache({ clock: clk.now });
  c.set('a', 1, { ttlMs: 100 });
  clk.t += 99;
  assert.strictEqual(c.get('a'), 1);
  clk.t += 1;
  assert.strictEqual(c.has('a'), false);
  assert.strictEqual(c.size, 0, 'lazy expiry must physically delete');
  assert.strictEqual(c.stats.expiredLazy, 1);
});

test('without reads or reaper, expired keys keep occupying memory', () => {
  const clk = fakeClock();
  const c = new TTLCache({ clock: clk.now });
  for (let i = 0; i < 100; i++) c.set(`k${i}`, i, { ttlMs: 10 });
  clk.t += 11;
  assert.strictEqual(c.size, 100);
  assert.strictEqual(c.countStale(), 100);
});

test('ttl()/expire()/persist() follow Redis PTTL/PEXPIRE/PERSIST semantics', () => {
  const clk = fakeClock();
  const c = new TTLCache({ clock: clk.now });
  c.set('a', 1, { ttlMs: 500 });
  c.set('p', 1);
  assert.strictEqual(c.ttl('a'), 500);
  assert.strictEqual(c.ttl('p'), -1);
  assert.strictEqual(c.ttl('missing'), -2);
  assert.strictEqual(c.persist('a'), true);
  assert.strictEqual(c.ttl('a'), -1);
  assert.strictEqual(c.persist('a'), false, 'already persistent');
  assert.strictEqual(c.expire('a', 50), true);
  clk.t += 20;
  assert.strictEqual(c.ttl('a'), 30);
  assert.strictEqual(c.expire('missing', 50), false);
  assert.strictEqual(c.expire('p', 0), true);
  assert.strictEqual(c.has('p'), false, 'expire <= 0 deletes');
  assertConsistent(c);
});

test('active cycle keeps sampling while >25% of samples are expired', () => {

test('time budget caps a cycle and remaining garbage is handled next cycle', () => {
  const clk = fakeClock();
  // Every PRNG call "costs" 0.1 ms, so a 5 ms budget allows ~50 samples.
  const base = mulberry32(9);
  const c = new TTLCache({ clock: clk.now, random: () => { clk.t += 0.1; return base(); }, timeBudgetMs: 5, budgetCheckEvery: 1 });
  for (let i = 0; i < 10_000; i++) c.set(`k${i}`, i, { ttlMs: 1 });
  clk.t += 5;
  const r1 = c.activeExpireCycle();
  assert.strictEqual(r1.stoppedBy, 'budget');
  assert.ok(r1.elapsedMs >= 5 && r1.elapsedMs < 7, `elapsed ${r1.elapsedMs}`);
  assert.ok(r1.sampled <= 60);
  assert.strictEqual(c.stats.budgetStops, 1);
  let cycles = 1;
  while (c.volatile.length && cycles < 1000) { c.activeExpireCycle(); cycles++; }
  assert.strictEqual(c.size, 0);
  assert.strictEqual(c.stats.expiredActive, 10_000);
});

test('randomized ops keep the volatile index consistent with the store', () => {
  const clk = fakeClock();
  const rnd = mulberry32(123);
  const c = new TTLCache({ clock: clk.now, random: mulberry32(1) });
  const model = new Map(); // key -> {value, expiresAt}
  for (let step = 0; step < 5000; step++) {
    const k = `k${Math.floor(rnd() * 200)}`;
    const op = rnd();
    if (op < 0.35) { const ttl = rnd() < 0.3 ? undefined : 1 + Math.floor(rnd() * 50); c.set(k, step, { ttlMs: ttl }); model.set(k, { value: step, expiresAt: ttl === undefined ? Infinity : clk.t + ttl }); }
    else if (op < 0.6) { const m = model.get(k); const want = m && m.expiresAt > clk.t ? m.value : undefined; assert.strictEqual(c.get(k), want); }
    else if (op < 0.7) { c.delete(k); model.delete(k); }
    else if (op < 0.75) { if (c.persist(k)) model.get(k).expiresAt = Infinity; }
    else if (op < 0.8) { c.activeExpireCycle(); }
    else clk.t += Math.floor(rnd() * 5);
  }
  assertConsistent(c);
  for (const [k, m] of model) assert.strictEqual(c.get(k), m.expiresAt > clk.t ? m.value : undefined);
});

test('start/stop use injected timers and unref', () => {

});
