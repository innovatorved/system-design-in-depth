HyperLogLog Cardinality Estimation

A from-scratch HyperLogLog sketch in Node. It includes a 64-bit hash (two seeded MurmurHash3 halves), precision

p from 4 to 16, max-rank registers, the harmonic-mean estimator with alpha_m, linear counting for small

cardinalities, Ertl's improved estimator as an alternative, lossless merge (including across different precisions),

and 6-bit packed serialization. Tests check the error against 3 x 1.04/sqrt(m) on 100k and 1M seeded distinct items.

The problem

"How many distinct users/IPs/search terms/devices?" An exact answer needs memory proportional to the number of distinct

items (a hash set of 100M ids is gigabytes), and exact sets from different shards or days can't be combined without

shipping all of them. HyperLogLog answers within about 1% using 12 KB, and sketches merge with a register-wise max.

That means per-shard, per-minute or per-partition sketches can be rolled up to any window or grouping later.

Where it shows up: Redis PFADD/PFCOUNT/PFMERGE, BigQuery APPROX_COUNT_DISTINCT and HLL_COUNT.*,

Trino/Presto approx_distinct, Elasticsearch/OpenSearch cardinality aggregations, Druid and Apache DataSketches,

Snowflake/Redshift approximate distinct, and the postgresql-hll extension.

Design

item ─► 64-bit hash ─► [ top p bits: register index j ][ remaining 64-p bits ]
                                                          └─► rank = leading zeros + 1   (1 .. 64-p+1)
registers[j] = max(registers[j], rank)

The intuition: in a stream of uniformly random bit strings, seeing a run of r-1 leading zeros suggests about 2^r

distinct values. One register would be hopelessly noisy, so HLL splits the stream into m = 2^p sub-streams by

the top bits and combines them with a harmonic mean, which resists outliers:

E_raw = alpha_m * m^2 / sum_j 2^(-M[j])
alpha_16 = 0.673, alpha_32 = 0.697, alpha_64 = 0.709, alpha_m = 0.7213 / (1 + 1.079/m) for m >= 128
if E_raw <= 2.5m and V registers are still zero:  E = m * ln(m / V)     (linear counting)

With a 64-bit hash, the 32-bit large-range correction from the original paper isn't needed: hash collisions stay negligible

far beyond any realistic cardinality (Heule et al. 2013).

Hash. hash64 runs MurmurHash3_x86_32 twice with independent seeds to produce hi and lo. The test suite checks

the implementation against the reference vectors and checks that all 64 output bits are balanced. Rank extraction

crosses from hi into lo when the low 32-p bits of hi are all zero, so ranks up to 64-p+1 really

occur. There is a unit test for each boundary.

Invariants
  • Registers only grow. add is idempotent, so duplicates never change the sketch (tested).
  • merge is register-wise max: commutative, associative and idempotent. a ∪ b is bit-identical to a sketch
    • built from the union stream (tested with overlapping sets).
  • Sketches only merge if they share a hash seed. Merging different precisions first folds the finer sketch down.
    • withPrecision(q) is exact: the p-q index bits that get dropped become the first bits of the remainder (new rank = their leading zeros + 1, or (p-q) + old rank if they're all zero). The tests show the result equals a sketch built directly at q.
  • Serialization: magic "HLL1" | version | p | seed u32 | registers packed 6 bits each (p=14 → 12,298 bytes).
    • Decoding rejects bad magic, bad length, invalid p and ranks above 64-p+1.

Accuracy and complexity

Relative standard error is 1.04 / sqrt(m). That's 26% at p=4, 3.25% at p=10, 0.81% at p=14 and 0.41% at p=16.

The tests assert:

  • every p in 4..16 is within 3σ at n = 100k and n = 1M
  • RMS error over 30 independent seeds is within [0.5σ, 1.5σ] of 1.04/sqrt(m), and the mean bias is small
OperationTimeSpace
addO(len(item)) hash + O(1) register update—
estimate / merge / withPrecisionO(m)m bytes in memory, 0.75·m bytes serialized
Transition-zone bias. Just after the linear-counting switch-over (about 2.5m < n < 5m), the classic estimator is

biased upward. At p=8 the demo measures about +2.3% at n = 2.6m, against about +0.8% for Ertl. That's why the 3σ test skips

the classic estimator for p=15 at n=100k (n ≈ 3m) and checks only estimate('ertl') there. A separate test

averages 300 runs to show the bump exists and that Ertl's estimator reduces it.

Failure modes and trade-offs

  • Small p is noisy. p=4 gives ±26%. Most systems use p=12–14. Error depends only on m, not on n.
  • No deletes, no exact intersection. Intersection by inclusion-exclusion (|A|+|B|-|A∪B|) takes on the absolute
    • error of the large sets, which is terrible when the overlap is small. Use MinHash or Theta sketches for set similarity.
  • Hash quality and hash agreement are correctness. A biased hash biases the estimate. Sketches built with a
    • different hash or seed merge into garbage, which is why the seed is serialized and checked.
  • Adversarial input. Anyone who knows the hash can craft items with huge ranks and inflate the count. Use a secret
    • seed when inputs are attacker-controlled.
  • Memory at low cardinality. A dense sketch costs 12 KB even for 3 items. Production systems start with a sparse
    • encoding.

How production systems do it

  • Redis uses p = 14 (16,384 registers, 0.81% standard error), with 6-bit registers in a 12 KB dense
    • encoding, a run-length sparse encoding for small sets that is promoted automatically, and MurmurHash64A. Since Redis 5 it estimates with Ertl's improved algorithm, the same one as estimate('ertl'). PFCOUNT caches the last estimate in the header.
  • Google HLL++ (BigQuery, and the ZetaSQL/HLL_COUNT functions) uses a 64-bit hash, empirical
    • bias-correction tables for n < 5m, and a sparse representation at a higher precision (p' = 25) that gives near-exact small counts.
  • Apache DataSketches (Druid, Spark, Hive) ships HLL_4/6/8 register widths, plus Theta and CPC sketches for better
    • accuracy per byte and for set operations.
  • Elasticsearch cardinality uses HLL++ and is close to exact below a precision_threshold. Trino approx_distinct
    • (the Airlift HLL) defaults to a 2.3% standard error and switches between sparse and dense representations.

hll.js 
'use strict';
// HyperLogLog cardinality sketch (Flajolet, Fusy, Gandouet, Meunier 2007) with the 64-bit-hash
// simplifications from Heule, Nunkesser, Hall 2013 ("HyperLogLog in Practice"): no large-range
// correction is needed, and linear counting handles the small range.
//
// Hash: 64 bits built from two independently seeded MurmurHash3_x86_32 passes (hi, lo).
//   bits 63..(64-p)  -> register index j   (top p bits of hi)
//   remaining 64-p   -> rank = (leading zeros of the remainder) + 1, in 1..(64-p+1)
// Each register keeps the max rank it has seen; ranks fit in 6 bits for every p in 4..16.

const MIN_P = 4, MAX_P = 16;
const MAGIC = 0x484c4c31; // "HLL1"
const HEADER = 10;        // magic u32 | version u8 | p u8 | seed u32

// ---------------------------------------------------------------- hashing
function murmur3_32(bytes, len, seed) {
  const c1 = 0xcc9e2d51, c2 = 0x1b873593;
  let h = seed >>> 0, i = 0;
  const blocks = len & ~3;
  for (; i < blocks; i += 4) {
    let k = bytes[i] | (bytes[i + 1] << 8) | (bytes[i + 2] << 16) | (bytes[i + 3] << 24);
    k = Math.imul(k, c1); k = (k << 15) | (k >>> 17); k = Math.imul(k, c2);
    h ^= k; h = (h << 13) | (h >>> 19); h = (Math.imul(h, 5) + 0xe6546b64) | 0;
  }
  let k = 0;
  switch (len & 3) { // intentional fall-through, as in the reference implementation
    case 3: k ^= bytes[i + 2] << 16; // falls through
    case 2: k ^= bytes[i + 1] << 8;  // falls through
    case 1: k ^= bytes[i]; k = Math.imul(k, c1); k = (k << 15) | (k >>> 17); k = Math.imul(k, c2); h ^= k;
  }
  h ^= len;
  h ^= h >>> 16; h = Math.imul(h, 0x85ebca6b); h ^= h >>> 13; h = Math.imul(h, 0xc2b2ae35); h ^= h >>> 16;
  return h >>> 0;
}

const encoder = new TextEncoder();
let scratch = new Uint8Array(256);
function toBytes(item) { // -> [bytes, length]; reuses a scratch buffer for strings (hot path)
  if (item instanceof Uint8Array) return [item, item.length];
  if (typeof item === 'number' || typeof item === 'bigint') item = String(item);
  if (typeof item !== 'string') throw new TypeError('item must be a string, number, bigint or Uint8Array');
  if (item.length * 3 > scratch.length) scratch = new Uint8Array(item.length * 3);
  return [scratch, encoder.encodeInto(item, scratch).written];
}
const SEED_LO = 0x5bd1e995;
function hash64(item, seed = 0) { // -> { hi, lo } unsigned 32-bit halves
  const [b, n] = toBytes(item);
  return { hi: murmur3_32(b, n, seed), lo: murmur3_32(b, n, (seed ^ SEED_LO) >>> 0) };
}

// ---------------------------------------------------------------- estimator constants
function alpha(m) { // bias correction for the harmonic mean (FFGM07, section 4)
  if (m === 16) return 0.673;
  if (m === 32) return 0.697;
  if (m === 64) return 0.709;
  return 0.7213 / (1 + 1.079 / m);
}
function sigma(x) { // x + sum_k 2^(k-1) x^(2^k); diverges at x = 1 (empty sketch -> estimate 0)
  if (x === 1) return Infinity;
  let y = 1, z = x, prev;
  do { x *= x; prev = z; z += x * y; y += y; } while (z !== prev);
  return z;
}
function tau(x) {
  if (x === 0 || x === 1) return 0;
  let y = 1, z = 1 - x, prev;
  do { x = Math.sqrt(x); prev = z; y *= 0.5; z -= (1 - x) * (1 - x) * y; } while (z !== prev);
  return z / 3;
}
const POW2NEG = Float64Array.from({ length: 66 }, (_, r) => Math.pow(2, -r));

class HyperLogLog {
  constructor(p = 14, { seed = 0 } = {}) {
    if (!Number.isInteger(p) || p < MIN_P || p > MAX_P) throw new RangeError(`precision p must be an integer in [${MIN_P}, ${MAX_P}]`);
    if (!Number.isInteger(seed) || seed < 0 || seed > 0xffffffff) throw new RangeError('seed must be a uint32');
    this.p = p; this.m = 1 << p; this.seed = seed;
    this.registers = new Uint8Array(this.m);
  }

  add(item) { const h = hash64(item, this.seed); return this.addHash(h.hi, h.lo); }

  // Returns true if a register changed (useful for "did cardinality possibly grow?").
  addHash(hi, lo) {
    const p = this.p, j = hi >>> (32 - p);
    // remainder = low (32-p) bits of hi followed by 32 bits of lo  (64-p bits total)
    const hiRest = (hi << p) >>> 0; // left-aligned; low p bits are zero padding
    let rank;
    if (hiRest !== 0) rank = Math.clz32(hiRest) + 1;              // first 1 lies in the hi part
    else rank = (32 - p) + (lo === 0 ? 32 : Math.clz32(lo)) + 1;  // all hi bits zero: continue into lo
    if (rank > this.registers[j]) { this.registers[j] = rank; return true; }
    return false;
  }

  // estimate("classic") [default]: the FFGM07 harmonic mean with alpha_m, switching to linear counting
  // when E <= 5m/2 and some register is still empty. estimate("ertl"): see _ertl() below.
  estimate(method = "classic") {
    if (method === "ertl") return this._ertl();
    if (method !== "classic") throw new RangeError("method must be \"classic\" or \"ertl\"");
    const m = this.m, R = this.registers;
    let sum = 0, zeros = 0;
    for (let j = 0; j < m; j++) { sum += POW2NEG[R[j]]; if (R[j] === 0) zeros++; }
    const raw = alpha(m) * m * m / sum;
    if (raw <= 2.5 * m && zeros > 0) return m * Math.log(m / zeros); // linear counting (small range)
    return raw; // 64-bit hash: collisions are negligible far past 2^32, so no large-range correction
  }
  count(method) { return Math.round(this.estimate(method)); }

  // Ertl 2017, "New cardinality estimation algorithms for HyperLogLog sketches" (used by Redis >= 5).
  // Works on the register-value histogram C[0..q+1] and needs no empirical tables. It removes the
  // bias bump that the classic estimator shows just past its linear-counting switch-over (n ~ 2.5m..5m).
  _ertl() {
    const m = this.m, q = 64 - this.p, C = new Float64Array(q + 2);
    for (let j = 0; j < m; j++) C[this.registers[j]]++;
    let z = m * tau(1 - C[q + 1] / m);
    for (let k = q; k >= 1; k--) z = 0.5 * (z + C[k]);
    z += m * sigma(C[0] / m);
    return m * m / (2 * Math.LN2 * z); // alpha_inf = 1 / (2 ln 2)
  }
  standardError() { return 1.04 / Math.sqrt(this.m); }

  _assertCompatible(other) {
    if (!(other instanceof HyperLogLog)) throw new TypeError('can only merge another HyperLogLog');
    if (other.seed !== this.seed) throw new Error('cannot merge sketches built with different hash seeds');
  }
  // Union: register-wise max. Commutative, associative, idempotent, so it is safe to merge
  // partial sketches from shards, time buckets or retries in any order. Sketches with different
  // precision are merged by first folding the finer one down to the coarser precision.
  merge(other) {
    this._assertCompatible(other);
    if (other.p < this.p) { const folded = this.withPrecision(other.p); this.p = folded.p; this.m = folded.m; this.registers = folded.registers; }
    const src = other.p === this.p ? other.registers : other.withPrecision(this.p).registers;
    for (let j = 0; j < this.m; j++) if (src[j] > this.registers[j]) this.registers[j] = src[j];
    return this;
  }
  static union(...sketches) {
    if (!sketches.length) throw new Error('union needs at least one sketch');
    return sketches.reduce((acc, s) => acc.merge(s), sketches[0].clone());
  }

  // Exact precision reduction: result equals a sketch built directly at precision q from the same items.
  // The d = p - q low index bits move to the front of the remainder:
  //   those bits != 0  -> new rank = leading zeros within the d bits + 1   (old rank no longer matters)
  //   those bits == 0  -> new rank = d + old rank
  withPrecision(q) {
    if (!Number.isInteger(q) || q < MIN_P || q > this.p) throw new RangeError(`target precision must be in [${MIN_P}, ${this.p}]`);
    const out = new HyperLogLog(q, { seed: this.seed }), d = this.p - q;
    if (d === 0) { out.registers.set(this.registers); return out; }
    for (let j = 0; j < this.m; j++) {
      const r = this.registers[j];
      if (r === 0) continue; // no item landed here
      const low = j & ((1 << d) - 1), nj = j >>> d;
      const nr = low !== 0 ? Math.clz32(low) - (32 - d) + 1 : d + r;
      if (nr > out.registers[nj]) out.registers[nj] = nr;
    }
    return out;
  }

  clone() { const c = new HyperLogLog(this.p, { seed: this.seed }); c.registers.set(this.registers); return c; }
  equals(other) { return other instanceof HyperLogLog && other.p === this.p && other.seed === this.seed && Buffer.compare(Buffer.from(this.registers), Buffer.from(other.registers)) === 0; }

  // Dense 6-bit packed encoding (as in Redis' dense representation): p=14 -> 12 KB + header.
  serialize() {
    const out = Buffer.alloc(HEADER + Math.ceil(this.m * 6 / 8));
    out.writeUInt32LE(MAGIC, 0); out.writeUInt8(1, 4); out.writeUInt8(this.p, 5); out.writeUInt32LE(this.seed, 6);
    for (let j = 0; j < this.m; j++) {
      const bit = j * 6, byte = HEADER + (bit >> 3), shift = bit & 7, v = this.registers[j];
      out[byte] |= (v << shift) & 0xff;
      if (shift > 2) out[byte + 1] |= v >> (8 - shift); // register straddles a byte boundary
    }
    return out;
  }
  static deserialize(buf) {
    if (!(buf instanceof Uint8Array) || buf.length < HEADER) throw new Error('not an HLL buffer');
    const b = Buffer.from(buf.buffer, buf.byteOffset, buf.length);
    if (b.readUInt32LE(0) !== MAGIC || b.readUInt8(4) !== 1) throw new Error('bad HLL magic/version');
    const s = new HyperLogLog(b.readUInt8(5), { seed: b.readUInt32LE(6) }); // validates p
    if (b.length !== HEADER + Math.ceil(s.m * 6 / 8)) throw new Error(`bad HLL length ${b.length} for p=${s.p}`);
    const maxRank = 64 - s.p + 1;
    for (let j = 0; j < s.m; j++) {
      const bit = j * 6, byte = HEADER + (bit >> 3), shift = bit & 7;
      let v = b[byte] >> shift;
      if (shift > 2) v |= b[byte + 1] << (8 - shift);
      v &= 0x3f;
      if (v > maxRank) throw new Error(`register ${j} holds impossible rank ${v}`);
      s.registers[j] = v;
    }
    return s;
  }
}

module.exports = { HyperLogLog, hash64, murmur3_32, alpha, MIN_P, MAX_P };

'use strict';
// Deterministic HyperLogLog walkthrough: registers, accuracy vs precision, merging, serialization.
const { HyperLogLog, hash64 } = require('./hll');

function mulberry32(seed) {
  return () => { seed |= 0; seed = (seed + 0x6d2b79f5) | 0; let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
}

for (const ratio of [1, 2, 2.6, 3.5, 5, 10]) {

'use strict';
const assert = require('node:assert/strict');
const { HyperLogLog, hash64, murmur3_32, alpha } = require('./hll');

let failed = 0;
function test(name, fn) {
  try { fn(); console.log('✓ ' + name); }
  catch (e) { failed++; console.log('✗ ' + name + '\n    ' + (e && e.stack || e)); }
}
function mulberry32(seed) {
  return () => { seed |= 0; seed = (seed + 0x6d2b79f5) | 0; let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
}
// Seeded generator of DISTINCT items: a random 64-bit-ish prefix per run plus a counter.
function distinctItems(seed) {
  const r = mulberry32(seed), tag = Math.floor(r() * 2 ** 32).toString(36);
  return (i) => `${tag}-${i}`;
}
const relErr = (est, n) => Math.abs(est - n) / n;

test('murmur3_32 matches reference test vectors', () => {
  const enc = (s) => { const b = Buffer.from(s, 'utf8'); return [b, b.length]; };
  assert.equal(murmur3_32(...enc(''), 0), 0);
  assert.equal(murmur3_32(...enc(''), 1), 0x514e28b7);
  assert.equal(murmur3_32(...enc('hello'), 0), 0x248bfa47);
  assert.equal(murmur3_32(...enc('The quick brown fox jumps over the lazy dog'), 0), 0x2e4ff723);
  assert.equal(murmur3_32(...enc('abc'), 0), 0xb3dd93fa);
});

test('64-bit hash: every one of the 64 bits is set ~50% of the time', () => {
  const n = 100000, counts = new Array(64).fill(0);
  for (let i = 0; i < n; i++) {
    const { hi, lo } = hash64('bit-balance-' + i);
    for (let b = 0; b < 32; b++) { counts[b] += (hi >>> b) & 1; counts[32 + b] += (lo >>> b) & 1; }
  }
  for (const c of counts) assert.ok(Math.abs(c / n - 0.5) < 0.01, 'bit frequency ' + c / n); // 6.3 sigma
});

test('precision and seed validation', () => {
  for (const p of [3, 17, 10.5, '12', NaN]) assert.throws(() => new HyperLogLog(p), RangeError);
  assert.throws(() => new HyperLogLog(12, { seed: -1 }), RangeError);
  assert.throws(() => new HyperLogLog(12).add({}), TypeError);
  assert.equal(new HyperLogLog(4).m, 16);
  assert.equal(new HyperLogLog(16).m, 65536);
  assert.equal(alpha(16), 0.673);
  assert.ok(Math.abs(alpha(1 << 14) - 0.7213 / (1 + 1.079 / 16384)) < 1e-15);
});

test('rank extraction: index from the top p bits, rank = leading zeros of the rest + 1', () => {
  const h = new HyperLogLog(4);
  h.addHash(0xf8000000, 0); assert.equal(h.registers[15], 1);       // 1111 | 1...
  h.addHash(0x10800000, 0); assert.equal(h.registers[1], 5);        // 0001 | 0000 1...
  h.addHash(0x20000000, 0x80000000); assert.equal(h.registers[2], 29); // 28 zero bits in hi, then 1
  h.addHash(0x30000000, 0); assert.equal(h.registers[3], 61);       // remainder all zero: 64-p+1
  assert.equal(h.addHash(0x10800000, 0), false);                    // same rank again: no change
});

test('empty sketch estimates 0; small cardinalities are near-exact via linear counting', () => {
  assert.equal(new HyperLogLog(14).count(), 0);
  for (const n of [1, 10, 100, 1000]) {
    const h = new HyperLogLog(14), gen = distinctItems(n);
    for (let i = 0; i < n; i++) h.add(gen(i));
    assert.ok(Math.abs(h.count() - n) <= Math.max(1, n * 0.02), `n=${n} est=${h.count()}`);
  }
});

test('duplicates do not change the sketch', () => {
  const h = new HyperLogLog(12), gen = distinctItems(5);
  for (let i = 0; i < 5000; i++) h.add(gen(i));
  const snapshot = h.clone();
  for (let rep = 0; rep < 3; rep++) for (let i = 0; i < 5000; i++) h.add(gen(i));
  assert.ok(h.equals(snapshot));
});

// The classic estimator has a known bias bump just past its linear-counting switch-over (2.5m < n < ~5m),
// the region HLL++ patches with empirical tables. At n=100k that zone contains p=15 (n = 3.05m), so the
// classic check skips it there; Ertl's estimator has no such zone and is checked for every p.
test('100k and 1M distinct items: error within 3 standard errors for p = 4..16', () => {
  const sketches = []; for (let p = 4; p <= 16; p++) sketches.push(new HyperLogLog(p));
  const gen = distinctItems(2024);
  let n = 0;
  for (const checkpoint of [100000, 1000000]) {
    for (; n < checkpoint; n++) { const { hi, lo } = hash64(gen(n)); for (const s of sketches) s.addHash(hi, lo); }
    for (const s of sketches) {
      const bound = 3 * s.standardError(), transition = n > 2 * s.m && n < 5 * s.m;
      for (const method of transition ? ['ertl'] : ['classic', 'ertl']) {
        const err = relErr(s.estimate(method), n);
        assert.ok(err < bound, `${method} p=${s.p} n=${n} rel.err=${err.toFixed(4)} > 3σ=${bound.toFixed(4)}`);
      }
    }
  }
});

test('RMS error over 30 independent seeds matches 1.04/sqrt(m) (p=10, n=50k)', () => {
  const p = 10, n = 50000, runs = 30, sigma = 1.04 / Math.sqrt(1 << p);
  let sq = 0, bias = 0;
  for (let s = 0; s < runs; s++) {
    const h = new HyperLogLog(p, { seed: s + 1 }), gen = distinctItems(100 + s);
    for (let i = 0; i < n; i++) h.add(gen(i));
    const e = (h.estimate() - n) / n; sq += e * e; bias += e;
  }
  const rms = Math.sqrt(sq / runs);
  assert.ok(rms > 0.5 * sigma && rms < 1.5 * sigma, `rms ${rms.toFixed(4)} vs sigma ${sigma.toFixed(4)}`);
  assert.ok(Math.abs(bias / runs) < 2 * sigma / Math.sqrt(runs) + 0.005, 'mean bias ' + (bias / runs));
});

test('transition zone: classic estimator is biased near n = 2.5m, Ertl estimator is not', () => {
  const p = 8, m = 1 << p, n = Math.round(2.6 * m), runs = 300;
  let classic = 0, ertl = 0;
  for (let s = 0; s < runs; s++) {
    const h = new HyperLogLog(p), gen = distinctItems(5000 + s);
    for (let i = 0; i < n; i++) h.add(gen(i));
    classic += (h.estimate() - n) / n; ertl += (h.estimate('ertl') - n) / n;
  }
  classic /= runs; ertl /= runs; // standard error of each mean is ~ 6.5% / sqrt(300) = 0.4%
  assert.ok(classic > 0.008, 'classic mean bias ' + classic);
  assert.ok(Math.abs(ertl) < 0.008 && Math.abs(ertl) < classic / 2, 'ertl mean bias ' + ertl);
  assert.throws(() => new HyperLogLog(8).estimate('hllpp'), RangeError);
  assert.equal(new HyperLogLog(8).estimate('ertl'), 0);
});

test('merge equals the sketch of the union (overlapping sets), and is commutative and idempotent', () => {
  const gen = distinctItems(9), a = new HyperLogLog(12), b = new HyperLogLog(12), all = new HyperLogLog(12);
  for (let i = 0; i < 60000; i++) { a.add(gen(i)); all.add(gen(i)); }
  for (let i = 40000; i < 100000; i++) { b.add(gen(i)); all.add(gen(i)); }
  const ab = a.clone().merge(b), ba = b.clone().merge(a);
  assert.ok(ab.equals(all) && ba.equals(all));
  assert.ok(ab.clone().merge(b).equals(ab));
  assert.ok(HyperLogLog.union(a, b, a).equals(all));
  assert.ok(relErr(ab.estimate(), 100000) < 3 * ab.standardError());
  assert.throws(() => a.clone().merge(new HyperLogLog(12, { seed: 1 })), /seeds/);
  assert.throws(() => a.merge({}), TypeError);
});

test('precision folding is exact, so sketches of different p can be merged', () => {
  const gen = distinctItems(77), fine = new HyperLogLog(14);
  const direct = {}; for (const q of [4, 8, 11, 14]) direct[q] = new HyperLogLog(q);
  for (let i = 0; i < 200000; i++) { const { hi, lo } = hash64(gen(i)); fine.addHash(hi, lo); for (const q in direct) direct[q].addHash(hi, lo); }
  for (const q of [4, 8, 11, 14]) assert.ok(fine.withPrecision(q).equals(direct[q]), 'fold to p=' + q);
  const merged = new HyperLogLog(11).merge(fine); // coarse.merge(fine)
  assert.ok(merged.equals(direct[11]));
  const merged2 = fine.clone().merge(new HyperLogLog(8)); // fine.merge(coarse) folds itself down
  assert.equal(merged2.p, 8); assert.ok(merged2.equals(direct[8]));
  assert.throws(() => fine.withPrecision(15), RangeError);
});

test('serialization round-trips exactly with 6-bit packing for every p', () => {
  for (let p = 4; p <= 16; p++) {
    const h = new HyperLogLog(p, { seed: 42 }), gen = distinctItems(p);
    for (let i = 0; i < 3000; i++) h.add(gen(i));
    h.addHash(0, 0); // register 0 gets the maximum rank 64-p+1
    const buf = h.serialize();
    assert.equal(buf.length, 10 + Math.ceil((1 << p) * 6 / 8));
    const back = HyperLogLog.deserialize(buf);
    assert.ok(back.equals(h), 'p=' + p);
    assert.equal(back.registers[0], 64 - p + 1);
  }
  assert.equal(new HyperLogLog(14).serialize().length, 12298); // 12 KB, like Redis' dense encoding
});

test('deserialize rejects bad magic, wrong length, bad precision and impossible ranks', () => {
  const good = new HyperLogLog(10).serialize();
  const bad = (mut) => { const b = Buffer.from(good); mut(b); return b; };
  assert.throws(() => HyperLogLog.deserialize(bad((b) => { b[0] ^= 1; })), /magic/);
  assert.throws(() => HyperLogLog.deserialize(good.subarray(0, good.length - 1)), /length/);
  assert.throws(() => HyperLogLog.deserialize(bad((b) => { b[5] = 20; })), RangeError);
  assert.throws(() => HyperLogLog.deserialize(bad((b) => { b[10] = 0x3f; })), /impossible rank/); // 63 > 55
  assert.throws(() => HyperLogLog.deserialize('nope'), /not an HLL/);
});
