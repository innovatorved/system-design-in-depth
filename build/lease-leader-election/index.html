Lease-Based Leader Election with Fencing Tokens

A lease store that issues monotonic fencing tokens, clients that renew and step down early using a clock-drift safety margin, and a storage layer that rejects stale tokens, so a leader that was paused by GC cannot corrupt data. All time is injected, so every scenario is deterministic.

Lease-Based Leader Election with Fencing Tokens

The problem

Many systems need exactly one node to do something: run the scheduler, own a shard, accept

writes for a partition, or be the active NameNode. Nodes crash and networks partition, so

"exactly one" has to recover on its own. The standard tool is a lease: a lock that

expires unless it is renewed. When the leader dies, the lease runs out and someone else

takes over.

Leases alone are not safe. A leader can check that it holds the lease and then freeze:

a GC pause, a VM migration, a swapped-out page, a slow disk. By the time it runs again the

lease has expired, a successor is active, and the old leader sends its write anyway. The fix

(Chubby's "sequencers", popularised by Kleppmann's critique of Redlock) is a **fencing

token*: a number that increases with every change of ownership and that the protected

resource* checks.

Where it shows up: Kubernetes controller-manager/scheduler (coordination.k8s.io/Lease),

HDFS NameNode HA (quorum journal epochs), Kafka controller epochs, etcd and ZooKeeper

election recipes, Google Chubby, and any cron or singleton worker that must not run twice.

Design

LeaseClient A ──acquire/renew──►  LeaseStore  (authority on ownership, issues tokens 1,2,3...)
  LeaseClient B ──acquire/renew──►
        │ write(token, ...)
        ▼
  FencedStorage  (remembers highest token seen, rejects anything lower)
lease.js exports:
  • LeaseStore: acquire(holder, ttl), renew(holder, token, ttl), release(holder, token).
    • A new owner always receives token + 1, including the same node coming back after its own lease expired, because someone else may have held the lease in between. Tokens never go down, even after a release.
  • LeaseClient: a candidate state machine driven by tick(). Its local check
    • isLeader() makes no network call.
  • FencedStorage: write(token, k, v) and fence(token). A token equal to the highest seen
    • is accepted (the same leader keeps writing); a lower one throws StaleTokenError.
  • ManualClock, DriftingClock (injectable clocks with rate drift and offset) and
    • mulberry32 (a seeded PRNG).

Invariants and the timing argument

  1. Token monotonicity: each ownership change in the store gets exactly the next integer.
  2. Storage safety: once storage has seen token n, no write with a token below n ever
    3. lands. This holds whatever the clocks do. It is the real safety net.
  3. Belief safety: at most one client has isLeader() === true at any real instant,
    4. provided relative clock drift stays within maxDriftRate. The client: - starts its countdown when it sends the request, not when the reply arrives. The store started the TTL later than that, so network delay only shortens the client's view. - acts only for safeWindow = ttl * (1 - maxDriftRate) - safetyMargin on its own clock. If that clock runs slow by rate r, the window lasts safeWindow / (1 - r) real ms, which is at most ttl whenever r ≤ maxDriftRate. - renews after renewFraction (1/3) of the window, so it survives a couple of lost renewals.
  4. Clock offset does not matter: only durations on a monotonic clock are used, never
    5. wall-clock timestamps compared across machines. DriftingClock in the demo runs B's clock 42 s ahead to show this.

The seeded chaos test runs 3 clients with random drift inside the bound and random pauses of

up to 1 s, and asserts invariant 3 at every step. If you set maxDriftRate and the margin to

0, the same test fails, so the margin is doing real work.

Election barrier

Storage can only reject token 1 after it has seen token 2. If the new leader has not

written yet, a zombie write with token 1 still gets in (the test shows this). The fix is for

the new leader to call storage.fence(token) as its first act, the way HDFS makes a new

NameNode bump the epoch on a quorum of JournalNodes before it writes.

Complexity

All operations are O(1) time and space. Memory is O(ownership changes) only because

history and events are kept for inspection. Failover takes at most ttl (plus one tick),

or one tick after a voluntary resign().

Failure modes & trade-offs

  • TTL length: a short TTL gives fast failover but false failovers under GC or network
    • jitter. A long TTL means longer unavailability when the leader really dies. Kubernetes defaults to 15 s lease / 10 s renew deadline / 2 s retry.
  • Drift beyond the bound breaks belief safety, as the demo's -20% case shows. Storage
    • safety still holds, which is why fencing is not optional.
  • Resources that cannot check tokens (a third-party API, an email being sent) cannot be
    • fenced. You need idempotency keys or a design that accepts at-least-once effects.
  • The lease store must itself be consistent. A token counter backed by one replicated
    • Raft log (etcd) or ZAB (ZooKeeper) is fine. A single Redis without replication is a single point of failure. Redlock across independent Redis nodes does not produce monotonic tokens at all.
  • Store restarts must never reuse tokens. Persist the counter, or derive it from a
    • replicated revision number.

How production systems do it

  • etcd: LeaseGrant / LeaseKeepAlive with a server-side TTL. The concurrency.Election
    • recipe writes a key attached to the lease, and the key's create revision (globally monotonic) works as the fencing token. Transactions can compare mod_revision so a write only applies if leadership has not changed.
  • ZooKeeper: ephemeral sequential znodes tied to the session timeout. The lowest sequence
    • number leads. The zxid or znode version serves as the token.
  • Chubby: lock holders obtain a sequencer (lock name, mode, generation) and pass it to
    • servers, which verify it. There is also a lock-delay for clients that do not check sequencers.
  • Kubernetes client-go leaderelection: a Lease object updated with optimistic
    • concurrency (resourceVersion) and a leaseTransitions counter. The docs say it relies on bounded clock skew and does not fence the controlled resources.
  • HDFS QJM: each new active NameNode obtains a higher epoch. JournalNodes reject edits
    • from lower epochs. This is textbook storage-side fencing.
  • Raft (etcd, CockroachDB, TiKV): terms act as fencing tokens for log replication.
    • Leader leases on top allow local reads, and they depend on the same bounded-drift argument used here.

How to run

node demo.js   # election, renewals, 6 s GC pause fenced off, drift within vs beyond bound, hand-over
node test.js   # 15 tests, including a seeded multi-client chaos run

Extension exercises

  1. Put the LeaseStore behind a simulated network with delay and loss, and check that sending
    2. time, not receive time, is what keeps isLeader() safe.
  2. Make FencedStorage a replicated store: a write succeeds only if a majority of replicas
    3. accept its token. Then partition one replica.
  3. Implement etcd-style compare-and-swap writes (if leaderKey.createRevision == myToken)
    4. instead of a highest-seen check, and compare the two.
  4. Add a lease-delay mode like Chubby's: after an expiry, the store refuses new owners for
    5. an extra period, which protects resources that cannot check tokens.
  5. Measure false failovers against TTL and renewFraction under a GC-pause distribution
    6. (for example, lognormal), and plot availability against failover time.
lease.js 
'use strict';
/**
 * Lease-based leader election with fencing tokens.
 *
 *   LeaseStore     the lock service (think etcd / ZooKeeper / a DynamoDB row). It is the only
 *                  authority on who holds the lease, and it hands out a strictly increasing
 *                  fencing token each time ownership changes.
 *   LeaseClient    a candidate. It trusts only its own monotonic clock and stops acting as
 *                  leader early enough that bounded clock drift can never let two clients
 *                  believe they lead at once.
 *   FencedStorage  the protected resource. It remembers the highest token it has seen and
 *                  rejects anything older. This is what makes a leader that was paused by GC
 *                  and then wakes up harmless.
 *
 * All time comes from injected clocks, so every scenario is deterministic.
 */

// ---------------------------------------------------------------- clocks ----
class ManualClock {
  constructor(start = 0) { this.t = start; }
  now() { return this.t; }
  advance(ms) {
    if (!(ms >= 0)) throw new RangeError('clocks are monotonic: advance(ms) needs ms >= 0');
    this.t += ms;
    return this.t;
  }
}

/**
 * A node-local monotonic clock that runs `rate` faster (+) or slower (-) than true time,
 * with an arbitrary offset. The offset (wall-clock skew) is irrelevant to lease safety,
 * because clients only measure durations. The rate (drift) is what the safety margin has to cover.
 */
class DriftingClock {
  constructor(base, { rate = 0, offset = 0 } = {}) {
    if (!base || typeof base.now !== 'function') throw new TypeError('base clock needs now()');
    if (!(rate > -1)) throw new RangeError('rate must be > -1');
    this.base = base; this.rate = rate; this.offset = offset; this.t0 = base.now();
  }
  now() { return this.offset + this.t0 + (this.base.now() - this.t0) * (1 + this.rate); }
}

// ------------------------------------------------------------ lease store ----
class LeaseStore {
  constructor({ clock }) {
    if (!clock || typeof clock.now !== 'function') throw new TypeError('LeaseStore needs a clock');
    this.clock = clock;
    this.holder = null;
    this.token = 0;       // last token issued; never decreases, even after release/expiry
    this.expiresAt = -Infinity;
    this.history = [];    // [{token, holder, at}] one entry per ownership change
  }

  _expired() { return this.clock.now() >= this.expiresAt; }

  /**
   * Acquire, or re-acquire if already held by the caller. A new owner always gets a NEW,
   * larger token. The current owner calling again keeps its token and extends the lease.
   */
  acquire(holder, ttlMs) {
    if (typeof holder !== 'string' || !holder) throw new TypeError('holder must be a non-empty string');
    if (!(Number.isFinite(ttlMs) && ttlMs > 0)) throw new RangeError('ttlMs must be a positive number');
    const now = this.clock.now();
    if (this.holder !== null && !this._expired() && this.holder !== holder) {
      return { ok: false, holder: this.holder, retryInMs: this.expiresAt - now };
    }
    if (this.holder !== holder || this._expired()) {
      this.token += 1;
      this.holder = holder;
      this.history.push({ token: this.token, holder, at: now });
    }
    this.expiresAt = now + ttlMs;
    return { ok: true, token: this.token, ttlMs };
  }

  /** Renew only if the caller still owns the lease under exactly this token and it has not expired. */
  renew(holder, token, ttlMs) {
    if (!(Number.isFinite(ttlMs) && ttlMs > 0)) throw new RangeError('ttlMs must be a positive number');
    if (this.holder !== holder || this.token !== token || this._expired()) {
      return { ok: false, holder: this._expired() ? null : this.holder };
    }
    this.expiresAt = this.clock.now() + ttlMs;
    return { ok: true, token, ttlMs };
  }

  /** Voluntary step-down so a successor need not wait for the TTL. Wrong token = no-op. */
  release(holder, token) {
    if (this.holder !== holder || this.token !== token) return false;
    this.holder = null;
    this.expiresAt = -Infinity;
    return true;
  }

  current() { return this._expired() ? null : { holder: this.holder, token: this.token, expiresAt: this.expiresAt }; }
}

// ----------------------------------------------------------- lease client ----
class LeaseClient {
  /**
   * @param {object} o
   * @param {string} o.id
   * @param {LeaseStore} o.store
   * @param {{now():number}} o.clock        this node's own monotonic clock
   * @param {number} o.ttlMs                lease duration requested from the store
   * @param {number} [o.maxDriftRate=0.01]  assumed bound on |drift| between this clock and the store's
   * @param {number} [o.safetyMarginMs]     extra slack for scheduling/GC jitter (default 5% of ttl)
   * @param {number} [o.renewFraction=1/3]  renew once this fraction of the safe window has passed
   */
  constructor({ id, store, clock, ttlMs, maxDriftRate = 0.01, safetyMarginMs, renewFraction = 1 / 3 }) {
    if (typeof id !== 'string' || !id) throw new TypeError('id must be a non-empty string');
    if (!(store instanceof LeaseStore)) throw new TypeError('store must be a LeaseStore');
    if (!clock || typeof clock.now !== 'function') throw new TypeError('clock needs now()');
    if (!(ttlMs > 0)) throw new RangeError('ttlMs must be > 0');
    if (!(maxDriftRate >= 0 && maxDriftRate < 1)) throw new RangeError('maxDriftRate must be in [0, 1)');
    if (!(renewFraction > 0 && renewFraction < 1)) throw new RangeError('renewFraction must be in (0, 1)');
    this.id = id; this.store = store; this.clock = clock; this.ttlMs = ttlMs;
    this.maxDriftRate = maxDriftRate;
    this.safetyMarginMs = safetyMarginMs === undefined ? ttlMs * 0.05 : safetyMarginMs;
    // Local duration during which we may act. If our clock runs slow by rate r, then
    // `local` ms of ours equal local/(1-r) true ms, so we need local <= ttl*(1-r).
    this.safeWindowMs = ttlMs * (1 - maxDriftRate) - this.safetyMarginMs;
    if (!(this.safeWindowMs > 0)) throw new RangeError('safety margin + drift allowance consume the whole ttl');
    this.renewFraction = renewFraction;
    this.token = null;
    this.safeUntil = -Infinity; // on OUR clock
    this.events = [];
  }

  /** True only while the lease is certainly still ours (a local check that makes no network call). */
  isLeader() { return this.token !== null && this.clock.now() < this.safeUntil; }

  _granted(res, sentAt) {
    // Measure from when the request was SENT: the store started its TTL later than that,
    // so any network delay only makes us stop earlier (safe), never later.
    if (this.token !== res.token) this.events.push({ at: sentAt, event: 'elected', token: res.token });
    this.token = res.token;
    this.safeUntil = sentAt + this.safeWindowMs;
  }

  _stepDown(reason) {
    if (this.token !== null) this.events.push({ at: this.clock.now(), event: 'stepped-down', token: this.token, reason });
    this.token = null;
    this.safeUntil = -Infinity;
  }

  /** Drive the state machine; call periodically. Returns the current role. */
  tick() {
    const now = this.clock.now();
    if (this.token !== null && now >= this.safeUntil) this._stepDown('lease-expired-locally');
    if (this.token !== null) {
      const renewAt = this.safeUntil - this.safeWindowMs * (1 - this.renewFraction);
      if (now >= renewAt) {
        const res = this.store.renew(this.id, this.token, this.ttlMs);
        if (res.ok) this._granted(res, now); else this._stepDown('renew-rejected');
      }
    } else {
      const res = this.store.acquire(this.id, this.ttlMs);
      if (res.ok) this._granted(res, now);
    }
    return this.isLeader() ? 'leader' : 'follower';
  }

  resign() {
    if (this.token !== null) this.store.release(this.id, this.token);
    this._stepDown('resigned');
  }
}

// --------------------------------------------------------- fenced storage ----
class StaleTokenError extends Error {
  constructor(token, highest) { super(`stale fencing token ${token} (highest seen ${highest})`); this.token = token; this.highest = highest; }
}

class FencedStorage {
  constructor() { this.highestToken = 0; this.data = new Map(); this.log = []; this.rejected = 0; }

  _check(token) {
    if (!Number.isSafeInteger(token) || token <= 0) throw new TypeError('token must be a positive integer');
    if (token < this.highestToken) { this.rejected++; throw new StaleTokenError(token, this.highestToken); }
    this.highestToken = token;
  }

  /**
   * Barrier: a new leader calls this right after election, so the old leader is fenced off
   * even before the new one has written anything. Without it, the storage cannot know that
   * token 1 is stale until it first sees token 2.
   */
  fence(token) { this._check(token); }

  write(token, key, value) {
    this._check(token); // equal is fine: the same leader keeps writing under one token
    this.data.set(key, value);
    this.log.push({ token, key, value });
  }
}

/** Mulberry32: tiny seeded PRNG for reproducible simulations. */
function mulberry32(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

demo.js 
'use strict';
// Deterministic walkthrough: election, renewals, a GC pause, fencing, and clock drift.
const { ManualClock, DriftingClock, LeaseStore, LeaseClient, FencedStorage, StaleTokenError } = require('./lease');

const truth = new ManualClock();              // the lock service's clock = "true" time
const store = new LeaseStore({ clock: truth });
const storage = new FencedStorage();
const TTL = 3000;
const mk = (id, rate) => new LeaseClient({ id, store, ttlMs: TTL, maxDriftRate: 0.01, safetyMarginMs: 100, clock: new DriftingClock(truth, { rate, offset: id === 'node-B' ? 42_000 : 0 }) });
const A = mk('node-A', -0.008); // runs 0.8% slow
const B = mk('node-B', +0.005); // runs 0.5% fast, and its wall clock is 42 s ahead (irrelevant)
const t = () => `t=${String(truth.now()).padStart(5)}ms`;
const roles = () => `A:${A.isLeader() ? `LEADER(tok ${A.token})` : 'follower'}  B:${B.isLeader() ? `LEADER(tok ${B.token})` : 'follower'}`;

function run(ms, step = 250, clients = [A, B]) {
  for (let el = 0; el < ms; el += step) {
    for (const c of clients) {
      const before = c.token;
      c.tick();
      if (c.isLeader() && c.token !== before) {
        storage.fence(c.token); // election barrier: storage learns the new token immediately
        console.log(`${t()}  ${c.id} elected with fencing token ${c.token}; fenced storage at ${c.token}`);
      }
    }
    truth.advance(step);
  }
}

console.log(`Lease TTL ${TTL} ms. Client safe window = TTL*(1-maxDrift) - margin = ${A.safeWindowMs} ms (on its own clock).`);
console.log('Renewal is attempted after 1/3 of the safe window.\n');

console.log('1) Election and steady-state renewals');
run(4000);
console.log(`${t()}  ${roles()}  store history: ${JSON.stringify(store.history.map((h) => [h.holder, h.token]))}`);
storage.write(A.token, 'config', 'v1 by A');
console.log(`${t()}  A writes config=v1 with token ${A.token}: ok\n`);

console.log('2) A stalls in a 6 s stop-the-world GC right after checking isLeader()');
const zombieToken = A.token;
console.log(`${t()}  A.isLeader() = ${A.isLeader()}  -> A decides to write ...`);
run(6000, 250, [B]); // only B gets CPU time
storage.write(B.token, 'config', 'v2 by B');
console.log(`${t()}  B writes config=v2 with token ${B.token}: ok`);
console.log(`${t()}  A wakes up and sends its write with token ${zombieToken}`);
try {
  storage.write(zombieToken, 'config', 'v0 by zombie A');
  console.log('   !!! write accepted: split brain');
} catch (e) {
  if (!(e instanceof StaleTokenError)) throw e;
  console.log(`   rejected by storage: ${e.message}`);
}
console.log(`   config = "${storage.data.get('config')}" (B's write survives); A.isLeader() now = ${A.isLeader()}`);
run(250);
console.log(`${t()}  ${roles()}\n`);

console.log('3) Why the client must use a safety margin: drift vs. lease expiry');
for (const [label, rate, maxDrift] of [['within bound (-1%, assumed 1%)', -0.01, 0.01], ['beyond bound (-20%, assumed 1%)', -0.2, 0.01]]) {
  const clock = new ManualClock();
  const s = new LeaseStore({ clock });
  const c = new LeaseClient({ id: 'x', store: s, ttlMs: 1000, maxDriftRate: maxDrift, safetyMarginMs: 0, clock: new DriftingClock(clock, { rate }) });
  c.tick();
  let lastLed = 0;
  while (clock.now() < 1500) { if (c.isLeader()) lastLed = clock.now(); clock.advance(1); }
  const verdict = lastLed < 1000 ? 'safe: stopped before the store expired the lease at 1000' : 'UNSAFE: still leading after the store expired the lease at 1000';
  console.log(`   ${label.padEnd(32)} client led until true t=${lastLed} -> ${verdict}`);
}

console.log('\n4) Graceful hand-over: B resigns, A takes over without waiting for the TTL');
B.resign();
run(250);
console.log(`${t()}  ${roles()}`);
storage.write(A.token, 'config', 'v3 by A');
console.log(`   write log: ${storage.log.map((e) => `[tok ${e.token}] ${e.value}`).join('  ')}`);
console.log(`   stale writes rejected: ${storage.rejected}`);
test.js 
'use strict';
const assert = require('node:assert');
const {
  ManualClock, DriftingClock, LeaseStore, LeaseClient, FencedStorage, StaleTokenError, mulberry32,
} = require('./lease');

let failed = 0; let count = 0;
function test(name, fn) {
  count++;
  try { fn(); console.log(`✓ ${name}`); } catch (err) { failed++; console.log(`✗ ${name}\n  ${err.stack}`); }
}

test('first acquirer gets token 1; a rival is refused while the lease is live', () => {
  const clock = new ManualClock();
  const store = new LeaseStore({ clock });
  assert.deepStrictEqual(store.acquire('a', 1000), { ok: true, token: 1, ttlMs: 1000 });
  clock.advance(999);
  const r = store.acquire('b', 1000);
  assert.strictEqual(r.ok, false);
  assert.strictEqual(r.holder, 'a');
  assert.strictEqual(r.retryInMs, 1);
});

test('renewal extends the lease and keeps the same token', () => {
  const clock = new ManualClock();
  const store = new LeaseStore({ clock });
  store.acquire('a', 1000);
  for (let i = 0; i < 10; i++) { clock.advance(600); assert.deepStrictEqual(store.renew('a', 1, 1000), { ok: true, token: 1, ttlMs: 1000 }); }
  assert.strictEqual(store.acquire('b', 1000).ok, false);
  assert.strictEqual(store.history.length, 1);
});

test('after expiry a new holder gets a strictly larger token and the old one cannot renew', () => {
  const clock = new ManualClock();
  const store = new LeaseStore({ clock });
  store.acquire('a', 1000);
  clock.advance(1000); // expiry is exclusive: at t = expiresAt the lease is gone
  assert.deepStrictEqual(store.acquire('b', 1000), { ok: true, token: 2, ttlMs: 1000 });
  assert.strictEqual(store.renew('a', 1, 1000).ok, false);
  assert.strictEqual(store.renew('b', 1, 1000).ok, false, 'right holder, wrong token');
});

test('the same holder re-acquiring after its own expiry still gets a new token', () => {
  const clock = new ManualClock();
  const store = new LeaseStore({ clock });
  store.acquire('a', 100);
  clock.advance(150);
  assert.strictEqual(store.acquire('a', 100).token, 2); // someone may have held it in between
});

test('tokens are strictly monotonic across random handovers, releases and expiries', () => {
  const rnd = mulberry32(7);
  const clock = new ManualClock();
  const store = new LeaseStore({ clock });
  let last = 0;
  for (let i = 0; i < 2000; i++) {
    const who = `n${Math.floor(rnd() * 4)}`;
    const r = store.acquire(who, 50 + rnd() * 100);
    if (r.ok) { assert.ok(r.token >= last); last = r.token; }
    if (rnd() < 0.2 && store.current()) store.release(store.holder, store.token);
    clock.advance(rnd() * 120);
  }
  const tokens = store.history.map((h) => h.token);
  tokens.forEach((t, i) => assert.strictEqual(t, i + 1)); // one new token per ownership change, no gaps
  assert.ok(tokens.length > 100);
});

test('release allows immediate takeover; releasing with a stale token does nothing', () => {
  const clock = new ManualClock();
  const store = new LeaseStore({ clock });
  store.acquire('a', 10_000);

test('GC pause: the paused ex-leader is fenced out and its write never lands', () => {
  const clock = new ManualClock();
  const store = new LeaseStore({ clock });
  const storage = new FencedStorage();
  const a = new LeaseClient({ id: 'a', store, clock, ttlMs: 1000 });
  const b = new LeaseClient({ id: 'b', store, clock, ttlMs: 1000 });
  a.tick(); b.tick();
  assert.ok(a.isLeader() && !b.isLeader());
  const token = a.token;
  assert.ok(a.isLeader()); // a checks "am I leader?" ... then stops the world for 5 s
  clock.advance(5000);
  b.tick();                // b is elected while a is frozen
  assert.ok(b.isLeader());
  storage.fence(b.token);  // election barrier
  assert.throws(() => storage.write(token, 'config', 'from-zombie'), StaleTokenError);

  assert.strictEqual(a.isLeader(), false); // once a looks at its clock again it knows it lost
});

test('safety invariant: at most one client believes it leads at any instant (seeded chaos)', () => {
  for (const seed of [1, 2, 3, 4, 5]) {
    const rnd = mulberry32(seed);
    const truth = new ManualClock();
    const store = new LeaseStore({ clock: truth });
    const storage = new FencedStorage();
    const clients = ['a', 'b', 'c'].map((id) => new LeaseClient({
      id, store, ttlMs: 300, maxDriftRate: 0.02,
      clock: new DriftingClock(truth, { rate: (rnd() * 2 - 1) * 0.02, offset: rnd() * 1e6 }),
    }));
    const pausedUntil = new Map();
    let leaderships = 0;
    for (let step = 0; step < 5000; step++) {
      for (const c of clients) {
        if ((pausedUntil.get(c) || 0) > truth.now()) continue; // frozen (GC / VM stall)
        if (rnd() < 0.002) { pausedUntil.set(c, truth.now() + rnd() * 1000); continue; }
        const before = c.token;
        c.tick();
        if (c.isLeader() && before !== c.token) { storage.fence(c.token); leaderships++; }
        if (c.isLeader() && rnd() < 0.3) storage.write(c.token, 'k', c.id);
      }
      const leaders = clients.filter((c) => c.isLeader());
      assert.ok(leaders.length <= 1, `seed ${seed} step ${step}: ${leaders.map((l) => l.id)}`);
      truth.advance(1 + rnd() * 10);
    }
    assert.ok(leaderships >= 2, `seed ${seed}: expected failovers, got ${leaderships}`);
    for (let i = 1; i < storage.log.length; i++) assert.ok(storage.log[i].token >= storage.log[i - 1].token);
  }
});
