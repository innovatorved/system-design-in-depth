Bloom Filter Membership Testing

A Bloom filter answers "have I seen this key?" in a fixed amount of memory

with two possible answers: definitely not or probably yes. It never

gives false negatives. The false-positive rate (FPR) is something you choose

at design time and pay for in bits.

Where it shows up

  • LSM storage engines (RocksDB, Cassandra, HBase, LevelDB): each SSTable has
    • a filter, so a point read skips files that can't contain the key and avoids a disk seek.
  • Caches and CDNs: "one-hit-wonder" filters admit an object into cache only
    • on its second request (Akamai's Maggs & Sitaraman, 2015).
  • Recommendation / feed dedup: "has this user already seen this post?"
    • (see the lesson seen-filtering-bloom-vs-exact-sets).
  • Distributed joins: Spark and Impala runtime filters send a small Bloom
    • filter from the build side to the probe side so non-matching rows are dropped early.

Design

add("user:42")
  h1 = murmur3(bytes, seedA)          h2 = murmur3(bytes, seedB) | 1
  g_i = (h1 + i*h2) mod m   for i = 0..k-1       <- Kirsch–Mitzenmacher
  set bit g_i in Uint8Array               byte = g >> 3, mask = 1 << (g & 7)
has(x): all k bits set?  -> "probably"   any bit clear? -> "definitely not"
Sizing. For n expected items and target FPR p: 
m = ceil( -n * ln(p) / (ln 2)^2 )      bits
k = round( (m / n) * ln 2 )            hash functions
FPR(n) = (1 - e^(-k n / m))^k          after inserting n distinct items

At the optimal k about half the bits are set. Each 10x reduction in p

costs log2(10)/ln 2 ≈ 4.79 more bits per item. For 1% that works out to

9.59 bits/item and k = 7. The demo checks these numbers.

Double hashing. Kirsch & Mitzenmacher (2006) showed that g_i = h1 + i*h2 gives the same asymptotic FPR as k independent hashes, so

you only need two hash computations per operation. h2 is forced odd so the

stride is never zero. If it were, all k probes would land on one bit.

Invariants.
  1. No false negatives. A bit is never cleared in the plain filter.
  2. Bits past m in the last byte are always zero. deserialize checks this.
  3. union only works for filters with the same (m, k) and the same hash
    4. seeds. It is a bitwise OR, and the result is exactly the filter you would get by building from both sets at once.
Measured vs theoretical. expectedFpr() uses the formula above with the

insert count. currentFpr() uses the actual fill ratio (X/m)^k. The demo

checks both against 200k real non-member probes. They agree to within a few

percent of each other.

Serialization. A 16-byte big-endian header (magic "BLM1" | k | m | count)

followed by the raw bit array. This is enough to mmap or ship over the wire.

Hash seeds are fixed constants, so any reader using this module computes the

same positions.

Counting variant. CountingBloomFilter replaces each bit with a 4-bit

counter, packed two per byte, to support remove(). Fan et al. ("Summary

Cache", 2000) showed that 4 bits overflow with negligible probability at

optimal load. A counter that reaches 15 becomes sticky and is never

decremented, because its true value is unknown. toBloomFilter() collapses

it to a plain filter for read-only consumers.

Failure modes and trade-offs

  • Overfilling. At 2x design load a 1% filter gets about 16% FPR. At 4x it
    • gets about 68% (see demo step 3). The filter cannot grow, so rebuild it or use a scalable Bloom filter: a chain of filters with tightening FPRs.
  • Counting-filter misuse. Calling remove(x) for an x that was never
    • added, but tests positive, decrements counters that belong to other keys and introduces false negatives. This implementation refuses removes that test negative, but it cannot detect a false-positive remove. Only remove keys you know you inserted.
  • Cache misses. Probes are random across m bits, so each lookup can touch
    • k cache lines. Blocked and cache-local filters (RocksDB's FastLocalBloom) keep all k probes in one 64-byte line and pay a small FPR penalty.
  • Hash quality. A weak or adversarially known hash lets attackers craft
    • keys that collide. Use a keyed hash (e.g. SipHash) if inputs are hostile.
  • Deletes vs space. Counting filters cost 4x the memory. Cuckoo filters
    • support deletes at about the same space as a Bloom filter when FPR < ~3%.

How production systems do it

  • Cassandra: one Bloom filter per SSTable, kept off-heap. It is tuned per
    • table with bloom_filter_fp_chance (default 0.01, and 0.1 for LeveledCompactionStrategy). It uses Murmur3 128-bit with the same h1 + i*h2 double hashing.
  • RocksDB: per-SST "full" filters, or partitioned filters for very large
    • files. Configured with bits_per_key (commonly 10, about 1% FPR). format_version=5 introduced the cache-local FastLocalBloom. The Ribbon filter (NewRibbonFilterPolicy) saves about 30% of the space for more build CPU.
  • Google Guava: BloomFilter.create(funnel, n, p) uses the same m/k
    • formulas and the MURMUR128_MITZ_64 strategy (Kirsch–Mitzenmacher on 128-bit Murmur3).
  • Redis Stack (RedisBloom): BF.RESERVE key error_rate capacity [EXPANSION n]
    • creates a scalable Bloom filter that stacks sub-filters as it fills. CF.* commands provide cuckoo filters with delete.
  • HBase: per-HFile ROW or ROWCOL Bloom filters, chosen per column family.

bloom.js 
'use strict';
/**
 * Bloom filter + counting Bloom filter.
 *
 * - Sizing: m = ceil(-n ln p / (ln 2)^2), k = round((m / n) ln 2)
 * - Hashing: Kirsch–Mitzenmacher double hashing, g_i(x) = (h1 + i*h2) mod m,
 *   built from two independent 32-bit MurmurHash3 evaluations (different seeds).
 *   Two good hashes are enough: the asymptotic FPR matches k independent hashes.
 * - Storage: plain bit array packed into a Uint8Array (bit j lives in byte j>>3).
 * - Counting variant: 4-bit saturating counters (two per byte) to support delete.
 */

const MAGIC = 0x424c4d31; // "BLM1"
const HEADER_BYTES = 16;  // magic u32 | k u32 | m u32 | count u32 (big endian)
const MAX_BITS = 2 ** 32 - 1;

/** Optimal parameters for n expected items at target false-positive rate p. */
function optimalParams(n, p) {
  if (!Number.isInteger(n) || n <= 0) throw new RangeError('n must be a positive integer');
  if (!(p > 0 && p < 1)) throw new RangeError('p must be in (0, 1)');
  const m = Math.ceil((-n * Math.log(p)) / (Math.LN2 * Math.LN2));
  if (m > MAX_BITS) throw new RangeError(`m=${m} bits exceeds 2^32-1; shard the filter`);
  const k = Math.max(1, Math.round((m / n) * Math.LN2));
  return { m, k, bitsPerItem: m / n };
}

/** Theoretical FPR after inserting n distinct items: (1 - e^(-kn/m))^k. */
function theoreticalFpr(m, k, n) {
  return Math.pow(1 - Math.exp((-k * n) / m), k);
}

// --- hashing ---------------------------------------------------------------

function toBytes(item) {
  if (typeof item === 'string') return Buffer.from(item, 'utf8');
  if (item instanceof Uint8Array) return item;
  if (typeof item === 'number' || typeof item === 'bigint') return Buffer.from(String(item), 'utf8');
  throw new TypeError('item must be a string, number, bigint, Buffer or Uint8Array');
}

/** MurmurHash3 x86_32. Returns an unsigned 32-bit integer. */
function murmur3(bytes, seed) {
  let h = seed >>> 0;
  const len = bytes.length;
  const nblocks = len >>> 2;
  const c1 = 0xcc9e2d51, c2 = 0x1b873593;
  for (let i = 0; i < nblocks; i++) {
    const o = i << 2;
    let k = bytes[o] | (bytes[o + 1] << 8) | (bytes[o + 2] << 16) | (bytes[o + 3] << 24);
    k = Math.imul(k, c1); k = (k << 15) | (k >>> 17); k = Math.imul(k, c2);
    h ^= k; h = (h << 13) | (h >>> 19); h = (Math.imul(h, 5) + 0xe6546b64) | 0;
  }
  let k = 0;
  const tail = nblocks << 2;
  switch (len & 3) {
    case 3: k ^= bytes[tail + 2] << 16; // fallthrough
    case 2: k ^= bytes[tail + 1] << 8;  // fallthrough
    case 1: k ^= bytes[tail];
      k = Math.imul(k, c1); k = (k << 15) | (k >>> 17); k = Math.imul(k, c2); h ^= k;
  }
  h ^= len;
  h ^= h >>> 16; h = Math.imul(h, 0x85ebca6b);
  h ^= h >>> 13; h = Math.imul(h, 0xc2b2ae35);
  h ^= h >>> 16;
  return h >>> 0;
}

/**
 * Fill `out` with k bit positions using double hashing. h2 is forced odd so
 * the probe stride is never 0 (which would collapse all k probes onto h1).
 * All arithmetic stays below 2^53: h1 < 2^32, i*h2 < k*2^32.
 */
function positions(bytes, k, m, out) {
  const h1 = murmur3(bytes, 0x9747b28c);
  const h2 = murmur3(bytes, 0x5bd1e995) | 1;
  for (let i = 0; i < k; i++) out[i] = (h1 + i * (h2 >>> 0)) % m;
  return out;
}

// --- standard Bloom filter -------------------------------------------------

class BloomFilter {
  /**
   * new BloomFilter({ expectedItems, falsePositiveRate })  -> optimal sizing
   * new BloomFilter({ bits, hashes })                      -> explicit sizing
   */
  constructor(opts = {}) {
    let { bits: m, hashes: k } = opts;
    if (m === undefined) {
      ({ m, k } = optimalParams(opts.expectedItems ?? 1000, opts.falsePositiveRate ?? 0.01));
    }
    if (!Number.isInteger(m) || m < 1 || m > MAX_BITS) throw new RangeError('bits must be an integer in [1, 2^32-1]');
    if (!Number.isInteger(k) || k < 1 || k > 64) throw new RangeError('hashes must be an integer in [1, 64]');
    this.m = m;
    this.k = k;
    this.count = 0; // number of add() calls that set at least one new bit (approx distinct items)
    this.bits = new Uint8Array(Math.ceil(m / 8));
    this._pos = new Array(k);
  }

  add(item) {
    positions(toBytes(item), this.k, this.m, this._pos);
    let changed = false;
    for (const p of this._pos) {
      const byte = p >>> 3, mask = 1 << (p & 7);
      if ((this.bits[byte] & mask) === 0) { this.bits[byte] |= mask; changed = true; }
    }
    // If no bit changed the item (or a collision twin) was already present;
    // not counting it keeps `count` close to the number of distinct items.
    if (changed) this.count++;
    return changed;
  }

  /** false => definitely absent. true => probably present. */
  has(item) {
    positions(toBytes(item), this.k, this.m, this._pos);
    for (const p of this._pos) {
      if ((this.bits[p >>> 3] & (1 << (p & 7))) === 0) return false;
    }
    return true;
  }

  /** Number of set bits (population count). */
  popcount() {
    let c = 0;
    for (let b of this.bits) { while (b) { b &= b - 1; c++; } }
    return c;
  }

  /** FPR predicted from the current fill ratio: (X/m)^k. Works even if count is unknown. */
  currentFpr() { return Math.pow(this.popcount() / this.m, this.k); }

  /** FPR predicted from the number of inserted items. */
  expectedFpr() { return theoreticalFpr(this.m, this.k, this.count); }

  /** Swamidass–Baldi cardinality estimate: n* = -(m/k) ln(1 - X/m). */
  estimateCardinality() {
    const x = this.popcount();
    if (x === this.m) return Infinity;
    return (-this.m / this.k) * Math.log(1 - x / this.m);
  }

  /** Bitwise OR of two filters with identical (m, k): the union of both sets. */
  union(other) {
    if (!(other instanceof BloomFilter) || other.m !== this.m || other.k !== this.k) {
      throw new Error('union requires filters with identical m and k');
    }
    const out = new BloomFilter({ bits: this.m, hashes: this.k });
    for (let i = 0; i < this.bits.length; i++) out.bits[i] = this.bits[i] | other.bits[i];
    out.count = Math.round(out.estimateCardinality());
    return out;
  }

  /** Portable binary form: 16-byte big-endian header followed by the bit array. */
  serialize() {
    const buf = Buffer.alloc(HEADER_BYTES + this.bits.length);
    buf.writeUInt32BE(MAGIC, 0);
    buf.writeUInt32BE(this.k, 4);
    buf.writeUInt32BE(this.m, 8);
    buf.writeUInt32BE(Math.min(this.count, MAX_BITS), 12);
    buf.set(this.bits, HEADER_BYTES);
    return buf;
  }

  static deserialize(buf) {
    if (!(buf instanceof Uint8Array) || buf.length < HEADER_BYTES) throw new Error('buffer too short');
    const b = Buffer.from(buf.buffer, buf.byteOffset, buf.byteLength);
    if (b.readUInt32BE(0) !== MAGIC) throw new Error('bad magic: not a serialized BloomFilter');
    const k = b.readUInt32BE(4), m = b.readUInt32BE(8), count = b.readUInt32BE(12);
    const f = new BloomFilter({ bits: m, hashes: k });
    if (b.length !== HEADER_BYTES + f.bits.length) throw new Error(`corrupt payload: expected ${f.bits.length} bytes of bits`);
    f.bits.set(b.subarray(HEADER_BYTES));
    // Padding bits past m in the final byte must be zero, else the payload is corrupt.
    const spare = f.bits.length * 8 - m;
    if (spare > 0 && (f.bits[f.bits.length - 1] >>> (8 - spare)) !== 0) throw new Error('corrupt payload: padding bits set');
    f.count = count;
    return f;
  }
}

// --- counting Bloom filter -------------------------------------------------

/**
 * Each slot is a 4-bit counter (Fan et al., "Summary Cache", 2000). Four bits
 * overflow with probability ~1.37e-15 * m at optimal load. A counter that hits
 * 15 becomes sticky: it is never decremented, because we no longer know its
 * true value — decrementing it could create false negatives.
 */
class CountingBloomFilter {
  constructor(opts = {}) {
    let { bits: m, hashes: k } = opts;
    if (m === undefined) {
      ({ m, k } = optimalParams(opts.expectedItems ?? 1000, opts.falsePositiveRate ?? 0.01));
    }
    if (!Number.isInteger(m) || m < 1 || m > MAX_BITS) throw new RangeError('bits must be an integer in [1, 2^32-1]');
    if (!Number.isInteger(k) || k < 1 || k > 64) throw new RangeError('hashes must be an integer in [1, 64]');
    this.m = m;
    this.k = k;
    this.count = 0;
    this.saturated = 0; // counters stuck at 15
    this.counters = new Uint8Array(Math.ceil(m / 2));
    this._pos = new Array(k);
  }

  _get(i) { const b = this.counters[i >>> 1]; return (i & 1) ? b >>> 4 : b & 0x0f; }
  _set(i, v) {
    const j = i >>> 1, b = this.counters[j];
    this.counters[j] = (i & 1) ? (b & 0x0f) | (v << 4) : (b & 0xf0) | v;
  }

  add(item) {
    positions(toBytes(item), this.k, this.m, this._pos);
    for (const p of this._pos) {
      const c = this._get(p);
      if (c < 15) { this._set(p, c + 1); if (c + 1 === 15) this.saturated++; }
    }
    this.count++;
  }

  has(item) {
    positions(toBytes(item), this.k, this.m, this._pos);
    for (const p of this._pos) if (this._get(p) === 0) return false;
    return true;
  }

  /**
   * Remove an item previously added. Returns false (and changes nothing) if the
   * filter says the item is definitely absent. Caller contract: only remove
   * items you actually inserted; removing a false positive corrupts the filter
   * by decrementing counters owned by other items (=> false negatives).
   */
  remove(item) {
    if (!this.has(item)) return false; // also refreshes this._pos
    for (const p of this._pos) {
      const c = this._get(p);
      if (c > 0 && c < 15) this._set(p, c - 1);
    }
    this.count--;
    return true;
  }

  expectedFpr() { return theoreticalFpr(this.m, this.k, this.count); }

  /** Collapse to a plain BloomFilter (counter > 0 => bit set), e.g. to ship to readers. */
  toBloomFilter() {
    const f = new BloomFilter({ bits: this.m, hashes: this.k });
    for (let i = 0; i < this.m; i++) if (this._get(i) > 0) f.bits[i >>> 3] |= 1 << (i & 7);
    f.count = this.count;
    return f;
  }
}

module.exports = { BloomFilter, CountingBloomFilter, optimalParams, theoreticalFpr, murmur3 };

// Deterministic walkthrough: sizing, measured vs theoretical FPR, overfill,
// serialization round-trip, and deletes with a counting Bloom filter.

const pct = (x) => (x * 100).toFixed(3) + '%';
const line = (s = '') => console.log(s);

function measure(filter, probes) {
  let fp = 0;
  for (let i = 0; i < probes; i++) if (filter.has(`absent:${i}`)) fp++;
  return fp / probes;
}

line('1) Sizing from n and p');

}
line('   Rule of thumb: every 10x lower FPR costs ~4.8 more bits per item.');
line();

for (let i = 0; i < n; i++) bf.add(`user:${i}`);
let falseNeg = 0;
for (let i = 0; i < n; i++) if (!bf.has(`user:${i}`)) falseNeg++;
const probes = 200_000;

'use strict';
const assert = require('node:assert');
const { BloomFilter, CountingBloomFilter, optimalParams, theoreticalFpr, murmur3 } = require('./bloom');

let failed = 0;
function test(name, fn) {
  try { fn(); console.log(`✓ ${name}`); }
  catch (e) { failed++; console.log(`✗ ${name}\n  ${e.stack}`); }
}

test('murmur3 matches reference vectors', () => {
  assert.strictEqual(murmur3(Buffer.from(''), 0), 0);
  assert.strictEqual(murmur3(Buffer.from(''), 1), 0x514e28b7);
  assert.strictEqual(murmur3(Buffer.from('hello'), 0), 0x248bfa47);
  assert.strictEqual(murmur3(Buffer.from('The quick brown fox jumps over the lazy dog'), 0), 0x2e4ff723);
});

test('optimalParams matches closed-form sizing', () => {
  // n=1e6, p=1% -> 9,585,059 bits, k=7 (textbook values)
  assert.deepStrictEqual(
    (({ m, k }) => ({ m, k }))(optimalParams(1_000_000, 0.01)),
    { m: 9_585_059, k: 7 });
  const { m, k } = optimalParams(1000, 0.001);
  assert.strictEqual(m, 14_378);
  assert.strictEqual(k, 10);
});

test('optimalParams rejects invalid input', () => {
  assert.throws(() => optimalParams(0, 0.01), RangeError);
  assert.throws(() => optimalParams(10, 0), RangeError);
  assert.throws(() => optimalParams(10, 1), RangeError);
  assert.throws(() => optimalParams(1.5, 0.1), RangeError);
  assert.throws(() => new BloomFilter({ bits: 0, hashes: 3 }), RangeError);
  assert.throws(() => new BloomFilter({ bits: 100, hashes: 0 }), RangeError);
});

test('no false negatives', () => {
  const f = new BloomFilter({ expectedItems: 5000, falsePositiveRate: 0.01 });
  for (let i = 0; i < 5000; i++) f.add(`item-${i}`);
  for (let i = 0; i < 5000; i++) assert.ok(f.has(`item-${i}`), `lost item-${i}`);

test('measured FPR tracks theoretical FPR at design load', () => {
  const n = 10_000;
  const f = new BloomFilter({ expectedItems: n, falsePositiveRate: 0.01 });
  for (let i = 0; i < n; i++) f.add(`member:${i}`);
  const probes = 100_000;
  let fp = 0;
  for (let i = 0; i < probes; i++) if (f.has(`other:${i}`)) fp++;
  const measured = fp / probes, theory = f.expectedFpr();
  assert.ok(theory > 0.008 && theory < 0.0105, `theory ${theory}`);
  // ~1000 expected hits -> std dev ~3%; allow a generous 20% band.
  assert.ok(Math.abs(measured - theory) / theory < 0.2, `measured ${measured} vs theory ${theory}`);
});

test('FPR rises as predicted when overfilled', () => {
  const f = new BloomFilter({ expectedItems: 2000, falsePositiveRate: 0.01 });
  for (let i = 0; i < 8000; i++) f.add(`x${i}`);
  let fp = 0;
  for (let i = 0; i < 50_000; i++) if (f.has(`y${i}`)) fp++;
  const measured = fp / 50_000, theory = theoreticalFpr(f.m, f.k, 8000);
  assert.ok(theory > 0.3, 'overfilled filter should be bad');
  assert.ok(Math.abs(measured - theory) < 0.03, `measured ${measured} vs theory ${theory}`);
});

test('bit layout: explicit Uint8Array packing, k=1 sets exactly one bit', () => {
  const f = new BloomFilter({ bits: 64, hashes: 1 });
  assert.strictEqual(f.bits.length, 8);
  f.add('a');
  assert.strictEqual(f.popcount(), 1);
  const f2 = new BloomFilter({ bits: 13, hashes: 3 }); // non-multiple of 8
  assert.strictEqual(f2.bits.length, 2);

  assert.strictEqual(f2.bits[1] >>> 5, 0, 'bits beyond m must never be set');

test('accepts strings, numbers, bigints and buffers; rejects objects', () => {
  const f = new BloomFilter({ expectedItems: 100 });
  f.add('s'); f.add(42); f.add(7n); f.add(Buffer.from([1, 2, 3]));
  assert.ok(f.has('s') && f.has(42) && f.has(7n) && f.has(new Uint8Array([1, 2, 3])));

test('serialize/deserialize round-trips and validates', () => {
  const f = new BloomFilter({ expectedItems: 1000, falsePositiveRate: 0.02 });
  for (let i = 0; i < 1000; i++) f.add(`k${i}`);
  const buf = f.serialize();
  const g = BloomFilter.deserialize(buf);
  assert.strictEqual(g.m, f.m); assert.strictEqual(g.k, f.k); assert.strictEqual(g.count, f.count);
  assert.deepStrictEqual(Buffer.from(g.bits), Buffer.from(f.bits));
  for (let i = 0; i < 2000; i++) assert.strictEqual(g.has(`k${i}`), f.has(`k${i}`));
  assert.throws(() => BloomFilter.deserialize(buf.subarray(0, buf.length - 1)), /corrupt/);
  const bad = Buffer.from(buf); bad[0] ^= 0xff;
  assert.throws(() => BloomFilter.deserialize(bad), /magic/);
  assert.throws(() => BloomFilter.deserialize(Buffer.alloc(3)), /short/);
});

test('union equals filter built from both sets', () => {
  const a = new BloomFilter({ bits: 4096, hashes: 5 });
  const b = new BloomFilter({ bits: 4096, hashes: 5 });
  const both = new BloomFilter({ bits: 4096, hashes: 5 });
  for (let i = 0; i < 200; i++) { a.add(`a${i}`); both.add(`a${i}`); }
  for (let i = 0; i < 200; i++) { b.add(`b${i}`); both.add(`b${i}`); }
  assert.deepStrictEqual(Buffer.from(a.union(b).bits), Buffer.from(both.bits));
  assert.throws(() => a.union(new BloomFilter({ bits: 4096, hashes: 4 })), /identical/);
});

test('counting filter: remove restores absence without harming others', () => {
  const c = new CountingBloomFilter({ expectedItems: 1000, falsePositiveRate: 0.01 });
  for (let i = 0; i < 500; i++) c.add(`u${i}`);
  for (let i = 0; i < 250; i++) assert.ok(c.remove(`u${i}`));
  for (let i = 250; i < 500; i++) assert.ok(c.has(`u${i}`), `false negative on u${i}`);
  let stillThere = 0;
  for (let i = 0; i < 250; i++) if (c.has(`u${i}`)) stillThere++;
  assert.ok(stillThere < 10, `${stillThere} removed items still reported (should be ~FPR)`);
  assert.strictEqual(c.count, 250);
});

test('counting filter: duplicate adds need matching removes; absent removes refused', () => {
  const c = new CountingBloomFilter({ bits: 1000, hashes: 4 });
  c.add('dup'); c.add('dup');
  assert.ok(c.remove('dup'));
  assert.ok(c.has('dup'), 'one copy should remain');
  assert.ok(c.remove('dup'));
  assert.ok(!c.has('dup'));
  assert.strictEqual(c.remove('never-added'), false);
});

test('counting filter: 4-bit counters saturate and become sticky', () => {
  const c = new CountingBloomFilter({ bits: 16, hashes: 1 });
  for (let i = 0; i < 20; i++) c.add('hot');
  assert.ok(c.saturated >= 1);
  for (let i = 0; i < 20; i++) c.remove('hot');
  // Sticky counter: we lost the true value, so we must keep reporting "maybe".
  assert.ok(c.has('hot'));
});

test('counting filter collapses to an equivalent plain filter', () => {
  const c = new CountingBloomFilter({ expectedItems: 300 });
  for (let i = 0; i < 300; i++) c.add(`z${i}`);
  const plain = c.toBloomFilter();
  for (let i = 0; i < 1000; i++) assert.strictEqual(plain.has(`z${i}`), c.has(`z${i}`));
});
