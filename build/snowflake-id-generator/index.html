Snowflake 64-bit ID Generator

A BigInt Snowflake generator using the 41/10/12 layout. It supports a custom epoch, waits for the next millisecond when the sequence overflows, detects clock rollback with a configurable tolerance, and can decode an id back into its timestamp, worker and sequence.

Snowflake 64-bit ID Generator

This lab generates unique 64-bit ids at millions per second per process. The

ids sort roughly by creation time, and generating one needs no coordination

with other processes. Workers only need to agree on a worker id when they start.

Where it shows up

  • Primary keys for sharded databases: auto-increment only works on a single
    • primary, and random UUIDv4 keys fragment B-tree indexes. Time-ordered ids append to the right edge of the index.
  • Public object ids: tweets, Discord messages, Instagram media, Mastodon statuses.
  • Event and log ids: they sort by time without needing a separate timestamp
    • column, and you can pull the creation time back out of the id.
  • Cursor pagination: an id that is ordered by time works as a stable
    • cursor on its own (see the keyset-pagination lesson).

Layout

63 | 62 ....................................... 22 | 21 ...... 12 | 11 ...... 0
  0 |      41 bits: ms since custom epoch           | 10: worker   | 12: sequence
    |      2^41 ms ≈ 69.7 years                     | 1024 workers | 4096 ids/ms
id = (now - epoch) << 22 | workerId << 12 | sequence. The top bit stays 0, so

ids fit a signed int64 (Java long, Postgres BIGINT). Everything here is

BigInt, because JS Number is exact only up to 2^53. Demo step 6 shows a

real id losing its low bits. Send ids to clients as decimal strings. Twitter's

API added id_str for this reason.

Algorithm and invariants

now = clock()
if now < last:                              # clock went backwards
    if last - now > tolerance: throw ClockRollbackError
    spin until clock() >= last
if now == last:
    seq = (seq + 1) & 4095
    if seq == 0: spin until clock() > last  # 4096 ids already issued this ms
else:
    seq = 0
last = now
return compose(now, worker, seq)
  1. Unique per worker. For a fixed (timestamp, worker), the sequence
    2. values are distinct. The timestamp never goes backwards, because a rollback is either waited out or refused.
  2. Strictly increasing per worker. The timestamp is non-decreasing and the
    3. sequence increases within a millisecond.
  3. Unique globally, if worker ids are unique among live processes. This
    4. is the one piece of coordination the scheme needs. Worker ids are usually handed out by ZooKeeper or etcd leases, a DB table, or a Kubernetes StatefulSet ordinal.
  4. K-sorted across workers. Ids are ordered by millisecond. Within the same
    5. millisecond, the worker id breaks ties, not the true issue order (demo step 3). Clock skew between machines blurs ordering by that many milliseconds.
Custom epoch. A recent epoch gives you the full ~69.7 years going forward.

Counting from 1970 would run out in 2039 (demo step 5). Once chosen, the epoch

can never change, because every decoder needs it.

Clock rollback. NTP can step a clock backwards, and restoring a VM from a

snapshot can move it back by hours. Issuing ids with a past timestamp could

repeat (ts, seq) pairs that were already handed out. A small drift (at most

rollbackToleranceMs, default 5) is waited out. A larger drift throws ClockRollbackError, and the caller should fail over or alert. Twitter's

original implementation refused all rollbacks.

Complexity

  • nextId: O(1) amortized. In the worst case it spins for up to 1 ms when the
    • sequence overflows, or up to tolerance ms on a rollback.
  • decode / compose: O(1). Space: O(1) per generator.
  • Throughput ceiling: 4096 ids/ms per worker, about 4.1M/s. Across all 1024
    • workers that is about 4.2 billion ids/s.

Failure modes and trade-offs

  • Duplicate worker ids. Two processes sharing a worker id will collide
    • within the same millisecond. This is the most common real-world bug. Use leases that expire, and fence them.
  • Restart inside the same millisecond. A process that restarts and reuses
    • its worker id right away could reissue ids from its last millisecond. Keep a persisted high-water mark, or wait for at least one tolerance window on startup.
  • Busy-waiting. The spin burns CPU. An async generator could await the
    • next tick instead, at the cost of latency jitter.
  • Information leakage. Ids reveal creation time, which shard or worker
    • issued them, and roughly how many ids that worker issues. Don't expose them where that is sensitive.
  • Low traffic means sequence 0 most of the time. If you shard by
    • id % N, the shards will be badly skewed. Hash the id first.
  • Bit budget. More worker bits leave fewer sequence bits or less lifetime.
    • Choose the split for your fleet size and peak rate per worker.

How production systems do it

  • Twitter Snowflake (2010): a Scala Thrift service using this exact 41/10/12
    • split, where the 10 bits were 5 datacenter plus 5 worker. It used the epoch 1288834974657, claimed its configured worker id in ZooKeeper at startup, and refused to issue ids while the clock was behind the last timestamp.
  • Discord: 42-bit ms timestamp from epoch 2015-01-01, 5-bit worker, 5-bit
    • process, 12-bit increment. Anyone can decode message creation times from the ids.
  • Instagram: generates ids inside PostgreSQL with PL/pgSQL. The layout is
    • 41-bit ms, 13-bit logical shard id, and 10-bit per-shard sequence (nextval % 1024), so an id also encodes where its row lives.
  • Sonyflake: 39 bits of 10 ms units (about 174 years), 8-bit sequence and
    • 16-bit machine id. It trades throughput (256 ids per 10 ms) for lifetime and number of machines.
  • Baidu UidGenerator: seconds-resolution timestamp. Its CachedUidGenerator
    • pre-fills a ring buffer and "borrows" future seconds to absorb bursts.
  • UUIDv7 (RFC 9562, 2024): a 48-bit Unix-ms timestamp plus random bits in
    • 128 bits. It sorts by time like Snowflake but needs no worker id, at the cost of being twice as wide.

Extension exercises

  1. Add a lease-based worker id allocator. It claims workerId from a shared
    2. table with a TTL and renews it. What must the generator do if renewal fails?
  2. Persist a high-water mark (last ms) to a file in os.tmpdir() every
    3. second. On startup, refuse to issue ids until clock() > mark. Test it with a simulated restart.
  3. Make the layout configurable, for example Sonyflake's 39/8/16 with 10 ms
    4. ticks. Keep decode and compose consistent, and add a test that the lifetime is about 174 years.
  4. Implement "borrow the future": within the tolerance, keep issuing ids at
    5. lastMs instead of waiting. When is this safe, and what breaks if the process restarts before real time catches up?
  5. Write a UUIDv7 generator with a monotonic counter (RFC 9562 method 1) and
    6. compare index-insert locality against UUIDv4 in a simple sorted-array model.
snowflake.js 
'use strict';
/**
 * Snowflake 64-bit ID generator (Twitter layout).
 *
 *   bit 63      62 ........... 22  21 ...... 12  11 ...... 0
 *   [ 0 ]  [ 41-bit ms since epoch ][ 10-bit worker ][ 12-bit seq ]
 *
 * The sign bit is always 0, so ids fit in a signed int64 (Java long, Postgres
 * BIGINT). Ids from one worker strictly increase. Ids from different workers
 * are "k-sorted": they are ordered by millisecond, and only ids issued in the
 * same millisecond on different workers can be out of order.
 *
 * JavaScript numbers are only exact up to 2^53, and a real Snowflake id is
 * ~2^60, so everything is BigInt. Serialize ids as decimal strings in JSON.
 */

const TIMESTAMP_BITS = 41n;
const WORKER_BITS = 10n;
const SEQUENCE_BITS = 12n;

const MAX_WORKER = (1n << WORKER_BITS) - 1n;       // 1023
const MAX_SEQUENCE = (1n << SEQUENCE_BITS) - 1n;   // 4095
const MAX_TIMESTAMP = (1n << TIMESTAMP_BITS) - 1n; // ~69.7 years of ms
const WORKER_SHIFT = SEQUENCE_BITS;                // 12
const TIMESTAMP_SHIFT = SEQUENCE_BITS + WORKER_BITS; // 22

const TWITTER_EPOCH = 1288834974657; // 2010-11-04T01:42:54.657Z
const DEFAULT_EPOCH = Date.UTC(2020, 0, 1);

class ClockRollbackError extends Error {
  constructor(driftMs, toleranceMs) {
    super(`clock moved backwards by ${driftMs}ms (tolerance ${toleranceMs}ms); refusing to generate ids`);
    this.name = 'ClockRollbackError';
    this.driftMs = driftMs;
  }
}

function toEpochMs(epoch) {
  const ms = epoch instanceof Date ? epoch.getTime() : epoch;
  if (!Number.isSafeInteger(ms) || ms < 0) throw new RangeError('epoch must be a non-negative integer ms timestamp or a Date');
  return ms;
}

class SnowflakeGenerator {
  /**
   * @param {object} opts
   * @param {number} opts.workerId              0..1023, must be unique per live process
   * @param {number|Date} [opts.epoch]          custom epoch (default 2020-01-01T00:00:00Z)
   * @param {() => number} [opts.clock]         integer ms wall clock (default Date.now)
   * @param {number} [opts.rollbackToleranceMs] wait out backwards jumps up to this size (default 5)
   * @param {number} [opts.maxSpin]             safety cap on clock polls while waiting (default 1e7)
   */
  constructor({ workerId, epoch = DEFAULT_EPOCH, clock = Date.now, rollbackToleranceMs = 5, maxSpin = 1e7 } = {}) {
    if (!Number.isInteger(workerId) || workerId < 0 || BigInt(workerId) > MAX_WORKER) {
      throw new RangeError(`workerId must be an integer in [0, ${MAX_WORKER}]`);
    }
    if (!Number.isInteger(rollbackToleranceMs) || rollbackToleranceMs < 0) throw new RangeError('rollbackToleranceMs must be an integer >= 0');
    if (typeof clock !== 'function') throw new TypeError('clock must be a function');
    this.epoch = toEpochMs(epoch);
    this.workerId = BigInt(workerId);
    this.clock = clock;
    this.rollbackToleranceMs = rollbackToleranceMs;
    this.maxSpin = maxSpin;
    const now = this._now();
    if (now < this.epoch) throw new RangeError('epoch is in the future');
    this.lastMs = -1; // last timestamp used, in absolute ms
    this.sequence = 0n;
    this.stats = { issued: 0, sequenceOverflowWaits: 0, rollbacksWaited: 0, rollbacksRejected: 0 };
  }

  _now() {
    const t = this.clock();
    if (!Number.isSafeInteger(t)) throw new TypeError('clock() must return an integer number of ms');
    return t;
  }

  /** Poll the clock until it returns a value > ms. Busy-waits, like Twitter's tilNextMillis. */
  _waitUntilAfter(ms) {
    let t = this._now();
    for (let spins = 0; t <= ms; spins++) {
      if (spins >= this.maxSpin) throw new Error(`clock did not advance past ${ms} after ${this.maxSpin} polls`);
      t = this._now();
    }
    return t;
  }

  /** Returns the next id as a BigInt. */
  nextId() {
    let now = this._now();

    if (now < this.lastMs) {
      const drift = this.lastMs - now;
      if (drift > this.rollbackToleranceMs) {
        this.stats.rollbacksRejected++;
        throw new ClockRollbackError(drift, this.rollbackToleranceMs);
      }
      // Small step back (e.g. an NTP slew/step): wait for the clock to reach
      // lastMs again. Reusing lastMs with seq+1 would also be safe; waiting
      // keeps "timestamp in id ≈ real time".
      this.stats.rollbacksWaited++;
      now = this._waitUntilAfter(this.lastMs - 1);
    }

    if (now === this.lastMs) {
      this.sequence = (this.sequence + 1n) & MAX_SEQUENCE;
      if (this.sequence === 0n) {
        // 4096 ids already issued this millisecond: block until the next one.
        this.stats.sequenceOverflowWaits++;
        now = this._waitUntilAfter(this.lastMs);
      }
    } else {
      this.sequence = 0n;
    }

    const delta = BigInt(now - this.epoch);
    if (delta > MAX_TIMESTAMP) throw new RangeError('timestamp overflowed 41 bits: epoch exhausted (~69.7 years)');
    this.lastMs = now;
    this.stats.issued++;
    return (delta << TIMESTAMP_SHIFT) | (this.workerId << WORKER_SHIFT) | this.sequence;
  }

  /** Decimal string form; safe to put in JSON. */
  nextIdString() { return this.nextId().toString(); }

  /** Decode using this generator's epoch. */
  decode(id) { return decode(id, { epoch: this.epoch }); }
}

function toBigIntId(id) {
  let v;
  if (typeof id === 'bigint') v = id;
  else if (typeof id === 'string' && /^\d+$/.test(id)) v = BigInt(id);
  else if (typeof id === 'number') {
    // Accepting a Number would silently lose precision above 2^53.
    if (!Number.isSafeInteger(id)) throw new RangeError('numeric id exceeds 2^53; pass a BigInt or decimal string');
    v = BigInt(id);
  } else throw new TypeError('id must be a BigInt, decimal string or safe integer');
  if (v < 0n || v >= 1n << 63n) throw new RangeError('id must be in [0, 2^63)');
  return v;
}

/** Split an id into its fields. */
function decode(id, { epoch = DEFAULT_EPOCH } = {}) {
  const v = toBigIntId(id);
  const epochMs = toEpochMs(epoch);
  const deltaMs = Number(v >> TIMESTAMP_SHIFT);
  const timestampMs = epochMs + deltaMs;
  return {
    timestampMs,
    date: new Date(timestampMs),
    workerId: Number((v >> WORKER_SHIFT) & MAX_WORKER),
    sequence: Number(v & MAX_SEQUENCE),
  };
}

/** Build an id from its parts (useful for tests and for range scans). */
function compose({ timestampMs, workerId = 0, sequence = 0 }, { epoch = DEFAULT_EPOCH } = {}) {
  const delta = BigInt(timestampMs - toEpochMs(epoch));
  if (delta < 0n || delta > MAX_TIMESTAMP) throw new RangeError('timestamp outside the 41-bit window for this epoch');
  if (workerId < 0 || BigInt(workerId) > MAX_WORKER) throw new RangeError('workerId out of range');
  if (sequence < 0 || BigInt(sequence) > MAX_SEQUENCE) throw new RangeError('sequence out of range');
  return (delta << TIMESTAMP_SHIFT) | (BigInt(workerId) << WORKER_SHIFT) | BigInt(sequence);
}

/**
 * Smallest id that could be issued at or after `timestampMs`, by any worker.
 * Enables "WHERE id >= lowerBoundFor(t)" time-range queries on the primary key.
 */
function lowerBoundFor(timestampMs, opts) { return compose({ timestampMs, workerId: 0, sequence: 0 }, opts); }

module.exports = {
  SnowflakeGenerator, ClockRollbackError, decode, compose, lowerBoundFor,
  TWITTER_EPOCH, DEFAULT_EPOCH,
  LAYOUT: { TIMESTAMP_BITS: 41, WORKER_BITS: 10, SEQUENCE_BITS: 12, TIMESTAMP_SHIFT: 22, WORKER_SHIFT: 12 },
};
demo.js 
'use strict';
// Deterministic walkthrough using simulated clocks (no real waiting).
const { SnowflakeGenerator, decode, lowerBoundFor, TWITTER_EPOCH, DEFAULT_EPOCH } = require('./snowflake');

const line = (s = '') => console.log(s);
const T0 = Date.UTC(2026, 8, 30, 12, 0, 0); // 2026-09-30T12:00:00Z

/** A clock that advances 1 ms every `callsPerMs` reads (models a machine's throughput). */
function throughputClock(start, callsPerMs) {
  let calls = 0;
  const c = () => start + Math.floor(calls++ / callsPerMs);
  return c;
}

line('1) Bit layout');
const g = new SnowflakeGenerator({ workerId: 37, clock: () => T0 });
const id = g.nextId();
const bin = id.toString(2).padStart(64, '0');
line(`   id = ${id}`);
line(`   ${bin[0]} ${bin.slice(1, 42)} ${bin.slice(42, 52)} ${bin.slice(52)}`);
line('   ' + '^'.padEnd(2) + '^ 41-bit ms since epoch'.padEnd(42) + '^ worker'.padEnd(11) + '^ sequence');
line('   (the first ^ is the sign bit, always 0 so the id fits a signed int64)');
const d = g.decode(id);
line(`   decode -> ${d.date.toISOString()}, worker=${d.workerId}, seq=${d.sequence}`);
line();

line('2) Sequence overflow: a burst of 10,000 ids when the CPU could do ~10,000 clock reads/ms');
const burst = new SnowflakeGenerator({ workerId: 1, clock: throughputClock(T0, 10_000) });
const perMs = new Map();
let prev = -1n, monotonic = true;
for (let i = 0; i < 10_000; i++) {
  const x = burst.nextId();
  if (x <= prev) monotonic = false;
  prev = x;
  const ms = decode(x).timestampMs - T0;
  perMs.set(ms, (perMs.get(ms) || 0) + 1);
}
line(`   ids per ms: ${[...perMs].map(([ms, n]) => `+${ms}ms:${n}`).join('  ')}`);
line(`   overflow waits: ${burst.stats.sequenceOverflowWaits}; strictly increasing: ${monotonic}`);
line('   A 12-bit sequence caps a worker at 4096 ids/ms (~4.1M/s); the 4097th waits for the next ms.');
line();

line('3) Two workers: globally k-sorted, not strictly ordered');
let shared = T0;
const a = new SnowflakeGenerator({ workerId: 1, clock: () => shared });
const b = new SnowflakeGenerator({ workerId: 2, clock: () => shared });
const issued = [];
for (let step = 0; step < 6; step++) {
  issued.push({ who: 'B', id: b.nextId() });
  issued.push({ who: 'A', id: a.nextId() });
  if (step % 2 === 1) shared++;
}
const sorted = [...issued].sort((x, y) => (x.id < y.id ? -1 : 1));
line(`   issue order: ${issued.map((x) => x.who).join(' ')}`);
line(`   sorted by id: ${sorted.map((x) => x.who).join(' ')}   (within a ms, worker id decides)`);
line();

line('4) Clock rollback handling (tolerance 5 ms)');
let wall = T0;
let polls = 0;
const rb = new SnowflakeGenerator({
  workerId: 9, rollbackToleranceMs: 5,
  // Every clock read lets 0.5 ms of simulated time pass.
  clock: () => { polls++; const t = Math.floor(wall); wall += 0.5; return t; },
});
const first = rb.nextId();
wall -= 3; // NTP steps the clock back 3 ms
const before = polls;
const afterSmall = rb.nextId();
line(`   step back 3 ms  -> waited ${polls - before} clock polls until time caught up; ids still increasing: ${afterSmall > first}`);
wall -= 50; // big jump back: e.g. VM restored from snapshot
try { rb.nextId(); } catch (e) {
  line(`   step back 50 ms -> ${e.name}: ${e.message}`);
}
line('   Refusing is the safe choice: issuing ids in the past risks duplicates with ids already handed out.');
line();

line('5) Custom epoch: how long 41 bits of milliseconds last');
for (const [name, ep] of [['Unix 1970', 0], ['Twitter 2010-11-04', TWITTER_EPOCH], ['default 2020-01-01', DEFAULT_EPOCH]]) {
  const end = new Date(ep + 2 ** 41 - 1);
  line(`   ${name.padEnd(20)} -> ids run out at ${end.toISOString()}`);
}
line();

line('6) Why BigInt and string serialization matter');
const bigGen = new SnowflakeGenerator({ workerId: 1023, clock: () => T0 });
bigGen.nextId();
const big = bigGen.nextId(); // sequence 1 -> low bit set
line(`   BigInt id       : ${big}`);
line(`   as JS Number    : ${Number(big)}  <- ${BigInt(Number(big)) === big ? 'exact' : 'precision lost above 2^53'}`);
line(`   JSON-safe string: "${big.toString()}" (Twitter's API added "id_str" for exactly this reason)`);
line();

line('7) Time-range queries on the primary key');
const lo = lowerBoundFor(T0), hi = lowerBoundFor(T0 + 60_000);
line(`   "created in the first minute after 12:00" == WHERE id >= ${lo} AND id < ${hi}`);
test.js 
'use strict';
const assert = require('node:assert');
const {
  SnowflakeGenerator, ClockRollbackError, decode, compose, lowerBoundFor, TWITTER_EPOCH, DEFAULT_EPOCH,
} = require('./snowflake');

let failed = 0;
function test(name, fn) {
  try { fn(); console.log(`✓ ${name}`); }
  catch (e) { failed++; console.log(`✗ ${name}\n  ${e.stack}`); }
}

const T0 = Date.UTC(2026, 0, 1);

/** Returns `start` for the first `perMs` reads, then start+1, and so on. */
function steppingClock(start, perMs) {
  let n = 0;
  return () => start + Math.floor(n++ / perMs);
}

test('bit layout: 41/10/12 fields at shifts 22 and 12', () => {
  const epoch = T0;
  const g = new SnowflakeGenerator({ workerId: 1, epoch, clock: () => epoch + 1 });
  assert.strictEqual(g.nextId(), (1n << 22n) | (1n << 12n) | 0n);
  assert.strictEqual(g.nextId(), (1n << 22n) | (1n << 12n) | 1n);
  const max = compose({ timestampMs: epoch + 2 ** 41 - 1, workerId: 1023, sequence: 4095 }, { epoch });
  assert.strictEqual(max, (1n << 63n) - 1n, 'all 63 payload bits set, sign bit clear');
});

test('decode inverts compose', () => {
  for (const [ts, w, s] of [[T0, 0, 0], [T0 + 123456789, 513, 4095], [T0 + 7, 1023, 1]]) {
    const id = compose({ timestampMs: ts, workerId: w, sequence: s });
    assert.deepStrictEqual((({ timestampMs, workerId, sequence }) => [timestampMs, workerId, sequence])(decode(id)), [ts, w, s]);
  }
});

test('Twitter epoch: id >> 22 is milliseconds since 2010-11-04T01:42:54.657Z', () => {
  assert.strictEqual(new Date(TWITTER_EPOCH).toISOString(), '2010-11-04T01:42:54.657Z');
  const ts = Date.UTC(2019, 11, 31, 19, 26, 16, 771);
  const g = new SnowflakeGenerator({ workerId: 0, epoch: TWITTER_EPOCH, clock: () => ts });
  const id = g.nextId();
  assert.strictEqual(id, BigInt(ts - TWITTER_EPOCH) << 22n);
  assert.strictEqual(decode(id.toString(), { epoch: TWITTER_EPOCH }).date.toISOString(), '2019-12-31T19:26:16.771Z');
});

test('ids from one worker are unique and strictly increasing', () => {
  const g = new SnowflakeGenerator({ workerId: 5, clock: steppingClock(T0, 3) });
  let prev = -1n;
  const seen = new Set();
  for (let i = 0; i < 50_000; i++) {
    const id = g.nextId();
    assert.ok(id > prev);
    seen.add(id);
    prev = id;
  }
  assert.strictEqual(seen.size, 50_000);
});

test('sequence overflow waits for the next millisecond', () => {
  // Clock stays on T0 for 10k reads: only 4096 ids fit, the 4097th must roll to T0+1.
  const g = new SnowflakeGenerator({ workerId: 0, clock: steppingClock(T0, 10_000) });
  const ids = Array.from({ length: 4097 }, () => g.nextId());
  const last = decode(ids[4095]), next = decode(ids[4096]);
  assert.strictEqual(last.timestampMs, T0);
  assert.strictEqual(last.sequence, 4095);
  assert.strictEqual(next.timestampMs, T0 + 1);
  assert.strictEqual(next.sequence, 0);
  assert.strictEqual(g.stats.sequenceOverflowWaits, 1);
});

test('sequence resets to 0 when the millisecond changes', () => {
  let t = T0;
  const g = new SnowflakeGenerator({ workerId: 0, clock: () => t });
  g.nextId(); g.nextId();
  t += 1;
  assert.strictEqual(decode(g.nextId()).sequence, 0);
});

test('small clock rollback (within tolerance) is waited out; ids stay increasing', () => {
  let t = T0 + 100;
  let reads = 0;
  const g = new SnowflakeGenerator({ workerId: 3, rollbackToleranceMs: 5, clock: () => { reads++; return t; } });
  const a = g.nextId();
  t -= 4;
  // Simulate time passing while the generator polls.
  const orig = g.clock;
  g.clock = () => { const v = orig(); t += 1; return v; };
  const b = g.nextId();
  assert.ok(b > a);
  assert.ok(decode(b).timestampMs >= decode(a).timestampMs);
  assert.strictEqual(g.stats.rollbacksWaited, 1);
});

test('rollback exactly at tolerance waits; one beyond throws ClockRollbackError', () => {
  let t = T0 + 100;
  const g = new SnowflakeGenerator({ workerId: 3, rollbackToleranceMs: 5, clock: () => t });
  g.nextId();
  t = T0 + 95; // exactly 5 ms back: tolerated, waits while time advances
  const orig = g.clock;
  g.clock = () => { const v = orig(); if (t < T0 + 100) t += 1; return v; };
  assert.strictEqual(decode(g.nextId()).timestampMs, T0 + 100);
  assert.strictEqual(g.stats.rollbacksWaited, 1);
  g.clock = orig;
  t = T0 + 94; // 6 ms back
  assert.throws(() => g.nextId(), (e) => e instanceof ClockRollbackError && e.driftMs === 6);
  assert.strictEqual(g.stats.rollbacksRejected, 1);
  const g2 = new SnowflakeGenerator({ workerId: 3, rollbackToleranceMs: 0, clock: () => t });
  t = T0 + 100; g2.nextId();
  t = T0 + 99;
  assert.throws(() => g2.nextId(), ClockRollbackError, 'tolerance 0 rejects any rollback');
});

test('a clock that never advances surfaces an error instead of hanging', () => {
  const g = new SnowflakeGenerator({ workerId: 0, clock: () => T0, maxSpin: 1000 });
  for (let i = 0; i < 4096; i++) g.nextId();
  assert.throws(() => g.nextId(), /did not advance/);
});

test('different workers never collide within the same millisecond', () => {
  const t = T0;
  const all = new Set();
  for (let w = 0; w < 8; w++) {
    const g = new SnowflakeGenerator({ workerId: w * 127, clock: () => t });
    for (let i = 0; i < 500; i++) all.add(g.nextId());
  }
  assert.strictEqual(all.size, 8 * 500);
});

test('custom epoch: Date or ms accepted; future epoch rejected; decode honors epoch', () => {
  const epoch = new Date('2024-01-01T00:00:00Z');
  const g = new SnowflakeGenerator({ workerId: 1, epoch, clock: () => epoch.getTime() + 1000 });
  const id = g.nextId();
  assert.strictEqual(id >> 22n, 1000n);
  assert.strictEqual(g.decode(id).date.toISOString(), '2024-01-01T00:00:01.000Z');
  assert.strictEqual(decode(id, { epoch }).timestampMs, epoch.getTime() + 1000);
  assert.throws(() => new SnowflakeGenerator({ workerId: 1, epoch: T0 + 10, clock: () => T0 }), /future/);
});

test('41-bit timestamp exhaustion is detected', () => {
  const epoch = 0;
  const g = new SnowflakeGenerator({ workerId: 1, epoch, clock: () => 2 ** 41 });
  assert.throws(() => g.nextId(), /41 bits/);
  assert.strictEqual(new Date(DEFAULT_EPOCH + 2 ** 41 - 1).getUTCFullYear(), 2089);
});

test('input validation', () => {
  assert.throws(() => new SnowflakeGenerator({ workerId: 1024 }), RangeError);
  assert.throws(() => new SnowflakeGenerator({ workerId: -1 }), RangeError);
  assert.throws(() => new SnowflakeGenerator({ workerId: 1.5 }), RangeError);
  assert.throws(() => new SnowflakeGenerator({}), RangeError);
  assert.throws(() => new SnowflakeGenerator({ workerId: 1, clock: () => 1.5 }), TypeError);
  assert.throws(() => decode(2 ** 60), /2\^53/, 'unsafe Number ids must be rejected');
  assert.throws(() => decode('-5'), TypeError);
  assert.throws(() => decode(1n << 63n), RangeError);
  assert.throws(() => compose({ timestampMs: T0, sequence: 4096 }), RangeError);
});

test('lowerBoundFor enables time-range scans over ids', () => {
  let t = T0;
  const g = new SnowflakeGenerator({ workerId: 1023, clock: () => t });
  const early = g.nextId();
  t += 10;
  const mid = g.nextId();
  t += 10;
  const late = g.nextId();
  const lo = lowerBoundFor(T0 + 5), hi = lowerBoundFor(T0 + 15);
  assert.ok(!(early >= lo && early < hi));
  assert.ok(mid >= lo && mid < hi);
  assert.ok(!(late >= lo && late < hi));
});
