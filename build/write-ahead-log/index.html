Write-Ahead Log (WAL) & Crash Recovery

The problem

A process can die between any two instructions: power loss, OOM kill, a kernel panic. A

store that updates its data structures in place can be caught half-way, with a B-tree page

split done but not linked, or money debited but not credited. The write-ahead rule fixes

this: **describe the change in an append-only log, make that log durable, and only then

acknowledge the change or apply it anywhere else.** After a crash, replaying the log rebuilds

the state.

Where it shows up: PostgreSQL WAL, MySQL/InnoDB redo log, SQLite -wal mode, RocksDB/LevelDB

.log, etcd and every Raft implementation (the replicated log is* a WAL), Kafka log

segments, ZooKeeper transaction logs, and filesystem journals (ext4/jbd2, NTFS $LogFile).

What this build does

wal.js has two layers:
  • WriteAheadLog: segmented binary log. append() buffers a record and assigns an LSN,
    • flush() writes the buffer with one write() and one fsync(), roll() starts a new segment, truncateBefore(lsn) deletes whole covered segments, open() scans and repairs.
  • DurableKV: a Map-backed store on top. put / del / batch resolve with the LSN after
    • fsync. checkpoint() writes a snapshot and truncates the log.

Record format (17-byte header, little-endian)

0        4        8                16   17
 +--------+--------+----------------+----+------------------+
 | len u32| crc u32|    lsn u64     |type| payload (len B)  |
 +--------+--------+----------------+----+------------------+
            crc32 covers  [lsn .. end of payload]
  • len lets the reader find the next record, and it is sanity-checked (maxRecordBytes) so a
    • corrupt length cannot make the reader allocate 4 GB or skip into garbage.
  • crc (CRC-32/IEEE, implemented in crc32Js, with zlib.crc32 used when the runtime has
    • it) catches torn and bit-flipped records. The test checks the standard value crc32("123456789") = 0xCBF43926 and that the JS and zlib versions agree.
  • lsn must go up by exactly one, and each segment is named after its first LSN
    • (wal-00000000000000000001.log). A gap means a record went missing, and that counts as corruption even when every CRC checks out.
  • A write batch is one record, so a multi-key update is atomic: its CRC either verifies
    • or the whole batch is gone. RocksDB's WriteBatch works the same way.

Invariants

  1. A write is acknowledged (its promise resolves) only after the fsync covering its record returns.
  2. A write becomes visible to get() only once it is durable, so readers never see data a crash could take back.
  3. Recovery replays a prefix of the log. It stops at the first invalid record (torn
    4. header, torn payload, bad length, CRC mismatch, LSN gap) and truncates the file there, so later appends never land after garbage.
  4. The checkpoint order is **roll, then write the snapshot (tmp + fsync + rename + dir fsync),
    5. then delete segments**. A crash between any two steps leaves either the old snapshot with the full log, or the new snapshot with redundant segments that are skipped by LSN.

Recovery modes (for corruption that is not at the tail)

modebad tail of last segmentcorruption in an earlier segment
tolerate-tail (default)truncatethrow WalCorruptionError (operator decides)
point-in-timetruncatecut there and delete all later segments
A torn tail is the normal result of a crash. Corruption in the middle of the log means the

disk or a bug is at fault. Throwing forces someone to look instead of quietly losing

acknowledged data.

Group commit

With sync: 'group', every batch issued in the same event-loop tick (up to

groupMaxRecords) shares one write and one fsync. The demo shows 200 concurrent writers

needing 200 fsyncs with always and 4 with group. Latency per write goes up by at most

one tick, and throughput goes up by roughly the batch size. PostgreSQL (commit_delay),

InnoDB and the binlog all use the same trick.

Complexity

  • Append: O(record size) to encode, plus a buffer copy. The fsync is the real cost: roughly
    • 0.05–10 ms depending on the device, which is why group commit matters.
  • Recovery: O(log bytes since the last checkpoint), one sequential read of each segment.
  • Checkpoint: O(state size) to serialise, which bounds replay time and disk usage.
  • Space: live state + snapshot + log since the last checkpoint.

Failure modes & trade-offs

  • fsync lies: some consumer disks and VMs acknowledge a flush that is still sitting in a
    • volatile cache. No software fix exists. Use enterprise drives with power-loss protection.
  • fsync errors are fatal (the 2018 "fsyncgate" issue in PostgreSQL): after a failed fsync,
    • Linux may drop the dirty pages and a retry can "succeed" without the data. Here a flush error rejects every waiter. A real database would crash and recover from the log.
  • Directory fsync: creating, renaming or unlinking a segment is durable only once the
    • directory is fsynced. fsyncDir does that on POSIX and is a no-op on Windows, where it is not supported.
  • CRC32 is not cryptographic. It detects accidental damage, not tampering. CRC-32C is
    • what RocksDB, ext4 and iSCSI use, because CPUs have an instruction for it. IEEE CRC-32 is used here so zlib can cross-check it.
  • Stopping at the first bad record can throw away later records that are still valid.
    • Skipping over a hole would replay history out of order, which is worse.
  • Snapshots here are full JSON dumps. Real engines checkpoint incrementally (dirty pages
    • in PostgreSQL, SSTable flushes in RocksDB) rather than rewriting all state.
  • One JSON record per batch keeps the code simple. Binary op encoding would be smaller.

How production systems do it

  • PostgreSQL: 16 MB WAL segments. Each record header carries total length, a pointer to
    • the previous record, and a CRC-32C. synchronous_commit chooses when a commit waits for the flush. A checkpoint records a REDO point and old segments are recycled. full_page_writes guards against torn data pages, which a WAL alone cannot repair.
  • RocksDB: 32 KB blocks. Each physical record has a checksum, a length and a type
    • (FULL/FIRST/MIDDLE/LAST) so large batches can span blocks. WALRecoveryMode offers kTolerateCorruptedTailRecords, kAbsoluteConsistency, kPointInTimeRecovery (the default) and kSkipAnyCorruptedRecords. A WAL file becomes obsolete once its memtable is flushed to an SSTable.
  • SQLite WAL mode: frames carry cumulative checksums and a salt. Recovery keeps frames up to
    • the last valid commit frame. A checkpoint copies pages back into the main database file.
  • etcd: 64 MB segment files with a CRC per record, chained across records. wal.Repair
    • truncates a torn tail, and snapshots let old segments be released.
  • Kafka: log segments with a CRC per record batch. After an unclean shutdown the broker
    • re-validates segments and truncates at the first invalid batch. By default it relies on replication rather than per-message fsync (flush.messages).
  • InnoDB: innodb_flush_log_at_trx_commit = 1 (fsync at commit), 2 (write at commit,
    • fsync once a second) or 0. This is the durability-versus-throughput knob in one setting.

Extension exercises

  1. Switch to CRC-32C (Castagnoli, polynomial 0x82F63B78) and add RocksDB-style masking
    2. so the CRC of a record that contains CRCs is not trivially related to them.
  2. Add block framing (32 KB blocks, FIRST/MIDDLE/LAST fragments). After a corrupt length,
    3. the reader can then resync at the next block boundary instead of losing the rest of the segment.
  3. Add a time window to group commit (for example, wait up to 2 ms or 64 records) and
    4. measure p50/p99 latency against throughput.
  4. Write a fault-injecting fs shim that fails or short-writes the Nth write/fsync, and
    5. prove that no acknowledged write is ever lost.
  5. Make checkpoints fuzzy: take the snapshot while writes continue, recording the LSN at
    6. which it started, as ARIES and PostgreSQL do.
wal.js 
'use strict';
/**
 * Write-ahead log + durable key/value store.
 *
 * On-disk layout (one directory):
 *   wal-00000000000000000001.log   log segments, named by the first LSN they hold
 *   snapshot.json                  latest checkpoint {lsn, crc, data}
 *
 * Record framing (little-endian, 17-byte header):
 *   off  size  field
 *   0    4     payloadLen  (u32)
 *   4    4     crc32       (u32, IEEE) over bytes [8 .. 17+payloadLen) = lsn|type|payload
 *   8    8     lsn         (u64)
 *   16   1     type        (1 = BATCH)
 *   17   n     payload     (UTF-8 JSON array of ops)
 *
 * A write batch is ONE record, so it is atomic: either its CRC verifies and all
 * of its ops are replayed, or it is discarded as part of a torn tail.
 */
const fs = require('fs');
const path = require('path');
const zlib = require('zlib');

// ---------------------------------------------------------------- CRC32 ----
// Table-driven CRC-32 (reflected polynomial 0xEDB88320, as in zlib/PNG/Ethernet).
const CRC_TABLE = (() => {
  const t = new Uint32Array(256);
  for (let n = 0; n < 256; n++) {
    let c = n;
    for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
    t[n] = c >>> 0;
  }
  return t;
})();

function crc32Js(buf) {
  let c = 0xffffffff;
  for (let i = 0; i < buf.length; i++) c = CRC_TABLE[(c ^ buf[i]) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}
// zlib.crc32 exists from Node 20.15 / 22.2; use it when present (same algorithm).
const crc32 = typeof zlib.crc32 === 'function' ? (b) => zlib.crc32(b) >>> 0 : crc32Js;

// ------------------------------------------------------------- framing ----
const HEADER = 17;
const TYPE_BATCH = 1;
const DEFAULT_MAX_RECORD = 1 << 20; // 1 MiB: larger length fields are treated as corruption

function encodeRecord(lsn, type, payload) {
  const buf = Buffer.alloc(HEADER + payload.length);
  buf.writeUInt32LE(payload.length, 0);
  buf.writeBigUInt64LE(BigInt(lsn), 8);
  buf.writeUInt8(type, 16);
  payload.copy(buf, HEADER);
  buf.writeUInt32LE(crc32(buf.subarray(8)), 4);
  return buf;
}

/**
 * Decode records from a segment buffer. Stops at the FIRST invalid record and
 * reports where valid data ends; it never tries to "skip over" garbage, because
 * after a bad length field every later byte boundary is a guess.
 */
function decodeSegment(buf, firstLsn, maxRecord = DEFAULT_MAX_RECORD) {
  const records = [];
  let off = 0;
  let expect = firstLsn;
  while (off < buf.length) {
    const rest = buf.length - off;
    if (rest < HEADER) return { records, validBytes: off, error: 'torn-header' };
    const len = buf.readUInt32LE(off);
    if (len > maxRecord) return { records, validBytes: off, error: 'bad-length' };
    if (rest < HEADER + len) return { records, validBytes: off, error: 'torn-payload' };
    const body = buf.subarray(off + 8, off + HEADER + len);
    if (crc32(body) !== buf.readUInt32LE(off + 4)) return { records, validBytes: off, error: 'crc-mismatch' };
    const lsn = Number(buf.readBigUInt64LE(off + 8));
    if (lsn !== expect) return { records, validBytes: off, error: 'lsn-gap' };
    records.push({ lsn, type: buf.readUInt8(off + 16), payload: buf.subarray(off + HEADER, off + HEADER + len) });
    off += HEADER + len;
    expect++;
  }
  return { records, validBytes: off, error: null };
}

class WalCorruptionError extends Error {}

const segName = (lsn) => `wal-${String(lsn).padStart(20, '0')}.log`;
const SEG_RE = /^wal-(\d{20})\.log$/;

function fsyncDir(dir) {
  // Makes creates/renames/unlinks durable on POSIX. Windows cannot open a
  // directory for fsync, so this is best-effort there.
  let fd;
  try { fd = fs.openSync(dir, 'r'); fs.fsyncSync(fd); } catch (_) { /* unsupported */ } finally { if (fd !== undefined) fs.closeSync(fd); }
}

// ----------------------------------------------------------------- WAL ----
class WriteAheadLog {
  /**
   * @param {string} dir
   * @param {object} [opts]
   * @param {'tolerate-tail'|'point-in-time'} [opts.recoveryMode] what to do with
   *   corruption in a NON-final segment: throw (tolerate-tail) or cut the log
   *   there and drop everything after it (point-in-time). A bad tail of the
   *   final segment is always truncated: that is what an interrupted write looks like.
   * @param {number} [opts.segmentBytes] roll to a new segment past this size
   */
  constructor(dir, opts = {}) {
    if (typeof dir !== 'string' || !dir) throw new TypeError('dir must be a non-empty string');
    this.dir = dir;
    this.recoveryMode = opts.recoveryMode || 'tolerate-tail';
    if (!['tolerate-tail', 'point-in-time'].includes(this.recoveryMode)) throw new RangeError('bad recoveryMode');
    this.segmentBytes = opts.segmentBytes || 4 << 20;
    this.maxRecord = opts.maxRecordBytes || DEFAULT_MAX_RECORD;
    this.fd = null;
    this.segments = []; // [{startLsn, file}]
    this.activeSize = 0;
    this.pending = []; // encoded, not yet written
    this.nextLsn = 1;
    this.durableLsn = 0;
    this.stats = { fsyncs: 0, bytesWritten: 0 };
  }

  _listSegments() {
    return fs.readdirSync(this.dir)
      .map((f) => SEG_RE.exec(f))
      .filter(Boolean)
      .map((m) => ({ startLsn: Number(m[1]), file: path.join(this.dir, m[0]) }))
      .sort((a, b) => a.startLsn - b.startLsn);
  }

  /** Scan, validate and repair the log. Returns every valid record with lsn >= minLsn. */
  open({ minLsn = 1 } = {}) {
    fs.mkdirSync(this.dir, { recursive: true });
    const segs = this._listSegments();
    const report = { records: [], truncated: null, removedSegments: [] };
    let expect = segs.length ? segs[0].startLsn : minLsn;
    if (segs.length && segs[0].startLsn > minLsn) {
      throw new WalCorruptionError(`log starts at LSN ${segs[0].startLsn} but LSN ${minLsn} is needed`);
    }
    for (let i = 0; i < segs.length; i++) {
      const seg = segs[i];
      const isLast = i === segs.length - 1;
      if (seg.startLsn !== expect) {
        throw new WalCorruptionError(`segment ${path.basename(seg.file)} starts at ${seg.startLsn}, expected ${expect}`);
      }
      const buf = fs.readFileSync(seg.file);
      const res = decodeSegment(buf, seg.startLsn, this.maxRecord);
      for (const r of res.records) if (r.lsn >= minLsn) report.records.push(r);
      expect = seg.startLsn + res.records.length;
      if (!res.error) continue;
      if (!isLast && this.recoveryMode === 'tolerate-tail') {
        throw new WalCorruptionError(`${res.error} at ${path.basename(seg.file)}:${res.validBytes} (not at the tail)`);
      }
      // Cut the log here: truncate this segment, delete any later ones.
      fs.truncateSync(seg.file, res.validBytes);
      report.truncated = { segment: path.basename(seg.file), offset: res.validBytes, droppedBytes: buf.length - res.validBytes, reason: res.error };
      for (const later of segs.slice(i + 1)) { fs.unlinkSync(later.file); report.removedSegments.push(path.basename(later.file)); }
      segs.length = i + 1;
      fsyncDir(this.dir);
      break;
    }
    if (expect < minLsn) {
      // Every surviving record is already covered by the snapshot: discard the
      // old segments so the chain restarts cleanly at minLsn without a gap.
      for (const s of segs) { fs.unlinkSync(s.file); report.removedSegments.push(path.basename(s.file)); }
      segs.length = 0;
      expect = minLsn;
    }
    this.nextLsn = expect;
    this.durableLsn = this.nextLsn - 1;
    this.segments = segs;
    const last = segs[segs.length - 1];
    if (last) {
      this.fd = fs.openSync(last.file, 'a');
      this.activeSize = fs.fstatSync(this.fd).size;
    } else {
      this._startSegment(this.nextLsn);
    }
    return report;
  }

  _startSegment(startLsn) {
    if (this.fd !== null) fs.closeSync(this.fd);
    const file = path.join(this.dir, segName(startLsn));
    this.fd = fs.openSync(file, 'a');
    this.segments.push({ startLsn, file });
    this.activeSize = 0;
    fsyncDir(this.dir);
  }

  /** Buffer a record in memory and assign its LSN. Not durable until flush(). */
  append(type, payload) {
    if (this.fd === null) throw new Error('log is not open');
    if (!Buffer.isBuffer(payload)) throw new TypeError('payload must be a Buffer');
    if (payload.length > this.maxRecord) throw new RangeError(`record of ${payload.length} bytes exceeds maxRecordBytes`);
    const lsn = this.nextLsn++;
    this.pending.push(encodeRecord(lsn, type, payload));
    return lsn;
  }

  /** Write all buffered records with one write() and one fsync(). Returns durable LSN. */
  flush() {
    if (!this.pending.length) return this.durableLsn;
    const buf = Buffer.concat(this.pending);
    const count = this.pending.length;
    this.pending = [];
    fs.writeSync(this.fd, buf);
    fs.fsyncSync(this.fd); // the durability point: nothing is acknowledged before this returns
    this.stats.fsyncs++;
    this.stats.bytesWritten += buf.length;
    this.activeSize += buf.length;
    this.durableLsn += count;
    if (this.activeSize >= this.segmentBytes) this._startSegment(this.nextLsn);
    return this.durableLsn;
  }

  /** Close the active segment and start a new one at nextLsn (flushes first). */
  roll() {
    this.flush();
    const active = this.segments[this.segments.length - 1];
    if (active.startLsn !== this.nextLsn) this._startSegment(this.nextLsn);
  }

  /** Delete whole segments whose records are all < lsn. The active segment is never deleted. */
  truncateBefore(lsn) {
    const removed = [];
    while (this.segments.length > 1 && this.segments[1].startLsn <= lsn) {
      const seg = this.segments.shift();
      fs.unlinkSync(seg.file);
      removed.push(path.basename(seg.file));
    }
    if (removed.length) fsyncDir(this.dir);
    return removed;
  }

  close() { this.flush(); this._drop(); }
  /** Close without flushing: buffered records are lost, exactly as in a crash. */
  _drop() { if (this.fd !== null) fs.closeSync(this.fd); this.fd = null; this.pending = []; }
}

// ---------------------------------------------------------- DurableKV ----
class DurableKV {
  /**
   * @param {string} dir
   * @param {object} [opts] sync: 'always' (fsync per write) | 'group' (coalesce
   *   writes issued in the same tick, or up to groupMaxRecords, into one fsync)
   */
  constructor(dir, opts = {}) {
    this.sync = opts.sync || 'always';
    if (!['always', 'group'].includes(this.sync)) throw new RangeError("sync must be 'always' or 'group'");
    this.groupMaxRecords = opts.groupMaxRecords || 128;
    this.dir = dir;
    this.snapshotFile = path.join(dir, 'snapshot.json');
    this.wal = new WriteAheadLog(dir, opts);
    this.data = new Map();
    this.waiters = []; // [{lsn, ops, resolve, reject}] awaiting fsync
    this.flushScheduled = false;
    this.lastCheckpointLsn = 0;
  }

  /** Load the checkpoint, replay the log tail, repair torn writes. */
  open() {
    fs.mkdirSync(this.dir, { recursive: true });
    let snapLsn = 0;
    if (fs.existsSync(this.snapshotFile)) {
      const snap = JSON.parse(fs.readFileSync(this.snapshotFile, 'utf8'));
      const body = Buffer.from(JSON.stringify({ lsn: snap.lsn, data: snap.data }));
      if (crc32(body) !== snap.crc) throw new WalCorruptionError('snapshot checksum mismatch');
      this.data = new Map(snap.data);
      snapLsn = snap.lsn;
    }
    this.lastCheckpointLsn = snapLsn;
    const rep = this.wal.open({ minLsn: snapLsn + 1 });
    for (const r of rep.records) if (r.type === TYPE_BATCH) this._apply(JSON.parse(r.payload.toString('utf8')));
    return { snapshotLsn: snapLsn, replayed: rep.records.length, lastLsn: this.wal.durableLsn, truncated: rep.truncated, removedSegments: rep.removedSegments };
  }

  static _validate(ops) {
    if (!Array.isArray(ops) || ops.length === 0) throw new TypeError('ops must be a non-empty array');
    for (const op of ops) {
      if (!op || (op.op !== 'put' && op.op !== 'del')) throw new TypeError("op must be 'put' or 'del'");
      if (typeof op.key !== 'string' || !op.key) throw new TypeError('key must be a non-empty string');
      if (op.op === 'put' && op.value === undefined) throw new TypeError('put needs a value');
    }
  }

  _apply(ops) { for (const o of ops) o.op === 'put' ? this.data.set(o.key, o.value) : this.data.delete(o.key); }

  /**
   * Atomically log a batch. Resolves with its LSN once it is fsynced; only then
   * does it become visible to get() (readers never see data a crash could lose).
   */
  batch(ops) {
    DurableKV._validate(ops);
    const norm = ops.map((o) => (o.op === 'put' ? { op: 'put', key: o.key, value: o.value } : { op: 'del', key: o.key }));
    const lsn = this.wal.append(TYPE_BATCH, Buffer.from(JSON.stringify(norm), 'utf8'));
    return new Promise((resolve, reject) => {
      this.waiters.push({ lsn, ops: norm, resolve, reject });
      if (this.sync === 'always' || this.waiters.length >= this.groupMaxRecords) this._flush();
      else if (!this.flushScheduled) { this.flushScheduled = true; setImmediate(() => this._flush()); }
    });
  }
  put(key, value) { return this.batch([{ op: 'put', key, value }]); }
  del(key) { return this.batch([{ op: 'del', key }]); }
  get(key) { return this.data.get(key); }
  get size() { return this.data.size; }

  _flush() {
    this.flushScheduled = false;
    if (!this.waiters.length) return;
    const ws = this.waiters;
    this.waiters = [];
    try { this.wal.flush(); } catch (err) { ws.forEach((w) => w.reject(err)); return; }
    for (const w of ws) { this._apply(w.ops); w.resolve(w.lsn); }
  }

  /**
   * Checkpoint: roll the log, persist a snapshot atomically (tmp + fsync + rename),
   * then delete segments the snapshot covers. A crash between any two steps is safe:
   * old snapshot + old segments, or new snapshot + redundant segments (skipped by LSN).
   */
  checkpoint() {
    this._flush();
    this.wal.roll();
    const lsn = this.wal.durableLsn;
    const data = [...this.data];
    const crc = crc32(Buffer.from(JSON.stringify({ lsn, data })));
    const tmp = this.snapshotFile + '.tmp';
    const fd = fs.openSync(tmp, 'w');
    try { fs.writeSync(fd, JSON.stringify({ lsn, crc, data })); fs.fsyncSync(fd); } finally { fs.closeSync(fd); }
    fs.renameSync(tmp, this.snapshotFile);
    fsyncDir(this.dir);
    this.lastCheckpointLsn = lsn;
    return { lsn, removedSegments: this.wal.truncateBefore(lsn + 1) };
  }

  async close() { this._flush(); this.wal.close(); }

  /** Test hook: die now. Unflushed group-commit writes are lost and their promises reject. */
  simulateCrash() {
    const ws = this.waiters;
    this.waiters = [];
    this.wal._drop();
    ws.forEach((w) => w.reject(new Error('crashed before fsync')));
  }
}

'use strict';
// Walkthrough: durable writes, a torn write at crash time, recovery, group commit, checkpoint.
const fs = require('fs');
const os = require('os');
const path = require('path');
const { DurableKV, segName, encodeRecord, TYPE_BATCH, HEADER } = require('./wal');

const dir = fs.mkdtempSync(path.join(os.tmpdir(), 'wal-demo-'));
const logFiles = () => fs.readdirSync(dir).filter((f) => f.endsWith('.log')).map((f) => `${f} (${fs.statSync(path.join(dir, f)).size} B)`).join(', ');

(async () => {
  try {
    console.log(`WAL directory: ${dir}\n`);

    console.log('1) Durable writes (sync=always: one fsync per acknowledged write)');
    let kv = new DurableKV(dir);
    kv.open();
    await kv.put('user:1', { name: 'Ada' });
    await kv.put('user:2', { name: 'Linus' });
    await kv.batch([
      { op: 'put', key: 'acct:ada', value: 70 },
      { op: 'put', key: 'acct:linus', value: 30 },
    ]); // one record => atomic transfer
    const lsn = await kv.put('user:3', { name: 'Grace' });
    console.log(`   last LSN ${lsn}, fsyncs ${kv.wal.stats.fsyncs}, segments: ${logFiles()}`);

    console.log('\n2) Process dies while write() of LSN 5 is in flight (never acknowledged)');
    kv.simulateCrash();
    const seg = path.join(dir, segName(1));
    const inflight = encodeRecord(5, TYPE_BATCH, Buffer.from(JSON.stringify([{ op: 'put', key: 'user:5', value: { name: 'Edsger' } }])));
    fs.appendFileSync(seg, inflight.subarray(0, 30)); // only 30 of its bytes reached the disk
    console.log(`   appended 30 of ${inflight.length} bytes of record 5 -> torn tail`);

    console.log('\n3) Recovery: validate length + LSN + CRC, stop at first bad record, truncate the tail');
    kv = new DurableKV(dir);
    let rep = kv.open();
    console.log(`   replayed ${rep.replayed} records, last good LSN ${rep.lastLsn}`);
    console.log(`   truncated: ${JSON.stringify(rep.truncated)}`);
    console.log(`   user:3 = ${JSON.stringify(kv.get('user:3'))}, user:5 = ${kv.get('user:5')}  (every acked write kept, torn one dropped)`);
    console.log(`   acct:ada = ${kv.get('acct:ada')}, acct:linus = ${kv.get('acct:linus')}  (the batch is one record, so it is all-or-nothing)`);
    console.log(`   next write gets LSN ${await kv.put('user:5', { name: 'Edsger' })} (no gap, no duplicate)`);

    console.log('\n4) Bit rot in the middle of the log');
    await kv.put('user:6', { name: 'Barbara' });
    await kv.close();
    const buf = fs.readFileSync(seg);
    // Find the start of record 3 by walking the length fields.
    let off = 0;
    for (let i = 0; i < 2; i++) off += HEADER + buf.readUInt32LE(off);
    buf[off + HEADER + 3] ^= 0x20; // flip one bit inside record 3's payload
    fs.writeFileSync(seg, buf);
    kv = new DurableKV(dir);
    rep = kv.open();
    console.log(`   ${rep.truncated.reason} at offset ${rep.truncated.offset}: recovery stops there, ${rep.truncated.droppedBytes} B dropped, ${kv.size} keys left`);
    console.log('   (later records had valid CRCs, but replaying past a hole would reorder history)');
    await kv.close();

    console.log('\n5) Group commit: 200 concurrent writers, one fsync per batch window');
    for (const mode of ['always', 'group']) {
      const d = fs.mkdtempSync(path.join(os.tmpdir(), `wal-demo-${mode}-`));
      const k = new DurableKV(d, { sync: mode, groupMaxRecords: 64 });
      k.open();
      const t0 = process.hrtime.bigint();
      await Promise.all(Array.from({ length: 200 }, (_, i) => k.put(`key${i}`, i)));
      const ms = Number(process.hrtime.bigint() - t0) / 1e6;
      console.log(`   sync=${mode.padEnd(6)} fsyncs=${String(k.wal.stats.fsyncs).padStart(3)}  (${ms.toFixed(1)} ms on this disk)`);
      await k.close();
      fs.rmSync(d, { recursive: true, force: true });
    }

    console.log('\n6) Checkpoint + log truncation (segments roll every ~200 B here)');
    fs.rmSync(dir, { recursive: true, force: true });
    kv = new DurableKV(dir, { segmentBytes: 200 });
    kv.open();
    for (let i = 0; i < 12; i++) await kv.put(`k${i}`, i);
    console.log(`   before: ${logFiles()}`);
    const cp = kv.checkpoint();
    console.log(`   checkpoint at LSN ${cp.lsn}; deleted ${cp.removedSegments.length} segments`);
    await kv.put('k0', 'new');
    kv.simulateCrash();
    kv = new DurableKV(dir);
    rep = kv.open();
    console.log(`   after crash: snapshot LSN ${rep.snapshotLsn} + ${rep.replayed} replayed record(s); k0=${kv.get('k0')}, k11=${kv.get('k11')}`);
    console.log(`   remaining: ${logFiles()}`);
    await kv.close();
  } finally {
    fs.rmSync(dir, { recursive: true, force: true });
  }
})();

'use strict';
const assert = require('node:assert');
const fs = require('fs');
const os = require('os');
const path = require('path');
const {
  DurableKV, WriteAheadLog, WalCorruptionError, encodeRecord, decodeSegment, crc32, crc32Js, HEADER, segName,
} = require('./wal');

const tests = [];
const test = (name, fn) => tests.push({ name, fn });
const dirs = [];
function tmp() { const d = fs.mkdtempSync(path.join(os.tmpdir(), 'wal-test-')); dirs.push(d); return d; }
const seg1 = (dir) => path.join(dir, segName(1));
async function openKV(dir, opts) { const kv = new DurableKV(dir, opts); const rep = kv.open(); return { kv, rep }; }
async function fill(kv, n, prefix = 'k') { for (let i = 1; i <= n; i++) await kv.put(`${prefix}${i}`, i); }
const recSize = (key, value) => HEADER + Buffer.byteLength(JSON.stringify([{ op: 'put', key, value }]));

test('CRC32 matches the standard check value and zlib', () => {
  assert.strictEqual(crc32Js(Buffer.from('123456789')), 0xcbf43926);
  assert.strictEqual(crc32(Buffer.from('123456789')), 0xcbf43926);
  assert.strictEqual(crc32Js(Buffer.alloc(0)), 0);
  for (let n = 0; n < 50; n++) {
    const b = Buffer.from(Array.from({ length: n * 7 }, (_, i) => (i * 31 + n) & 0xff));
    assert.strictEqual(crc32Js(b), crc32(b));
  }
});

test('record framing: header layout and round trip', () => {
  const payload = Buffer.from('{"x":1}');
  const rec = encodeRecord(42, 1, payload);
  assert.strictEqual(rec.length, HEADER + payload.length);
  assert.strictEqual(rec.readUInt32LE(0), payload.length);
  assert.strictEqual(Number(rec.readBigUInt64LE(8)), 42);
  assert.strictEqual(rec.readUInt32LE(4), crc32(rec.subarray(8)));
  const out = decodeSegment(Buffer.concat([rec, encodeRecord(43, 1, payload)]), 42);
  assert.strictEqual(out.error, null);
  assert.deepStrictEqual(out.records.map((r) => r.lsn), [42, 43]);
  assert.strictEqual(decodeSegment(rec, 41).error, 'lsn-gap');
});

test('writes survive a clean close and reopen', async () => {

test('torn payload at the tail is truncated and the log stays appendable', async () => {

test('a flipped bit stops recovery at that record, discarding everything after it', async () => {
  const dir = tmp();
  let { kv } = await openKV(dir);
  await fill(kv, 6);
  await kv.close();
  const buf = fs.readFileSync(seg1(dir));

test('group commit coalesces concurrent writes into one fsync', async () => {

  const group = (await openKV(tmp(), { sync: 'group', groupMaxRecords: 1000 })).kv;

  assert.strictEqual(group.wal.stats.fsyncs, 1);

  await Promise.all(Array.from({ length: 50 }, (_, i) => capped.put(`k${i}`, i)));
  assert.strictEqual(capped.wal.stats.fsyncs, 4); // 16+16+16 at the cap, 2 on the next tick

});
