LRU Cache (Doubly Linked List + Hash Map)

A bounded in-memory cache that, when full, throws away the entry that was used least recently.

Every operation is O(1).

The problem and where it shows up

Memory is finite, and access patterns are usually skewed: a small hot set gets most of the reads.

An eviction policy decides what to drop when the cache is full. Least-recently-used is the usual

default because recency is a cheap, decent predictor of reuse. You find it in:

  • Application caches in the process: Guava/Caffeine (Java), lru-cache (npm), functools.lru_cache (Python).
  • Database buffer pools: InnoDB's buffer pool is an LRU list split into young and old sublists. PostgreSQL uses clock-sweep, which approximates LRU.
  • Block caches: RocksDB's LRUCache (sharded, size-aware, with a high-priority pool for index/filter blocks).
  • CDN and reverse-proxy caches: Nginx proxy_cache evicts by LRU once max_size is hit, and Varnish uses LRU for its malloc/file storage.
  • OS page cache: Linux keeps active and inactive LRU lists (two-list approximation).

Design

map: key -> node                 (O(1) lookup)

head <-> [MRU] <-> ... <-> [LRU] <-> tail     (O(1) reorder / evict)
 ^ sentinel                         sentinel ^
  • get(k): look up the node in the Map and splice it to the front.
  • set(k, v): insert at the front (or update in place and move to front), then pop from the back until the bounds hold.
  • Sentinel head and tail nodes mean _unlink and _pushFront never need null checks.
  • The Map holds node references, so removing an arbitrary node (for delete or expiry) is O(1). A singly linked list can't do this.

Invariants (checked by _checkInvariants() and the tests)

  1. Every list node is in the Map under its own key, and every Map entry is in the list.
  2. node.next.prev === node for every node.
  3. size <= maxEntries and calculatedSize <= maxSize after every public call returns.
  4. List order is exactly recency order: the result of get / set. peek, has and keys do not change it.

Features

OptionMeaning
maxEntriesEntry count bound
maxSize + sizeOf(value, key)Weight bound, e.g. bytes. Per-entry size override on set
ttlMsDefault TTL. set(k, v, { ttlMs }) overrides it. 0 = never expires
nowInjectable clock, so tests and the demo never sleep
onEvict(key, value, reason)capacity, expired, deleted, replaced, cleared
stats()hits, misses, sets, evictions, expirations, rejected, hitRate
Expiry is lazy: an expired entry is removed when you touch it. There's also an explicit prune() sweep, the same split as Redis's passive and active expiry. When capacity eviction reaches an

expired tail node, it reports it as expired, not capacity.

Oversized items (size > maxSize) are rejected (set returns false). Accepting one would flush

the entire cache and still not fit it. Any older value under the same key is removed, so readers

never see data the writer meant to replace.

Complexity

OperationTimeNotes
get / set / delete / has / peekO(1) amortisedMap ops + constant pointer swaps
eviction per setO(k)k = entries evicted. Amortised O(1) because each entry is evicted once
prune / keys / clearO(n)
SpaceO(n)One Map entry + one node (key, value, size, expiresAt, 2 pointers) per item
The per-entry overhead is roughly 100+ bytes in V8, which matters when values are small. Production

caches often store entries in flat arrays indexed by integer slots to avoid per-node objects

(lru-cache v7+ does this).

Failure modes and trade-offs

  • Scan pollution: a one-off sequential scan (a batch job or a crawler) pushes the whole hot set out.
    • LRU has no notion of frequency. Fixes: segmented LRU / midpoint insertion (InnoDB inserts new pages at the 3/8 point), 2Q, ARC, or W-TinyLFU (Caffeine), which admits a new item only if it's estimated to be more popular than the victim.
  • Lock contention: every get writes (it reorders the list). A multithreaded LRU needs a lock
    • on reads. Caffeine buffers reorders in ring buffers and replays them in batches. RocksDB and memcached shard the cache so each shard has its own lock.
  • Stale reads with TTL-only invalidation: TTL bounds staleness but doesn't remove it. Pair with
    • explicit invalidation on writes if correctness matters.
  • Thundering herd on miss: when a hot key expires, many callers miss together and all hit the
    • database. Use single-flight (request coalescing) or refresh-ahead. Not implemented here.
  • Size estimation lies: sizeOf is only as accurate as you make it. JS object size is hard to
    • measure, so a byte bound on objects is approximate.
  • Callback reentrancy: onEvict runs synchronously after internal state is consistent, and
    • exceptions it throws are swallowed. Calling back into the cache from it works, but it can cascade.

How production systems do it

  • Redis (maxmemory-policy allkeys-lru / volatile-lru) keeps no linked list. Each object stores
    • a 24-bit LRU clock. On eviction Redis samples maxmemory-samples keys (default 5) and evicts the oldest of the sample, using an eviction pool that carries candidates between rounds. It's approximate LRU with zero per-access list maintenance. allkeys-lfu uses a probabilistic log counter instead.
  • Memcached uses a per-slab-class LRU. The modern "segmented LRU" splits it into HOT, WARM and COLD
    • sublists maintained by a background thread, and items are bumped at most once every 60 s to limit lock traffic.
  • Caffeine (Java) uses W-TinyLFU: a small admission window LRU, a Count-Min-style frequency sketch,
    • and a segmented main LRU (probation and protected). Its hit rates are close to optimal on most traces.
  • RocksDB block cache uses a sharded LRU (num_shard_bits) with a charge per block, plus a
    • newer HyperClockCache that avoids a global list mutex entirely.
  • Linux page cache uses active/inactive two-list LRU approximation, and more recently MGLRU
    • (multi-generational LRU).

    6. LRU ordering, and why real systems accept that.
lru.js 
'use strict';
/**
 * LRU cache: Map (key -> node) + intrusive doubly linked list (recency order).
 *
 *   head (sentinel) <-> MRU <-> ... <-> LRU <-> tail (sentinel)
 *
 * Every operation that "uses" a key splices its node to the front in O(1);
 * eviction pops from the back in O(1). Sentinels remove all null checks.
 *
 * Bounds (either or both):
 *   maxEntries - maximum number of entries
 *   maxSize    - maximum total "size" (bytes, weight...) as computed by sizeOf
 * Optional TTL: per-cache default ttlMs, overridable per set(). Expiry is lazy
 * (checked on access) plus an explicit prune() sweep, like Redis' passive +
 * active expiry.
 */

class Node {
  constructor(key, value, size, expiresAt) {
    this.key = key;
    this.value = value;
    this.size = size;
    this.expiresAt = expiresAt; // Infinity = never
    this.prev = null;
    this.next = null;
  }
}

function isPositiveIntOrInf(n) {
  return n === Infinity || (Number.isInteger(n) && n > 0);
}

class LRUCache {
  /**
   * @param {object} opts
   * @param {number} [opts.maxEntries=Infinity]
   * @param {number} [opts.maxSize=Infinity]
   * @param {(value:any, key:any) => number} [opts.sizeOf] default: 1 per entry
   * @param {number} [opts.ttlMs=0]  0 = no default TTL
   * @param {() => number} [opts.now=Date.now] injectable clock (ms)
   * @param {(key, value, reason) => void} [opts.onEvict]
   *        reason: 'capacity' | 'expired' | 'deleted' | 'replaced' | 'cleared'
   */
  constructor(opts = {}) {
    const {
      maxEntries = Infinity,
      maxSize = Infinity,
      sizeOf = () => 1,
      ttlMs = 0,
      now = Date.now,
      onEvict = null,
    } = opts;
    if (!isPositiveIntOrInf(maxEntries)) throw new RangeError('maxEntries must be a positive integer');
    if (!(maxSize === Infinity || (typeof maxSize === 'number' && maxSize > 0))) {
      throw new RangeError('maxSize must be a positive number');
    }
    if (maxEntries === Infinity && maxSize === Infinity) {
      throw new RangeError('at least one of maxEntries / maxSize must be bounded');
    }
    if (typeof sizeOf !== 'function') throw new TypeError('sizeOf must be a function');
    if (!(typeof ttlMs === 'number' && ttlMs >= 0)) throw new RangeError('ttlMs must be >= 0');
    if (typeof now !== 'function') throw new TypeError('now must be a function');
    if (onEvict !== null && typeof onEvict !== 'function') throw new TypeError('onEvict must be a function');

    this.maxEntries = maxEntries;
    this.maxSize = maxSize;
    this.sizeOf = sizeOf;
    this.ttlMs = ttlMs;
    this.now = now;
    this.onEvict = onEvict;

    this.map = new Map();
    this.head = new Node(null, null, 0, Infinity);
    this.tail = new Node(null, null, 0, Infinity);
    this.head.next = this.tail;
    this.tail.prev = this.head;
    this.totalSize = 0;
    this._stats = { hits: 0, misses: 0, sets: 0, evictions: 0, expirations: 0, rejected: 0 };
  }

  // ---- linked-list primitives (all O(1)) ----
  _unlink(node) {
    node.prev.next = node.next;
    node.next.prev = node.prev;
    node.prev = node.next = null;
  }
  _pushFront(node) {
    node.prev = this.head;
    node.next = this.head.next;
    this.head.next.prev = node;
    this.head.next = node;
  }
  _moveToFront(node) {
    if (this.head.next === node) return;
    this._unlink(node);
    this._pushFront(node);
  }

  /** Remove a node from both structures and fire the callback. */
  _remove(node, reason) {
    this._unlink(node);
    this.map.delete(node.key);
    this.totalSize -= node.size;
    if (reason === 'capacity') this._stats.evictions++;
    else if (reason === 'expired') this._stats.expirations++;
    if (this.onEvict) {
      // A throwing callback must not corrupt the cache: state is already consistent.
      try { this.onEvict(node.key, node.value, reason); } catch (_) { /* swallow */ }
    }
  }

  _isExpired(node, t = this.now()) {
    return node.expiresAt <= t;
  }

  /** Returns a live node or undefined, expiring lazily. Does not touch recency. */
  _live(key) {
    const node = this.map.get(key);
    if (!node) return undefined;
    if (this._isExpired(node)) {
      this._remove(node, 'expired');
      return undefined;
    }
    return node;
  }

  get size() { return this.map.size; }
  get calculatedSize() { return this.totalSize; }

  /** Read and promote to MRU. */
  get(key) {
    const node = this._live(key);
    if (!node) { this._stats.misses++; return undefined; }
    this._stats.hits++;
    this._moveToFront(node);
    return node.value;
  }

  /** Read without promoting and without counting stats. */
  peek(key) {
    const node = this._live(key);
    return node ? node.value : undefined;
  }

  has(key) { return this._live(key) !== undefined; }

  /**
   * Insert or replace. Returns true if stored, false if the item alone exceeds maxSize.
   * @param {object} [o] { ttlMs, size }  per-entry overrides
   */
  set(key, value, o = {}) {
    const ttl = o.ttlMs !== undefined ? o.ttlMs : this.ttlMs;
    if (!(typeof ttl === 'number' && ttl >= 0)) throw new RangeError('ttlMs must be >= 0');
    const size = o.size !== undefined ? o.size : this.sizeOf(value, key);
    if (!(typeof size === 'number' && Number.isFinite(size) && size >= 0)) {
      throw new RangeError('size must be a finite number >= 0');
    }

    const existing = this.map.get(key);
    if (size > this.maxSize) {
      // Storing it would evict everything and still not fit. Reject, and drop any
      // stale older value so a reader never sees data the writer tried to replace.
      if (existing) this._remove(existing, 'replaced');
      this._stats.rejected++;
      return false;
    }
    this._stats.sets++;
    const expiresAt = ttl > 0 ? this.now() + ttl : Infinity;

    if (existing) {
      const oldValue = existing.value;
      this.totalSize += size - existing.size;
      existing.value = value;
      existing.size = size;
      existing.expiresAt = expiresAt;
      this._moveToFront(existing);
      if (this.onEvict && oldValue !== value) {
        try { this.onEvict(key, oldValue, 'replaced'); } catch (_) { /* swallow */ }
      }
    } else {
      const node = new Node(key, value, size, expiresAt);
      this.map.set(key, node);
      this._pushFront(node);
      this.totalSize += size;
    }
    this._evictIfNeeded();
    return true;
  }

  /** Evict from the LRU end until both bounds hold. Expired tail entries go first. */
  _evictIfNeeded() {
    while (this.map.size > this.maxEntries || this.totalSize > this.maxSize) {
      const lru = this.tail.prev;
      // The just-inserted node is at the head and always fits (size <= maxSize),
      // so this loop terminates before reaching it.
      this._remove(lru, this._isExpired(lru) ? 'expired' : 'capacity');
    }
  }

  delete(key) {
    const node = this.map.get(key);
    if (!node) return false;
    this._remove(node, 'deleted');
    return true;
  }

  clear() {
    for (let n = this.head.next; n !== this.tail;) {
      const next = n.next;
      this._remove(n, 'cleared');
      n = next;
    }
  }

  /** Active expiry sweep: O(n). Returns number removed. */
  prune() {
    const t = this.now();
    let removed = 0;
    for (let n = this.head.next; n !== this.tail;) {
      const next = n.next;
      if (this._isExpired(n, t)) { this._remove(n, 'expired'); removed++; }
      n = next;
    }
    return removed;
  }

  /** Remaining TTL in ms (Infinity if none, undefined if absent). */
  ttl(key) {
    const node = this._live(key);
    if (!node) return undefined;
    return node.expiresAt === Infinity ? Infinity : node.expiresAt - this.now();
  }

  /** Keys from most- to least-recently used (skips expired, no promotion). */
  *keys() {
    const t = this.now();
    for (let n = this.head.next; n !== this.tail; n = n.next) {
      if (!this._isExpired(n, t)) yield n.key;
    }
  }

  *entries() {
    const t = this.now();
    for (let n = this.head.next; n !== this.tail; n = n.next) {
      if (!this._isExpired(n, t)) yield [n.key, n.value];
    }
  }

  stats() {
    const s = this._stats;
    const lookups = s.hits + s.misses;
    return { ...s, entries: this.map.size, size: this.totalSize, hitRate: lookups ? s.hits / lookups : 0 };
  }

  /** Debug helper: verify list/map agreement. Throws on corruption. */
  _checkInvariants() {
    let count = 0, size = 0;
    for (let n = this.head.next; n !== this.tail; n = n.next) {
      if (n.next.prev !== n) throw new Error('broken back-link at ' + String(n.key));
      if (this.map.get(n.key) !== n) throw new Error('map/list mismatch at ' + String(n.key));
      count++; size += n.size;
    }
    if (count !== this.map.size) throw new Error('count mismatch');
    if (size !== this.totalSize) throw new Error('size mismatch');
    if (count > this.maxEntries || size > this.maxSize) throw new Error('bound violated');
    return true;
  }
}

module.exports = { LRUCache };

// Seeded PRNG (mulberry32) so the numbers are reproducible run to run.
function mulberry32(seed) {
  return () => {
    seed |= 0; seed = (seed + 0x6d2b79f5) | 0;
    let x = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    x = (x + Math.imul(x ^ (x >>> 7), 61 | x)) ^ x;
    return ((x ^ (x >>> 14)) >>> 0) / 4294967296;
  };
}
const rand = mulberry32(42);
const hot = new LRUCache({ maxEntries: 100, now });
for (let i = 0; i < 20000; i++) {
  // 80% of requests hit 50 hot keys, 20% spread across 5000 cold keys.
  const key = rand() < 0.8 ? 'hot' + Math.floor(rand() * 50) : 'cold' + Math.floor(rand() * 5000);
  if (hot.get(key) === undefined) hot.set(key, i); // cache-aside fill on miss
}
const s = hot.stats();
console.log(`20k requests, 100-slot cache: hits=${s.hits} misses=${s.misses} evictions=${s.evictions} hitRate=${(s.hitRate * 100).toFixed(1)}%`);
console.log('invariants hold:', hot._checkInvariants());
test.js 
'use strict';
const assert = require('node:assert/strict');
const { LRUCache } = require('./lru');

let failed = 0, passed = 0;
function test(name, fn) {
  try { fn(); passed++; console.log('✓ ' + name); }
  catch (e) { failed++; console.log('✗ ' + name + '\n    ' + (e && e.stack || e)); }
}
const clock = () => { const c = { t: 0 }; c.now = () => c.t; return c; };

test('evicts least-recently-used entry when entry bound exceeded', () => {
  const c = new LRUCache({ maxEntries: 2 });
  c.set('a', 1); c.set('b', 2); c.set('c', 3);
  assert.equal(c.has('a'), false);
  assert.deepEqual([...c.keys()], ['c', 'b']);
});

test('get promotes to MRU; peek and has do not', () => {
  const c = new LRUCache({ maxEntries: 3 });
  c.set('a', 1); c.set('b', 2); c.set('c', 3);
  c.peek('a'); c.has('a');
  assert.deepEqual([...c.keys()], ['c', 'b', 'a']);
  c.get('a');
  assert.deepEqual([...c.keys()], ['a', 'c', 'b']);
  c.set('d', 4); // b is now LRU
  assert.equal(c.has('b'), false);
});

test('overwriting a key updates value, promotes it, and does not grow count', () => {
  const c = new LRUCache({ maxEntries: 2 });
  c.set('a', 1); c.set('b', 2); c.set('a', 10);
  assert.equal(c.size, 2);
  assert.equal(c.get('a'), 10);
  c.set('c', 3);
  assert.equal(c.has('b'), false, 'b should be LRU after a was overwritten');
});

test('size-aware eviction keeps total size within maxSize', () => {
  const c = new LRUCache({ maxSize: 10, sizeOf: (v) => v.length });
  c.set('a', 'xxxx'); c.set('b', 'xxxx');
  assert.equal(c.calculatedSize, 8);
  c.set('c', 'xxxxx'); // 13 > 10 -> evict a (LRU) -> 9
  assert.deepEqual([...c.keys()], ['c', 'b']);
  assert.equal(c.calculatedSize, 9);
  c.set('b', 'x'); // shrink in place
  assert.equal(c.calculatedSize, 6);
  c._checkInvariants();
});

test('item larger than maxSize is rejected and removes a stale older value', () => {
  const c = new LRUCache({ maxSize: 5, sizeOf: (v) => v.length });
  c.set('k', 'abc'); c.set('other', 'z');
  assert.equal(c.set('k', 'abcdefgh'), false);
  assert.equal(c.has('k'), false);
  assert.equal(c.get('other'), 'z', 'rejection must not flush other entries');
  assert.equal(c.stats().rejected, 1);
});

test('both bounds enforced at once', () => {
  const c = new LRUCache({ maxEntries: 3, maxSize: 100, sizeOf: (v) => v });
  c.set('a', 10); c.set('b', 10); c.set('c', 10); c.set('d', 10);
  assert.equal(c.size, 3);
  c.set('e', 90); // 30+90=120 > 100 -> evict b (110), then c (100)
  assert.deepEqual([...c.keys()], ['e', 'd']);
  assert.equal(c.calculatedSize, 100);
  c._checkInvariants();
});

test('TTL: entry expires exactly at deadline, lazily on access', () => {
  const k = clock();
  const c = new LRUCache({ maxEntries: 5, ttlMs: 100, now: k.now });
  c.set('a', 1);
  k.t = 99; assert.equal(c.get('a'), 1);
  assert.equal(c.ttl('a'), 1);
  k.t = 100; assert.equal(c.get('a'), undefined);
  assert.equal(c.size, 0);
  assert.equal(c.stats().expirations, 1);

test('TTL: per-entry override, 0 means never expire, re-set refreshes deadline', () => {
  const k = clock();
  const c = new LRUCache({ maxEntries: 5, ttlMs: 100, now: k.now });
  c.set('forever', 1, { ttlMs: 0 });
  c.set('short', 2, { ttlMs: 10 });
  c.set('refresh', 3);
  k.t = 90; c.set('refresh', 4);
  k.t = 150;
  assert.equal(c.get('forever'), 1);
  assert.equal(c.ttl('forever'), Infinity);
  assert.equal(c.get('short'), undefined);
  assert.equal(c.get('refresh'), 4);
});

test('prune() sweeps expired entries and keys() skips them', () => {
  const k = clock();
  const c = new LRUCache({ maxEntries: 10, now: k.now });

test('onEvict receives key, value and reason for every removal path', () => {
  const k = clock();
  const log = [];
  const c = new LRUCache({ maxEntries: 2, now: k.now, onEvict: (key, v, r) => log.push([key, v, r]) });
  c.set('a', 1); c.set('b', 2); c.set('c', 3);  // a capacity
  c.set('b', 20);                               // b replaced (old value 2)
  c.delete('c');                                // c deleted
  c.set('x', 9, { ttlMs: 5 }); k.t = 5; c.get('x'); // x expired
  c.clear();                                    // b cleared
  assert.deepEqual(log, [['a', 1, 'capacity'], ['b', 2, 'replaced'], ['c', 3, 'deleted'], ['x', 9, 'expired'], ['b', 20, 'cleared']]);
});

test('randomized ops agree with a naive reference model', () => {
  let seed = 7;
  const rnd = (n) => { seed = (seed * 1103515245 + 12345) >>> 0; return seed % n; };
  const c = new LRUCache({ maxEntries: 8 });
  let ref = []; // array of [key, value], index 0 = MRU
  for (let i = 0; i < 5000; i++) {
    const key = rnd(20), op = rnd(3);
    const idx = ref.findIndex(([k]) => k === key);
    if (op === 0) {
      c.set(key, i);
      if (idx >= 0) ref.splice(idx, 1);
      ref.unshift([key, i]);
      if (ref.length > 8) ref.pop();
    } else if (op === 1) {
      const expect = idx >= 0 ? ref[idx][1] : undefined;
      assert.equal(c.get(key), expect);
      if (idx >= 0) ref.unshift(ref.splice(idx, 1)[0]);
    } else {
      assert.equal(c.delete(key), idx >= 0);
      if (idx >= 0) ref.splice(idx, 1);
    }
  }
  assert.deepEqual([...c.keys()], ref.map(([k]) => k));
  c._checkInvariants();
});

  const ms = Number(process.hrtime.bigint() - start) / 1e6;
