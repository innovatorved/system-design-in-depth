Layer 7 Load Balancer From Scratch

A real HTTP reverse proxy on node:http. It spreads requests across backends, removes bad ones

through active probes and through observed failures, and forwards the right headers.

const lb = new LoadBalancer({
  backends: [{ id: 'a', port: 9001 }, { id: 'b', port: 9002 }],
  algorithm: 'p2c',                        // 'round-robin' | 'least-connections' | 'p2c'
  healthCheck: { path: '/health', intervalMs: 2000, unhealthyThreshold: 3, healthyThreshold: 2 },
  outlier: { consecutiveFailures: 5, baseEjectionMs: 30_000, maxEjectionPercent: 50 },
});
await lb.listen(8080);

The problem and where it shows up

One server can't take all the traffic and can't be allowed to be a single point of failure.

A load balancer gives clients one address and chooses a healthy backend per request. An L7

(HTTP-aware) balancer can also route on paths and headers, retry, and add metadata. You'll find them as

AWS ALB, Google Cloud Load Balancing, Envoy (and every Istio sidecar), NGINX, HAProxy, Traefik,

and Kubernetes Ingress controllers.

Design

client ─► server.on('request')
            ├─ buffer body (≤ maxBodyBytes, else 413), so a retry can resend it
            ├─ headers: strip hop-by-hop, append X-Forwarded-For, set -Proto/-Host, X-Request-Id
            ├─ pick(): eligible = healthy (active HC) AND not ejected (passive)
            │     round-robin | least-connections | power-of-two-choices
            ├─ http.request(backend, keep-alive agent) ── pipe response back, add X-Upstream
            └─ on error: connect error + idempotent → retry on a different backend
                         timeout → 504, other → 502, nobody eligible → 503

Algorithms (pure classes, unit-tested without sockets)

PickerRuleGood atWeak at
RoundRobini-th eligible backend, cyclicEqual backends, equal request costSlow or overloaded nodes keep getting their turn
LeastConnectionsMinimum in-flight requests. Ties rotateMixed request cost, slow nodesO(N) scan. Every LB instance needs accurate counts
PowerOfTwoChoicesSample 2 distinct at random, take the less loadedNearly as good as least-conn at O(1)Randomness can pick two busy nodes
P2C is the "power of two choices" result (Mitzenmacher). With random placement, the maximum load drops from

Θ(log n / log log n) to Θ(log log n) just by comparing two samples. It also never herds: many LB instances

with stale counts won't all pick the same "least loaded" node, which is a known failure of pure least-conn at scale.

The test checks a concrete invariant: the single most-loaded backend is never chosen, and the least-loaded one

is chosen with probability exactly 1 - C(n-1,2)/C(n,2) (= 1/2 for n = 4).

Health: two independent signals

  • Active health checks (checkHealth(), or intervalMs for a timer): GET /health with a timeout. A 2xx is a success.
    • Thresholds add hysteresis: it takes unhealthyThreshold consecutive failures to mark a node down and healthyThreshold consecutive successes to bring it back, so one slow probe doesn't cause flapping.
  • Passive outlier ejection: real traffic results (connection errors, timeouts, 5xx) feed a per-backend
    • consecutive-failure counter. At consecutiveFailures the backend is ejected for baseEjectionMs × ejectionCount, so repeat offenders stay out longer. maxEjectionPercent refuses to eject past that share of the fleet. If everything is failing, the cause is probably shared (a bad dependency), and ejecting everyone would turn a partial outage into a total one.
  • A backend is eligible only if it is healthy and not ejected. Passive detection reacts within a few requests.
    • Active checks catch nodes that receive no traffic, and are the only way back from healthy=false.

Header rules

  • Hop-by-hop headers (RFC 9110 §7.6.1 plus the older RFC 2616 §13.5.1 list: Connection, Keep-Alive, TE, Transfer-Encoding, Upgrade,
    • Proxy-, Trailer, plus any header named in* Connection) are removed in both directions.
  • X-Forwarded-For is appended: client-supplied, . Only the right-most entries added by
    • proxies you trust are reliable. Anything to the left can be forged by the client. IPv4-mapped IPv6 peers (::ffff:1.2.3.4) are normalised.
  • X-Forwarded-Proto and X-Forwarded-Host are set if absent. X-Request-Id is preserved or generated (UUID v4) and echoed
    • to the client for log correlation. The response carries X-Upstream (the chosen backend), which is handy for learning but leaks topology in production.

Retries

Only connection refused/reset failures on idempotent methods are retried, and only on a different backend.

A refused connection means the backend never saw the request. A timeout doesn't: the request may have run, so

retrying a POST could charge a card twice. Timeouts return 504 and are not retried.

Failure modes and trade-offs

  • The LB is a single point of failure itself. Real deployments run several instances behind DNS, anycast, or an L4 tier
    • (ECMP, or AWS NLB in front of ALB), with keepalived/VRRP for failover.
  • Retry storms: retries multiply load exactly when backends are struggling. Use retry budgets (Envoy
    • retry_budget, e.g. ≤20% of active requests) and jittered backoff. This lab caps it at retries per request.
  • Health check that lies: /health returning 200 while the real path is broken. Passive ejection covers that.
    • A deep health check that calls the database can mark every node down during a DB blip, which is why the max-ejection cap exists.
  • In-flight counts are local: with M LB instances, each sees only its own connections. P2C tolerates this better than least-conn.
  • Buffering bodies costs memory and adds latency (and bounds uploads). Production proxies stream and keep only a bounded retry buffer.
  • Not implemented: TLS termination, HTTP/2 or gRPC upstreams, WebSocket Upgrade, connection draining on removal,
    • slow start for recovered nodes, weighted backends, sticky sessions.

How production systems do it

  • Envoy: ROUND_ROBIN, LEAST_REQUEST (P2C by default, with choice_count: 2), RING_HASH, MAGLEV, RANDOM.
    • Active health checking has unhealthy_threshold / healthy_threshold. Outlier detection has consecutive_5xx, base_ejection_time × times ejected, and max_ejection_percent. This lab's passive model copies that design. There's also a panic threshold: if too few hosts are healthy, Envoy balances across all hosts anyway.
  • NGINX: least_conn, ip_hash, hash … consistent, and (since 1.15) random two least_conn, which is P2C. Open-source
    • NGINX has passive checks only (max_fails, fail_timeout). Active health_check is an NGINX Plus feature.
  • HAProxy: roundrobin, leastconn, source, uri, and since 2.x random(2) (P2C). Checks use inter plus rise/fall thresholds,
    • and observe layer7 + error-limit + on-error mark-down for passive detection.
  • AWS ALB: round-robin or "least outstanding requests". Target-group health checks have healthy and unhealthy threshold counts.
    • It appends to X-Forwarded-For and sets X-Forwarded-Proto and X-Forwarded-Port.
  • Standards: RFC 7239 defines the structured Forwarded: header, the standardised successor to X-Forwarded-*.

balancer.js 
'use strict';
/**
 * A small Layer-7 (HTTP) load balancer / reverse proxy on node:http.
 *
 *   client ──► LoadBalancer ──pick()──► backend
 *                 │   ├─ algorithms: round-robin | least-connections | p2c (power of two choices)
 *                 │   ├─ active health checks (GET /health, healthy/unhealthy thresholds)
 *                 │   ├─ passive outlier ejection (consecutive failures -> ejected for a while)
 *                 │   └─ header hygiene: X-Forwarded-For/-Proto/-Host, X-Request-Id, hop-by-hop stripping
 *                 └─ 502 on upstream error, 504 on upstream timeout, 503 when nobody is eligible
 *
 * Pickers are pure (take eligible backends + rng) so they can be tested without sockets.
 * Time (for ejection) and randomness (for p2c) are injectable.
 */
const http = require('node:http');
const crypto = require('node:crypto');

// RFC 9110 §7.6.1: hop-by-hop headers must not be forwarded by a proxy.
const HOP_BY_HOP = new Set([
  'connection', 'keep-alive', 'proxy-connection', 'proxy-authenticate', 'proxy-authorization',
  'te', 'trailer', 'transfer-encoding', 'upgrade',
]);

function stripHopByHop(headers) {
  const out = { ...headers };
  // Headers named in Connection: are also hop-by-hop for this hop only.
  const listed = String(headers.connection || '').split(',').map((s) => s.trim().toLowerCase()).filter(Boolean);
  for (const h of [...HOP_BY_HOP, ...listed]) delete out[h];
  return out;
}

function clientIp(socket) {
  const a = socket.remoteAddress || '';
  return a.startsWith('::ffff:') ? a.slice(7) : a; // IPv4-mapped IPv6 -> dotted quad
}

// ---------------------------------------------------------------------------
// Pickers
// ---------------------------------------------------------------------------
class RoundRobin {
  constructor() { this.next = 0; }
  pick(eligible) {
    const b = eligible[this.next % eligible.length];
    this.next = (this.next + 1) % 1e9;
    return b;
  }
}

class LeastConnections {
  constructor() { this.offset = 0; }
  pick(eligible) {
    // Scan from a rotating offset so ties don't always go to the first backend.
    const n = eligible.length;
    const start = this.offset++ % n;
    let best = eligible[start];
    for (let i = 1; i < n; i++) {
      const b = eligible[(start + i) % n];
      if (b.active < best.active) best = b;
    }
    return best;
  }
}

/** Power of two choices: sample 2 distinct backends at random, take the less loaded one. */
class PowerOfTwoChoices {
  constructor(rng = Math.random) { this.rng = rng; }
  pick(eligible) {
    const n = eligible.length;
    if (n === 1) return eligible[0];
    const i = Math.floor(this.rng() * n);
    let j = Math.floor(this.rng() * (n - 1));
    if (j >= i) j++; // distinct second choice, uniform over the rest
    const a = eligible[i], b = eligible[j];
    return b.active < a.active ? b : a;
  }
}

const PICKERS = {
  'round-robin': () => new RoundRobin(),
  'least-connections': () => new LeastConnections(),
  p2c: (rng) => new PowerOfTwoChoices(rng),
};

// ---------------------------------------------------------------------------
// Backend state
// ---------------------------------------------------------------------------
class Backend {
  constructor({ id, host = '127.0.0.1', port }) {
    if (!Number.isInteger(port) || port <= 0 || port > 65535) throw new RangeError(`bad port for ${id}: ${port}`);
    this.id = id || `${host}:${port}`;
    this.host = host;
    this.port = port;
    this.healthy = true;      // active health-check verdict
    this.hcSuccesses = 0;     // consecutive, for thresholds
    this.hcFailures = 0;
    this.active = 0;          // in-flight proxied requests
    this.total = 0;           // requests sent
    this.consecutiveFailures = 0; // passive signal (errors / 5xx)
    this.ejectedUntil = 0;
    this.ejections = 0;
  }
  snapshot(now) {
    return {
      id: this.id, healthy: this.healthy, ejected: now < this.ejectedUntil,
      active: this.active, total: this.total, ejections: this.ejections,
    };
  }
}

// ---------------------------------------------------------------------------
// Load balancer
// ---------------------------------------------------------------------------
class LoadBalancer {
  /**
   * @param {object} o
   * @param {{id?:string, host?:string, port:number}[]} o.backends
   * @param {'round-robin'|'least-connections'|'p2c'} [o.algorithm='round-robin']
   * @param {() => number} [o.rng]  used by p2c
   * @param {() => number} [o.now]  used for ejection timing
   * @param {object} [o.healthCheck] { path='/health', timeoutMs=500, intervalMs=0 (manual), healthyThreshold=2, unhealthyThreshold=3 }
   * @param {object} [o.outlier]     { consecutiveFailures=3, baseEjectionMs=5000, maxEjectionPercent=50 }
   * @param {number} [o.requestTimeoutMs=5000]
   * @param {number} [o.retries=1]   retries on a different backend, for idempotent methods, on connect errors only
   * @param {number} [o.maxBodyBytes=1MiB] request bodies are buffered (to allow retry); larger -> 413
   */
  constructor(o = {}) {
    if (!Array.isArray(o.backends) || o.backends.length === 0) throw new Error('at least one backend is required');
    const algorithm = o.algorithm || 'round-robin';
    if (!PICKERS[algorithm]) throw new Error(`unknown algorithm ${algorithm}`);
    this.backends = o.backends.map((b) => new Backend(b));
    if (new Set(this.backends.map((b) => b.id)).size !== this.backends.length) throw new Error('duplicate backend id');
    this.algorithm = algorithm;
    this.picker = PICKERS[algorithm](o.rng || Math.random);
    this.now = o.now || Date.now;
    this.hc = { path: '/health', timeoutMs: 500, intervalMs: 0, healthyThreshold: 2, unhealthyThreshold: 3, ...o.healthCheck };
    this.outlier = { consecutiveFailures: 3, baseEjectionMs: 5000, maxEjectionPercent: 50, ...o.outlier };
    this.requestTimeoutMs = o.requestTimeoutMs ?? 5000;
    this.retries = o.retries ?? 1;
    this.maxBodyBytes = o.maxBodyBytes ?? 1024 * 1024;
    this.agent = new http.Agent({ keepAlive: true, maxSockets: 256 });
    this.server = http.createServer((req, res) => this._handle(req, res));
    this.timer = null;
  }

  // ---- lifecycle ----
  listen(port = 0, host = '127.0.0.1') {
    return new Promise((resolve, reject) => {
      this.server.once('error', reject);
      this.server.listen(port, host, () => {
        if (this.hc.intervalMs > 0) {
          this.timer = setInterval(() => this.checkHealth().catch(() => {}), this.hc.intervalMs);
          this.timer.unref();
        }
        resolve(this.server.address());
      });
    });
  }

  close() {
    clearInterval(this.timer);
    this.agent.destroy();
    this.server.closeAllConnections?.();
    return new Promise((resolve) => this.server.close(() => resolve()));
  }

  // ---- selection ----
  eligible() {
    const t = this.now();
    return this.backends.filter((b) => b.healthy && t >= b.ejectedUntil);
  }

  pick(exclude = new Set()) {
    const pool = this.eligible().filter((b) => !exclude.has(b));
    return pool.length ? this.picker.pick(pool) : null;
  }

  stats() {
    const t = this.now();
    return this.backends.map((b) => b.snapshot(t));
  }

  // ---- passive outlier detection ----
  _recordResult(b, ok) {
    if (ok) { b.consecutiveFailures = 0; return; }
    b.consecutiveFailures++;
    if (b.consecutiveFailures < this.outlier.consecutiveFailures) return;
    const t = this.now();
    if (t < b.ejectedUntil) return; // already ejected
    // Never eject more than maxEjectionPercent of the fleet: losing everyone to a shared
    // problem (e.g. a bad downstream dependency) would turn partial failure into total failure.
    const ejected = this.backends.filter((x) => t < x.ejectedUntil).length;
    if (((ejected + 1) / this.backends.length) * 100 > this.outlier.maxEjectionPercent) return;
    b.ejections++;
    b.ejectedUntil = t + this.outlier.baseEjectionMs * b.ejections; // back off repeat offenders
    b.consecutiveFailures = 0;
  }

  // ---- active health checks ----
  /** Probe every backend once, concurrently. Resolves to a snapshot. */
  async checkHealth() {
    await Promise.all(this.backends.map((b) => this._probe(b).then((ok) => this._applyProbe(b, ok))));
    return this.stats();
  }

  _probe(b) {
    return new Promise((resolve) => {
      let done = false;
      const finish = (ok) => { if (!done) { done = true; resolve(ok); } };
      const req = http.request({ host: b.host, port: b.port, path: this.hc.path, method: 'GET', agent: this.agent }, (res) => {
        res.resume(); // drain so the socket can be reused
        finish(res.statusCode >= 200 && res.statusCode < 300);
      });
      req.setTimeout(this.hc.timeoutMs, () => { req.destroy(); finish(false); });
      req.on('error', () => finish(false));
      req.end();
    });
  }

  /** Thresholds add hysteresis so one slow probe doesn't flap a backend. */
  _applyProbe(b, ok) {
    if (ok) {
      b.hcFailures = 0;
      b.hcSuccesses++;
      if (!b.healthy && b.hcSuccesses >= this.hc.healthyThreshold) b.healthy = true;
    } else {
      b.hcSuccesses = 0;
      b.hcFailures++;
      if (b.healthy && b.hcFailures >= this.hc.unhealthyThreshold) b.healthy = false;
    }
  }

  // ---- proxying ----
  _forwardHeaders(req) {
    const h = stripHopByHop(req.headers);
    const ip = clientIp(req.socket);
    // Append, don't overwrite: each proxy adds the address it received the connection from.
    h['x-forwarded-for'] = req.headers['x-forwarded-for'] ? `${req.headers['x-forwarded-for']}, ${ip}` : ip;
    h['x-forwarded-proto'] = req.headers['x-forwarded-proto'] || (req.socket.encrypted ? 'https' : 'http');
    if (req.headers.host) h['x-forwarded-host'] = req.headers['x-forwarded-host'] || req.headers.host;
    h['x-request-id'] = req.headers['x-request-id'] || crypto.randomUUID();
    return h;
  }

  _handle(req, res) {
    const headers = this._forwardHeaders(req);
    const idempotent = ['GET', 'HEAD', 'OPTIONS', 'PUT', 'DELETE'].includes(req.method);
    const tried = new Set();

    const attempt = (retriesLeft) => {
      const b = this.pick(tried);
      if (!b) return this._reply(res, 503, 'no healthy upstream', headers['x-request-id']);
      tried.add(b);
      b.active++; b.total++;
      let released = false;
      const release = () => { if (!released) { released = true; b.active--; } };

      const up = http.request({
        host: b.host, port: b.port, method: req.method, path: req.url, headers, agent: this.agent,
      }, (upRes) => {
        this._recordResult(b, upRes.statusCode < 500);
        const outHeaders = stripHopByHop(upRes.headers);
        outHeaders['x-upstream'] = b.id;
        outHeaders['x-request-id'] = headers['x-request-id'];
        res.writeHead(upRes.statusCode, outHeaders);
        upRes.pipe(res);
        upRes.on('end', release);
        upRes.on('error', () => { release(); res.destroy(); });
      });

      up.setTimeout(this.requestTimeoutMs, () => up.destroy(Object.assign(new Error('upstream timeout'), { code: 'ETIMEDOUT' })));
      up.on('error', (err) => {
        release();
        this._recordResult(b, false);
        if (res.headersSent) return res.destroy(); // mid-stream failure: nothing sane to send
        // Only a refused/reset connection is safe to retry: the backend never processed the request.
        const connectErr = err.code === 'ECONNREFUSED' || err.code === 'ECONNRESET';
        if (connectErr && idempotent && retriesLeft > 0) return attempt(retriesLeft - 1);
        const status = err.code === 'ETIMEDOUT' ? 504 : 502;
        this._reply(res, status, status === 504 ? 'upstream timeout' : `bad gateway: ${err.code || err.message}`, headers['x-request-id']);
      });
      res.on('close', () => { if (!res.writableFinished) up.destroy(); release(); }); // client went away

      if (bodyBuf) up.end(bodyBuf); else up.end();
    };

    // Buffer the request body so a retry can resend it. Fine for a lab with small bodies; a
    // production proxy streams (with a bounded retry buffer) and rejects oversized bodies (413).
    let bodyBuf = null, bytes = 0, tooLarge = false;
    const chunks = [];
    req.on('data', (c) => {
      bytes += c.length;
      if (bytes > this.maxBodyBytes) { tooLarge = true; return; } // keep draining, stop buffering
      chunks.push(c);
    });
    req.on('end', () => {
      if (tooLarge) return this._reply(res, 413, 'request body too large', headers['x-request-id']);
      if (chunks.length) bodyBuf = Buffer.concat(chunks);
      attempt(this.retries);
    });
    req.on('error', () => res.destroy());
  }

  _reply(res, status, message, requestId) {
    if (res.headersSent || res.destroyed) return;
    const body = JSON.stringify({ error: message });
    res.writeHead(status, { 'content-type': 'application/json', 'content-length': Buffer.byteLength(body), 'x-request-id': requestId });
    res.end(body);
  }
}

module.exports = { LoadBalancer, RoundRobin, LeastConnections, PowerOfTwoChoices, stripHopByHop, Backend };

'use strict';
/**
 * Walkthrough: real backends and a real proxy on ephemeral localhost ports.
 * Ejection uses a fake clock and p2c a seeded PRNG, so nothing waits on wall-clock timers
 * longer than ~100 ms.
 */
const http = require('node:http');
const { LoadBalancer } = require('./balancer');

function startBackend(name, cfg = {}) {
  const state = { status: 200, healthStatus: 200, delayMs: 0, ...cfg };
  const server = http.createServer((req, res) => {
    if (req.url === '/health') { res.writeHead(state.healthStatus); return res.end(); }
    req.resume();
    req.on('end', () => setTimeout(() => {
      res.writeHead(state.status, { 'content-type': 'application/json' });
      res.end(JSON.stringify({ name, xff: req.headers['x-forwarded-for'], rid: req.headers['x-request-id'] }));
    }, state.delayMs));
  });
  return new Promise((resolve) => server.listen(0, '127.0.0.1', () => resolve({
    name, state, port: server.address().port,
    close: () => { server.closeAllConnections(); return new Promise((r) => server.close(r)); },
  })));
}

function get(port, headers = {}) {
  const t0 = process.hrtime.bigint();
  return new Promise((resolve, reject) => {
    http.get({ host: '127.0.0.1', port, path: '/', headers, agent: false }, (res) => {
      let d = '';
      res.on('data', (c) => (d += c));
      res.on('end', () => resolve({
        status: res.statusCode, upstream: res.headers['x-upstream'] || '-',
        body: d, ms: Number(process.hrtime.bigint() - t0) / 1e6,
      }));
    }).on('error', reject);
  });
}

function mulberry32(seed) {
  return () => {
    seed |= 0; seed = (seed + 0x6d2b79f5) | 0;
    let x = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    x = (x + Math.imul(x ^ (x >>> 7), 61 | x)) ^ x;
    return ((x ^ (x >>> 14)) >>> 0) / 4294967296;
  };

'use strict';
const assert = require('node:assert/strict');
const http = require('node:http');
const { LoadBalancer, RoundRobin, LeastConnections, PowerOfTwoChoices, stripHopByHop } = require('./balancer');

// ---- tiny async test runner ------------------------------------------------
const tests = [];
const test = (name, fn) => tests.push({ name, fn });

// ---- helpers -----------------------------------------------------------------
/** Backend on an ephemeral localhost port. `cfg` is mutable at runtime. */
function startBackend(name, cfg = {}) {
  const state = { status: 200, healthStatus: 200, delayMs: 0, hits: 0, ...cfg };
  const server = http.createServer((req, res) => {
    if (req.url === '/health') { res.writeHead(state.healthStatus); return res.end(); }
    state.hits++;
    const chunks = [];
    req.on('data', (c) => chunks.push(c));
    req.on('end', () => setTimeout(() => {
      const body = JSON.stringify({ name, headers: req.headers, body: Buffer.concat(chunks).toString() });
      res.writeHead(state.status, { 'content-type': 'application/json', connection: 'keep-alive', 'keep-alive': 'timeout=99' });
      res.end(body);
    }, state.delayMs));
  });
  return new Promise((resolve) => server.listen(0, '127.0.0.1', () => resolve({
    name, state, port: server.address().port,
    close: () => { server.closeAllConnections(); return new Promise((r) => server.close(r)); },
  })));
}

/** A port that refuses connections. */
async function deadPort() {
  const b = await startBackend('dead');
  await b.close();
  return b.port;
}

function request(port, { method = 'GET', path = '/', headers = {}, body } = {}) {
  return new Promise((resolve, reject) => {
    const req = http.request({ host: '127.0.0.1', port, method, path, headers, agent: false }, (res) => {
      let data = '';
      res.on('data', (c) => (data += c));
      res.on('end', () => {
        let json = null;
        try { json = JSON.parse(data); } catch (_) { /* not json */ }
        resolve({ status: res.statusCode, headers: res.headers, json });
      });
    });
    req.on('error', reject);
    req.end(body);
  });
}

async function withLB(backends, opts, fn) {
  const lb = new LoadBalancer({ backends: backends.map((b) => ({ id: b.name, port: b.port })), ...opts });
  const { port } = await lb.listen(0);
  try { await fn(lb, port); } finally { await lb.close(); }
}

function seeded(seed) {
  return () => { seed = (seed * 1664525 + 1013904223) >>> 0; return seed / 2 ** 32; };
}

  assert.deepEqual(new Set([...Array(3)].map(() => lc.pick(ties).id)).size, 3);

test('p2c: two distinct samples, never picks the single most-loaded backend', () => {
  const p = new PowerOfTwoChoices(seeded(1));
  const pool = [fake('a', 1), fake('b', 2), fake('c', 3), fake('d', 9)];
  const counts = { a: 0, b: 0, c: 0, d: 0 };
  for (let i = 0; i < 6000; i++) counts[p.pick(pool).id]++;
  assert.equal(counts.d, 0);       // d always loses its comparison
  // a wins every pair it is in: P(a sampled) = 1 - C(3,2)/C(4,2) = 1/2
  assert.ok(Math.abs(counts.a / 6000 - 0.5) < 0.03, JSON.stringify(counts));
  assert.equal(new PowerOfTwoChoices(seeded(2)).pick([fake('only')]).id, 'only');
});

  try {
    await withLB([b], {}, async (lb, port) => {

      const h = r.json.headers;

test('passive ejection after consecutive 5xx, timed return, backoff on repeat', async () => {
  const bad = await startBackend('bad', { status: 500 });
  const good = await startBackend('good');
  let t = 0;
  try {
    await withLB([bad, good], { now: () => t, outlier: { consecutiveFailures: 2, baseEjectionMs: 1000, maxEjectionPercent: 50 } }, async (lb, port) => {
      for (let i = 0; i < 4; i++) await request(port); // bad gets requests 1 and 3 -> 2 consecutive 5xx
      assert.equal(lb.stats()[0].ejected, true);
      const during = [];
      for (let i = 0; i < 4; i++) during.push((await request(port)).headers['x-upstream']);
      assert.deepEqual(during, ['good', 'good', 'good', 'good']);
      t = 1000;                                            // ejection expires
      assert.equal(lb.stats()[0].ejected, false);
      bad.state.hits = 0;
      for (let i = 0; i < 4; i++) await request(port);
      assert.equal(bad.state.hits, 2);                     // back in rotation... and failing again
      assert.equal(lb.stats()[0].ejections, 2);
      assert.equal(lb.backends[0].ejectedUntil, 1000 + 2000); // second ejection lasts 2x base
    });
  } finally { await Promise.all([bad.close(), good.close()]); }
});

test('least-connections steers concurrent load away from a slow backend', async () => {
  const slow = await startBackend('slow', { delayMs: 120 });
  const fast = await startBackend('fast', { delayMs: 5 });
  try {
    await withLB([slow, fast], { algorithm: 'least-connections' }, async (lb, port) => {
      // 5 waves of 4 concurrent requests, staggered so in-flight counts matter.
      const results = [];
      for (let w = 0; w < 5; w++) {
        const wave = [];
        for (let i = 0; i < 4; i++) {
          wave.push(request(port));
          await new Promise((r) => setTimeout(r, 10));
        }
        results.push(...(await Promise.all(wave)));
      }
      const toSlow = results.filter((r) => r.headers['x-upstream'] === 'slow').length;
      assert.ok(toSlow <= 6, `slow got ${toSlow}/20`);
    });
  } finally { await Promise.all([slow.close(), fast.close()]); }
});
