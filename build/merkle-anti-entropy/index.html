Merkle-Tree Anti-Entropy Repair (Dynamo/Cassandra style)

Two replicas build XOR-composable Merkle trees over hash-partitioned token buckets. The trees are diffed top-down through mismatched subtrees only, and the divergent ranges are repaired with last-write-wins and tombstones. The build counts hashes exchanged against a naive per-key compare, measures overstreaming by depth, and handles trees of different depths as well as empty replicas and ranges.

Merkle-Tree Anti-Entropy Repair

Two replicas that should hold the same key range have drifted apart. This build finds out where they differ

without shipping every key, then repairs them. Keys are hash-partitioned into token buckets. Each replica builds a

Merkle tree over those buckets, the trees are compared top-down (descending only into mismatched subtrees), and only

the mismatched ranges are streamed and resolved with last-write-wins. The same approach is behind Dynamo's

anti-entropy and Cassandra's nodetool repair.

The problem

Replication with sloppy quorums, hinted handoff and read repair still leaves gaps. Hints expire, nodes get replaced,

disks lose files, and keys that are never read never get read-repaired. Some background process has to guarantee that

replicas eventually converge. Comparing replicas key by key means sending a digest for every one of

millions of keys every time, even when only a handful differ. A Merkle tree summarises the whole range in one root

hash, and a mismatch can be narrowed down in O(differences × depth) hashes.

Where it shows up: Amazon Dynamo (the 2007 paper), Apache Cassandra and ScyllaDB repair, Riak's Active Anti-Entropy,

and more generally in content-addressed sync (Git, IPFS, ZFS scrubs, certificate-transparency logs).

Design

token = murmur3_32(key) in [0, 2^32)        tree over [lo, hi) with 2^depth equal-width leaf buckets

entry digest = SHA-256(key, ts, value | tombstone)
leaf hash    = XOR of digests of entries in the bucket       (empty range = 32 zero bytes)
inner hash   = XOR of its two children  == XOR of every entry digest in its range
Diff (diffTrees): send the root. For each mismatched node, send its two children in the next round. Stop at

the shallower tree's leaf depth, or as soon as either side's node is empty (nothing left to narrow down, so the whole

range is streamed). Adjacent mismatched ranges are coalesced. The result reports hashesExchanged, rounds and a

per-level trace.

Repair (repair): both replicas stream their entries in each mismatched range. For every key the winner is chosen

by timestamp, then tombstone beats value, then larger value. The winner is applied to whichever side lost. The rule

is deterministic and symmetric, which makes LWW a join: the outcome doesn't depend on which replica

starts the session.

Invariants
  • Range hash is independent of depth. XOR is associative and commutative, so a node's hash depends only on the
    • entries in its token range, not on how the range was subdivided. Trees of different depths therefore agree on every level they share (tested level by level), and diffing works at min(depthA, depthB). Cassandra combines row hashes the same way, and so do Riak's tictac trees.
  • Single-key divergence costs 2·depth + 1 hashes: the root, then two siblings per level (tested at depths 4, 10 and 15).
  • Incremental maintenance: one write XORs out the old digest and XORs in the new one along its leaf-to-root path,
    • in O(depth). The test shows the result is identical to a full rebuild.
  • Deletes are data. Tombstones take part in the hashes and win ties, so a stale replica can't resurrect a deleted
    • key. Purging a tombstone before every replica has seen it does resurrect the key, and the demo shows it.
  • Bucket/range arithmetic is shared: bucketOf and rangeOf use the same floor/ceil boundaries, so every
    • token belongs to exactly one leaf in every tree over [lo, hi).

Complexity

Cost
Build treeO(n) digests + O(2^depth) node combines; memory (2^(depth+1) − 1) × 32 B (depth 16 ≈ 4 MB)
Diff, k divergent leaves≤ 1 + 2·k·depth hashes (bounded by 2^(depth+1) − 1), depth + 1 round trips
Naive compareone digest per key: n hashes, every session
Streamabout k × n / 2^depth entries per side (whole buckets)
In node demo.js, with 50,000 keys and 33 divergent keys at depth 12, the diff exchanges 463 hashes compared with 50,003

for a naive per-key compare, and streams 815 entries.

Failure modes and trade-offs

  • Overstreaming. The repair unit is a bucket, not a key. With 33 bad keys the demo streams 87,505 entries at
    • depth 4 and 107 at depth 16. Deeper trees cost memory, more hashes and more round trips. Cassandra spent years fighting this: row-level repair in ScyllaDB and subrange repair in Cassandra both exist because of it.
  • Hot or churning data. A tree is a snapshot. Writes that land during the session show up as false mismatches.
    • Real systems build from a consistent snapshot (Cassandra's validation compaction) or accept that some writes get repaired next time.
  • Topology changes. Trees are per token range. When ranges split or move (a node joins or leaves), the trees have to be
    • rebuilt. The Dynamo paper names this as the main drawback.
  • Tombstone GC vs repair cadence. If tombstones are purged before repair has reached every replica, deleted data
    • comes back. Cassandra's rule: repair every node within gc_grace_seconds (10 days by default).
  • XOR's weakness. XOR-combined hashes are only safe because each key appears once per range and the digests are
    • cryptographic. A structured, adversarial set of entries could cancel out. Classic Merkle trees (H(left‖right)) avoid this, but they lose the depth independence and O(depth) incremental updates.
  • Clock-based LWW can silently drop a concurrent write when clocks skew. Dynamo used vector clocks and sibling
    • values for that reason.

How production systems do it

  • Dynamo (2007): each node keeps a Merkle tree per key range it hosts and exchanges roots with the other
    • replicas to detect divergence cheaply. This handles permanent failures, while hinted handoff covers transient ones.
  • Cassandra: nodetool repair triggers a validation compaction on each replica that reads the range and builds
    • a Merkle tree. Trees are compared by the coordinator, and mismatched ranges are streamed as SSTable sections. Tree depth is capped (historically 2^15 leaves per range, later sized by a memory budget), so large ranges overstream. Incremental repair (marking SSTables repaired), subrange repair, and schedulers such as Cassandra Reaper keep it tractable.
  • ScyllaDB row-level repair compares row hashes in small batches, which removes most overstreaming.
  • Riak KV Active Anti-Entropy keeps persistent hash trees updated on every write. Its later tictac trees use
    • XOR-combinable hashes for exactly the incremental-update property used here.

merkle.js 
'use strict';
// Merkle-tree anti-entropy between two replicas of a token range (Dynamo / Cassandra "repair").
//
//  * Keys are hash-partitioned: token = murmur3_32(key) in [0, 2^32). A tree covers a token range
//    [lo, hi) split into 2^depth equal buckets (leaves).
//  * Node hash = XOR of the SHA-256 digests of every entry in the node's range (Cassandra also XORs
//    row hashes). XOR makes a range's hash independent of how finely it's subdivided, so trees
//    of DIFFERENT depths agree on every level they share, and a single write updates a path in O(depth).
//  * diff() descends level by level, only into children of mismatched nodes, counting hashes exchanged.
//  * repair() streams the entries of mismatched ranges both ways and resolves them with last-write-wins
//    (timestamp, then tombstone-beats-value, then larger value), so deletes propagate instead of resurrecting.
const crypto = require('crypto');

const TOKEN_SPACE = 2 ** 32;
const MAX_DEPTH = 20;
const ZERO = Buffer.alloc(32); // XOR identity = hash of an empty range

function murmur3_32(str, seed = 0) {
  const b = Buffer.from(str, 'utf8'), len = b.length, c1 = 0xcc9e2d51, c2 = 0x1b873593;
  let h = seed >>> 0, i = 0, k;
  for (; i + 4 <= len; i += 4) {
    k = b[i] | (b[i + 1] << 8) | (b[i + 2] << 16) | (b[i + 3] << 24);
    k = Math.imul(k, c1); k = (k << 15) | (k >>> 17); h ^= Math.imul(k, c2);
    h = (h << 13) | (h >>> 19); h = (Math.imul(h, 5) + 0xe6546b64) | 0;
  }
  k = 0;
  switch (len & 3) { // fall-through by design
    case 3: k ^= b[i + 2] << 16; // falls through
    case 2: k ^= b[i + 1] << 8;  // falls through
    case 1: k ^= b[i]; k = Math.imul(k, c1); k = (k << 15) | (k >>> 17); h ^= Math.imul(k, c2);
  }
  h ^= len; h ^= h >>> 16; h = Math.imul(h, 0x85ebca6b); h ^= h >>> 13; h = Math.imul(h, 0xc2b2ae35); h ^= h >>> 16;
  return h >>> 0;
}
const tokenOf = (key) => murmur3_32(key);

function entryDigest(key, e) {
  return crypto.createHash('sha256').update(`${key}\0${e.ts}\0${e.value === null ? 'D' : 'V' + e.value}`).digest();
}
function xorInto(dst, src) { for (let i = 0; i < 32; i++) dst[i] ^= src[i]; }

// Deterministic, commutative conflict resolution: the same winner no matter who compares first.
function newer(a, b) {
  if (!a) return b; if (!b) return a;
  if (a.ts !== b.ts) return a.ts > b.ts ? a : b;
  if ((a.value === null) !== (b.value === null)) return a.value === null ? a : b; // delete wins ties
  return (a.value || '') >= (b.value || '') ? a : b;
}

class Replica {
  constructor(name) { this.name = name; this.data = new Map(); } // key -> { value|null, ts, token }
  put(key, value, ts) { this._apply(key, { value, ts }); }
  delete(key, ts) { this._apply(key, { value: null, ts }); }
  _apply(key, e) {
    if (typeof key !== 'string' || !key) throw new TypeError('key must be a non-empty string');
    if (!Number.isFinite(e.ts)) throw new TypeError('ts must be a finite number');
    if (e.value !== null && typeof e.value !== 'string') throw new TypeError('value must be a string');
    const cur = this.data.get(key), win = newer(cur, e);
    if (win === e) this.data.set(key, { value: e.value, ts: e.ts, token: tokenOf(key) });
    return win === e && !(cur && cur.ts === e.ts && cur.value === e.value);
  }
  get(key) { const e = this.data.get(key); return e && e.value !== null ? e.value : undefined; }
  *entriesInRange(lo, hi) { for (const [k, e] of this.data) if (e.token >= lo && e.token < hi) yield [k, e]; }
}

class MerkleTree {
  // levels[0] = [root], levels[depth] = leaves; each node { hash: Buffer(32), count }
  constructor({ lo = 0, hi = TOKEN_SPACE, depth = 10 } = {}) {
    if (!Number.isInteger(depth) || depth < 0 || depth > MAX_DEPTH) throw new RangeError(`depth must be an integer in [0, ${MAX_DEPTH}]`);
    if (!(Number.isInteger(lo) && Number.isInteger(hi) && lo >= 0 && hi <= TOKEN_SPACE && lo < hi)) throw new RangeError('need 0 <= lo < hi <= 2^32');
    if (hi - lo < 2 ** depth) throw new RangeError('range too small for this depth');
    this.lo = lo; this.hi = hi; this.depth = depth;
    this.levels = [];
    for (let l = 0; l <= depth; l++) this.levels.push(Array.from({ length: 2 ** l }, () => ({ hash: Buffer.alloc(32), count: 0 })));
  }
  static build(replica, opts) {
    const t = new MerkleTree(opts), leaves = t.levels[t.depth];
    for (const [k, e] of replica.entriesInRange(t.lo, t.hi)) { const n = leaves[t.bucketOf(e.token)]; xorInto(n.hash, entryDigest(k, e)); n.count++; }
    for (let l = t.depth - 1; l >= 0; l--) {
      t.levels[l].forEach((n, i) => {
        const a = t.levels[l + 1][2 * i], b = t.levels[l + 1][2 * i + 1];
        n.hash = Buffer.from(a.hash); xorInto(n.hash, b.hash); n.count = a.count + b.count;
      });
    }
    return t;
  }
  bucketOf(token) { return Math.floor(((token - this.lo) * 2 ** this.depth) / (this.hi - this.lo)); }
  rangeOf(level, i) { // token range covered by node (level, i): same arithmetic in every tree over [lo, hi)
    const span = this.hi - this.lo, n = 2 ** level;
    return { lo: this.lo + Math.ceil((i * span) / n), hi: this.lo + Math.ceil(((i + 1) * span) / n) };
  }
  get root() { return this.levels[0][0]; }
  // Incremental maintenance: XOR out the old digest and XOR in the new one along the leaf-to-root path.
  update(key, oldEntry, newEntry) {
    const token = tokenOf(key);
    if (token < this.lo || token >= this.hi) return;
    const delta = Buffer.alloc(32); let dc = 0;
    if (oldEntry) { xorInto(delta, entryDigest(key, oldEntry)); dc--; }
    if (newEntry) { xorInto(delta, entryDigest(key, newEntry)); dc++; }
    for (let l = this.depth, i = this.bucketOf(token); l >= 0; l--, i >>= 1) { const n = this.levels[l][i]; xorInto(n.hash, delta); n.count += dc; }
  }
}

// Top-down comparison. One "round" is one level of the exchange; each compared node costs one hash on
// the wire (the peer compares against its own copy locally). If either side's node is empty there is
// nothing to narrow down: the whole range is streamed from the other side.
function diffTrees(a, b) {
  if (a.lo !== b.lo || a.hi !== b.hi) throw new Error('trees must cover the same token range');
  const depth = Math.min(a.depth, b.depth), ranges = [];
  let frontier = [0], hashesExchanged = 0, rounds = 0;
  const trace = []; // per round: { level, compared, mismatched, streamedWhole }
  for (let l = 0; frontier.length; l++) {
    rounds++;
    const next = [];
    let mismatched = 0, streamedWhole = 0;
    for (const i of frontier) {
      hashesExchanged++;
      const x = a.levels[l][i], y = b.levels[l][i];
      if (x.count === y.count && x.hash.equals(y.hash)) continue;
      mismatched++;
      if (l === depth || x.count === 0 || y.count === 0) { ranges.push(a.rangeOf(l, i)); streamedWhole++; }
      else next.push(2 * i, 2 * i + 1);
    }
    trace.push({ level: l, compared: frontier.length, mismatched, streamedWhole });
    frontier = next;
  }
  // coalesce adjacent ranges so repair streams contiguous spans
  ranges.sort((p, q) => p.lo - q.lo);
  const merged = [];
  for (const r of ranges) { const last = merged[merged.length - 1]; if (last && last.hi === r.lo) last.hi = r.hi; else merged.push({ ...r }); }
  return { ranges: merged, hashesExchanged, rounds, comparedDepth: depth, trace };
}

// Full anti-entropy session between two replicas over [lo, hi).
function repair(a, b, { lo = 0, hi = TOKEN_SPACE, depthA = 10, depthB = depthA } = {}) {
  const ta = MerkleTree.build(a, { lo, hi, depth: depthA }), tb = MerkleTree.build(b, { lo, hi, depth: depthB });
  const d = diffTrees(ta, tb);
  let streamed = 0, updatedA = 0, updatedB = 0, differing = 0;
  for (const r of d.ranges) {
    const fromA = new Map(a.entriesInRange(r.lo, r.hi)), fromB = new Map(b.entriesInRange(r.lo, r.hi));
    streamed += fromA.size + fromB.size;
    for (const key of new Set([...fromA.keys(), ...fromB.keys()])) {
      const ea = fromA.get(key), eb = fromB.get(key), win = newer(ea, eb);
      if (ea && eb && ea.ts === eb.ts && ea.value === eb.value) continue; // already in sync
      differing++;
      if (win !== ea) { a._apply(key, win); updatedA++; }
      if (win !== eb) { b._apply(key, win); updatedB++; }
    }
  }
  const naiveHashes = Math.max(countInRange(a, lo, hi), countInRange(b, lo, hi)); // one digest per key
  return { ...d, naiveHashes, streamed, differing, updatedA, updatedB };
}
function countInRange(r, lo, hi) { let n = 0; for (const _ of r.entriesInRange(lo, hi)) n++; return n; }

module.exports = { Replica, MerkleTree, diffTrees, repair, newer, tokenOf, murmur3_32, entryDigest, TOKEN_SPACE, ZERO };

'use strict';
// Deterministic walkthrough of Merkle-tree anti-entropy between two replicas.
const { Replica, MerkleTree, diffTrees, repair, TOKEN_SPACE } = require('./merkle');

function mulberry32(seed) {
  return () => { seed |= 0; seed = (seed + 0x6d2b79f5) | 0; let t = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t; return ((t ^ (t >>> 14)) >>> 0) / 4294967296; };
}
const N = 50000;
function replicas() {
  const a = new Replica('A'), b = new Replica('B');
  for (let i = 0; i < N; i++) { a.put('user:' + i, 'profile-v1-' + i, 1000); b.put('user:' + i, 'profile-v1-' + i, 1000); }
  return [a, b];
}
function diverge(a, b, seed) { // B was partitioned away; hinted handoff expired before it came back
  const rnd = mulberry32(seed);
  for (let i = 0; i < 25; i++) a.put('user:' + Math.floor(rnd() * N), 'profile-v2', 2000 + i);
  for (let i = 0; i < 5; i++) a.delete('user:' + Math.floor(rnd() * N), 3000 + i);
  for (let i = 0; i < 3; i++) b.put('user:new-' + i, 'signup-on-B', 2500 + i);
}

}
function sameData(a, b) {
  const strip = (r) => [...r.data].map(([k, e]) => [k, e.value, e.ts]).sort((x, y) => (x[0] < y[0] ? -1 : 1));
  assert.deepEqual(strip(a), strip(b));
}

test('murmur3_32 reference vectors (token function)', () => {
  assert.equal(murmur3_32('', 0), 0);
  assert.equal(murmur3_32('', 1), 0x514e28b7);
  assert.equal(murmur3_32('hello'), 0x248bfa47);
  assert.equal(murmur3_32('The quick brown fox jumps over the lazy dog'), 0x2e4ff723);
});

  const r = repair(a, b, { depthA: 12 });
  assert.deepEqual(r.ranges, []);

test('one differing key: exactly one leaf range, 2*depth + 1 hashes, and it contains the key', () => {
  const [a, b] = twin(20000);
  b.put('k777', 'changed', 2);
  for (const depth of [4, 10, 15]) {
    const d = diffTrees(MerkleTree.build(a, { depth }), MerkleTree.build(b, { depth }));
    assert.equal(d.ranges.length, 1);
    assert.equal(d.hashesExchanged, 2 * depth + 1, 'depth ' + depth);
    const t = tokenOf('k777');
    assert.ok(d.ranges[0].lo <= t && t < d.ranges[0].hi);
    assert.equal(d.ranges[0].hi - d.ranges[0].lo, Math.round(TOKEN_SPACE / 2 ** depth));
  }
});

test('XOR composition: a tree at depth d equals the top d levels of any deeper tree', () => {
  const [a] = twin(3000);
  const deep = MerkleTree.build(a, { depth: 12 });
  for (const d of [0, 3, 7, 12]) {
    const shallow = MerkleTree.build(a, { depth: d });
    for (let l = 0; l <= d; l++) shallow.levels[l].forEach((n, i) => {
      assert.ok(n.hash.equals(deep.levels[l][i].hash)); assert.equal(n.count, deep.levels[l][i].count);
    });
  }
  const leafCounts = deep.levels[12].reduce((s, n) => s + n.count, 0);
  assert.equal(leafCounts, 3000); assert.equal(deep.root.count, 3000);
});

test('randomized divergence (missing, stale, deleted keys) converges; newer write wins on both sides', () => {
  const rnd = mulberry32(7), [a, b] = twin(10000);
  const expected = new Map();
  for (let i = 0; i < 300; i++) {
    const key = 'k' + Math.floor(rnd() * 12000), side = rnd() < 0.5 ? a : b, ts = 2 + Math.floor(rnd() * 100), op = rnd();
    if (op < 0.6) side.put(key, 'w' + i, ts); else side.delete(key, ts);
    const cur = expected.get(key), e = { value: op < 0.6 ? 'w' + i : null, ts };
    expected.set(key, cur ? newer(cur, e) : e);
  }
  const r = repair(a, b, { depthA: 10 });
  assert.ok(r.differing > 200 && r.updatedA > 0 && r.updatedB > 0);
  sameData(a, b);
  for (const [key, e] of expected) { // LWW is a join: the result is the max over ALL writes, wherever they landed
    const got = a.data.get(key);
    assert.deepEqual([got.value, got.ts], [e.value, e.ts], key);
  }
  assert.ok(MerkleTree.build(a, { depth: 10 }).root.hash.equals(MerkleTree.build(b, { depth: 10 }).root.hash));
  assert.equal(repair(a, b).hashesExchanged, 1); // second session finds nothing
});

test('tombstones propagate: a delete is not resurrected by the stale replica', () => {
  const [a, b] = twin(100);
  a.delete('k5', 10);
  b.put('k6', 'old', 0.5); // older than the existing ts=1 write: ignored locally
  assert.equal(b.get('k6'), 'v6');
  repair(a, b);
  assert.equal(a.get('k5'), undefined); assert.equal(b.get('k5'), undefined);
  assert.equal(b.data.get('k5').value, null); // kept as a tombstone, so hashes agree
  sameData(a, b);
});

test('trees of different depth are compared at the shallower depth and still converge', () => {
  const [a, b] = twin(8000);
  for (let i = 0; i < 20; i++) a.put('extra' + i, 'x', 5);
  const r = repair(a, b, { depthA: 6, depthB: 14 });
  assert.equal(r.comparedDepth, 6);
  for (const g of r.ranges) assert.equal((g.hi - g.lo) % (TOKEN_SPACE / 64), 0); // depth-6 leaf granularity
  assert.equal(r.updatedB, 20);
  sameData(a, b);
  const r2 = repair(a, b, { depthA: 14, depthB: 6 });
  assert.equal(r2.hashesExchanged, 1);
});

test('empty replica: stop at the root and stream the whole range; both empty is in sync', () => {

test('empty sub-ranges short-circuit the descent', () => {
  // keys only in the lower half of the token space on A; B is missing a quarter's worth of them
  const a = new Replica('A'), b = new Replica('B');
  for (let i = 0, n = 0; n < 4000; i++) {
    const key = 'u' + i, t = tokenOf(key);
    if (t >= TOKEN_SPACE / 2) continue;
    n++; a.put(key, 'v', 1); if (t >= TOKEN_SPACE / 4) b.put(key, 'v', 1);
  }
  const d = diffTrees(MerkleTree.build(a, { depth: 12 }), MerkleTree.build(b, { depth: 12 }));
  // root(1) + level1 (2) + level2 (2): node [0, 1/4) is empty on B, so it is streamed wholesale
  assert.equal(d.hashesExchanged, 5);
  assert.deepEqual(d.ranges, [{ lo: 0, hi: TOKEN_SPACE / 4 }]);
});

test('Merkle exchange is far cheaper than a per-key compare when divergence is sparse', () => {
  const [a, b] = twin(50000);
  const rnd = mulberry32(3);
  for (let i = 0; i < 10; i++) b.put('k' + Math.floor(rnd() * 50000), 'drift', 9);
  const r = repair(a, b, { depthA: 14 });
  assert.equal(r.naiveHashes, 50000);
  assert.ok(r.hashesExchanged <= 10 * 2 * 14 + 1, 'hashes ' + r.hashesExchanged);
  assert.ok(r.hashesExchanged * 100 < r.naiveHashes);
  assert.equal(r.differing, 10);
  sameData(a, b);
});

test('overstreaming trade-off: shallow trees stream many in-sync keys, deeper trees fewer', () => {
  const results = [];
  for (const depth of [2, 6, 10, 14]) {
    const [a, b] = twin(20000);
    for (let i = 0; i < 16; i++) b.put('k' + (i * 1237), 'drift', 3);
    const r = repair(a, b, { depthA: depth });
    assert.equal(r.differing, 16);
    results.push(r);
  }
  for (let i = 1; i < results.length; i++) assert.ok(results[i].streamed < results[i - 1].streamed);
  assert.ok(results[0].streamed > 10000 && results[3].streamed < 100);
  assert.ok(results[3].hashesExchanged > results[0].hashesExchanged); // ...paid for in hashes
});

test('sub-range repair ignores keys outside [lo, hi); mismatched ranges and bad params throw', () => {
  const [a, b] = twin(4000);
  const lo = 1 << 30, hi = 2 ** 31;
  const inside = [...a.data.keys()].find((k) => tokenOf(k) >= lo && tokenOf(k) < hi);
  const outside = [...a.data.keys()].find((k) => tokenOf(k) < lo);
  b.put(inside, 'in', 5); b.put(outside, 'out', 5);
  const r = repair(a, b, { lo, hi, depthA: 8 });
  assert.equal(r.differing, 1);
  for (const g of r.ranges) assert.ok(g.lo >= lo && g.hi <= hi);
  assert.equal(a.get(inside), 'in'); assert.equal(a.get(outside), 'v' + outside.slice(1));
  assert.throws(() => diffTrees(MerkleTree.build(a, { lo, hi, depth: 4 }), MerkleTree.build(b, { depth: 4 })), /same token range/);
  assert.throws(() => new MerkleTree({ depth: 21 }), RangeError);
  assert.throws(() => new MerkleTree({ lo: 5, hi: 5 }), RangeError);
  assert.throws(() => new MerkleTree({ lo: 0, hi: 8, depth: 4 }), /too small/);
  assert.throws(() => a.put('', 'v', 1), TypeError);
  assert.throws(() => a.put('k', 'v', NaN), TypeError);
});

test('incremental update of a tree equals a full rebuild', () => {
  const [a] = twin(3000);
  const t = MerkleTree.build(a, { depth: 9 });
  const ops = [['k10', 'new', 5], ['fresh-key', 'hello', 5], ['k20', null, 6]];
  for (const [key, value, ts] of ops) {
    const old = a.data.get(key) ? { ...a.data.get(key) } : undefined;
    if (value === null) a.delete(key, ts); else a.put(key, value, ts);
    t.update(key, old, a.data.get(key));
  }
  const fresh = MerkleTree.build(a, { depth: 9 });
  for (let l = 0; l <= 9; l++) t.levels[l].forEach((n, i) => { assert.ok(n.hash.equals(fresh.levels[l][i].hash)); assert.equal(n.count, fresh.levels[l][i].count); });
});

test('conflict resolution is deterministic and symmetric on timestamp ties', () => {
  const x = { value: 'apple', ts: 5 }, y = { value: 'banana', ts: 5 }, del = { value: null, ts: 5 };
  assert.equal(newer(x, y), y); assert.equal(newer(y, x), y);

  assert.equal(a.get('k'), 'banana'); assert.equal(b.get('k'), 'banana');
});
