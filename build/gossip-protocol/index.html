Gossip: Push-Pull Anti-Entropy & SWIM Failure Detection

The problem

A cluster of hundreds or thousands of nodes needs shared, slowly changing knowledge: who is

a member, who is alive, which node owns which token range, the schema version, feature

flags. A central registry becomes a bottleneck and a single point of failure. Broadcasting

every change to everyone costs O(N) per sender and falls apart under loss.

Gossip has each node talk to a few random peers per round. An update then reaches all

N nodes in O(log N) rounds, with O(1) work per node per round, and it tolerates lost

messages and crashed nodes without any extra machinery.

The second half of the problem is failure detection. Heartbeating everyone to everyone

costs O(N²) messages. SWIM gets constant load per member and O(1) expected detection time,

and rides the gossip channel to spread its verdicts.

Where it shows up: Cassandra/ScyllaDB (ring state, schema, phi-accrual detector), HashiCorp

memberlist (Consul, Nomad, Serf), Amazon Dynamo (membership), Redis Cluster (cluster bus

PFAIL/FAIL), Akka Cluster, Uber Ringpop, and Bitcoin/Ethereum transaction relay.

Design

gossip.js is one simulation with synchronous rounds, a lossy Network, and a seeded mulberry32 PRNG, so every run is reproducible.

Part 1: anti-entropy of versioned state (GossipCluster)

  • Each entry is {value, version, writer}. version comes from the writer's Lamport clock:
    • set() increments it, and merge() does clock = max(clock, received). A write made after seeing version 41 therefore gets version 42 or more, and supersedes what the writer saw.
  • Merge = last-writer-wins on (version, writer). It is a total order, so merge is
    • commutative, associative and idempotent (a state-based CRDT). Replicas converge whatever the order, duplication or loss of messages. Ties (concurrent writes with equal versions) are broken by writer id. That is deterministic, and it deliberately loses one of the writes.
  • Push-pull exchange uses the same three steps as Cassandra's gossip:
    • 1. SYN: p sends a digest (key, version, writer), with no values. 2. ACK: q replies with entries newer than p's, and the keys where p is newer. 3. ACK2: p sends the requested entries. Peers that are already in sync exchange only digests. Modes push (send full state) and pull (digest, then deltas) exist for comparison.
  • Round model: in each round every live node contacts fanout random peers, and messages
    • are built from start-of-round snapshots. A rumour therefore moves at most one hop per exchange per round, which is the model the O(log N) results assume.

Part 2: SWIM failure detector (SwimCluster)

Why SWIM instead of phi-accrual: phi-accrual (Cassandra, Akka) turns heartbeat

inter-arrival statistics into a suspicion level, but it still needs heartbeats from every

monitored peer. SWIM decouples detection from dissemination. It has constant per-member

load, needs no per-peer timing history, and verifies failures through other members instead

of trusting one lossy path. It is the protocol behind memberlist and Consul.

Each protocol period, every live member:

  1. Probes the next target in a shuffled round-robin list. Round-robin bounds the time
    2. until a member is probed to 2N-1 periods; random choice gives an expected e/(e-1) ≈ 1.6 periods to first detection but no worst-case bound.
  2. If the ping or its ack is lost, it sends a ping-req through k random helpers
    3. (default 3). Any helper's ack counts.
  3. If everything fails, it marks the target SUSPECT (with the target's known
    4. incarnation) instead of DEAD.
  4. A suspect that hears about its own suspicion refutes it: it increments its
    5. incarnation and spreads ALIVE(inc+1).
  5. A suspicion that nobody refutes within suspicionRounds (default 2·⌈log2(N+1)⌉) becomes
    6. DEAD at that observer.

Precedence rules (the unit test covers each one): ALIVE(i) replaces SUSPECT/DEAD only

if i > current; SUSPECT(i) replaces ALIVE(j) if i ≥ j; DEAD replaces anything that is not

already DEAD with i ≥ current. Updates are piggybacked (up to 6 per message) on

ping/ack/ping-req traffic, freshest first, and each one is sent 4·⌈log10(N+1)⌉ times, which

is memberlist's retransmit rule.

Complexity

  • Anti-entropy: O(fanout) exchanges per node per round. Digest size is O(keys), and deltas
    • are O(changed keys). Spreading one update takes O(log N) rounds and O(N log N) messages in total.
  • SWIM: an expected O(1) messages per member per period (1 ping, plus k·4 when a ping
    • fails). First detection takes an expected ~1.6 periods. Full dissemination takes O(log N) periods after the suspicion timeout.
  • Memory: O(keys) per node for the KV state, and O(N) per node for the membership table.

Failure modes & trade-offs

  • Digest cost grows with state. Sending every key's version each round is fine for
    • cluster metadata and wasteful for large data sets. Dynamo and Cassandra repair use Merkle trees for bulk data instead.
  • LWW silently drops concurrent writes. For data where that matters, use version vectors
    • or CRDTs with richer merges (OR-sets, counters).
  • Lamport versions only work if clocks are persisted. A node that restarts at clock 0
    • writes versions that lose to its old ones. Cassandra pairs a generation (boot timestamp) with a per-boot version for exactly this reason.
  • Suspicion timeout trade-off: a longer timeout means fewer false positives and slower
    • detection of real crashes. Lifeguard adapts timeouts to a member's own health (its "local health multiplier").
  • Piggyback capacity: under heavy churn the update queue outgrows the 6-updates-per-message
    • budget, refutations arrive late, and false positives rise (the "ping only" column shows this feedback loop). memberlist limits updates by UDP packet size.
  • Partitions: SWIM on each side will declare the other side dead. Gossip does not solve
    • split brain. Pair it with consensus for anything that needs a single decision.

How production systems do it

  • Cassandra: once a second, each node gossips with one random live peer, maybe one
    • unreachable peer, and maybe a seed, using GossipDigestSyn / Ack / Ack2. Endpoint state is versioned by (generation, version). Failure detection is phi-accrual (phi_convict_threshold, default 8).
  • HashiCorp memberlist (Consul, Nomad, Serf): SWIM + Lifeguard over UDP, with a 1 s probe
    • interval, 3 indirect checks, suspicion multiplier 4 and retransmit multiplier 4. It also runs a periodic TCP push-pull full-state sync (30 s by default), which is the anti-entropy half of this build.
  • Amazon Dynamo: gossip-based membership and token-map propagation, with seed nodes to
    • prevent logical partitions, and Merkle-tree anti-entropy between replicas.
  • Redis Cluster: nodes ping random peers over the cluster bus and mark unresponsive ones
    • PFAIL (like SUSPECT). A node becomes FAIL only when a majority of masters report it.
  • Akka Cluster: membership state gossiped with vector clocks, and a phi-accrual detector
    • on each node's heartbeat.

Extension exercises

  1. Add phi-accrual as an alternative detector (a sliding window of heartbeat
    2. intervals, phi = -log10(1 - CDF(Δt))) and compare detection time and false positives against SWIM on the same seeds.
  2. Let GossipCluster choose peers from SwimCluster's live view, so dead nodes stop
    3. wasting fanout.
  3. Replace full digests with a Merkle tree per node, and measure bytes exchanged against
    4. the number of keys when only 1% of the keys differ.
  4. Swap LWW registers for an OR-set CRDT, and show that concurrent add/remove no longer
    5. loses an add.
  5. Add Lifeguard's local health multiplier: a node that is missing acks itself stretches
    6. its own probe timeout and suspicion timeout. Measure false positives when one node is overloaded.

'use strict';
/**
 * Gossip, in two parts, over one simulated lossy network (synchronous rounds, seeded PRNG):
 *
 *  1. GossipCluster: push-pull anti-entropy of a versioned key/value map. Each entry
 *     carries (version, writer), where version comes from the writer's Lamport clock.
 *     Merge is last-writer-wins on (version, writer), which is commutative, associative and
 *     idempotent, so replicas converge whatever the order, duplication or loss of messages.
 *     An exchange is Cassandra's three messages: SYN(digest) -> ACK(deltas + requests) -> ACK2(deltas).
 *
 *  2. SwimCluster: SWIM failure detection (Das, Gupta, Motivala 2002) with the Lifeguard-style
 *     suspicion subprotocol that memberlist and Consul use: ping, then k indirect ping-reqs,
 *     then SUSPECT; a suspect can refute by bumping its incarnation, otherwise it is declared
 *     DEAD after a timeout. Membership updates are piggybacked on probe traffic and
 *     retransmitted O(log N) times (infection-style dissemination).
 */

/** Mulberry32: small, fast, seedable PRNG with good enough statistics for simulations. */
function mulberry32(seed) {
  let a = seed >>> 0;
  return () => {
    a = (a + 0x6d2b79f5) >>> 0;
    let t = a;
    t = Math.imul(t ^ (t >>> 15), t | 1);
    t ^= t + Math.imul(t ^ (t >>> 7), t | 61);
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
}

/** Pick k distinct items from arr, excluding `exclude`, without modifying arr. */
function sample(rng, arr, k, exclude = new Set()) {
  const pool = arr.filter((x) => !exclude.has(x));
  for (let i = pool.length - 1; i > 0; i--) { const j = Math.floor(rng() * (i + 1)); [pool[i], pool[j]] = [pool[j], pool[i]]; }
  return pool.slice(0, k);
}

/** k distinct random picks from arr other than arr[self]; rejection sampling, O(k) for k << n. */
function pickOthers(rng, arr, k, self) {
  const chosen = new Set();
  while (chosen.size < k) { const i = Math.floor(rng() * arr.length); if (i !== self) chosen.add(i); }
  return [...chosen].map((i) => arr[i]);
}

// ------------------------------------------------------------- network ----
class Network {
  constructor({ rng, lossRate = 0 }) {
    if (!(lossRate >= 0 && lossRate < 1)) throw new RangeError('lossRate must be in [0, 1)');
    this.rng = rng; this.lossRate = lossRate;
    this.crashed = new Set(); this.isolated = new Set();
    this.sent = 0; this.dropped = 0;
  }
  up(id) { return !this.crashed.has(id); }
  /** One datagram. False if an endpoint is down or isolated, or the packet is lost. */
  send(from, to) {
    this.sent++;
    const ok = this.up(from) && this.up(to) && !this.isolated.has(from) && !this.isolated.has(to) && this.rng() >= this.lossRate;
    if (!ok) this.dropped++;
    return ok;
  }
}

// ------------------------------------------------------ anti-entropy KV ----
const newer = (a, b) => !b || a.version > b.version || (a.version === b.version && a.writer > b.writer);

class KVNode {
  constructor(id) { this.id = id; this.clock = 0; this.state = new Map(); }
  set(key, value) {
    if (typeof key !== 'string' || !key) throw new TypeError('key must be a non-empty string');
    this.clock++; // Lamport: a local event
    this.state.set(key, { value, version: this.clock, writer: this.id });
  }
  get(key) { return this.state.get(key)?.value; }
  digest() { const d = new Map(); for (const [k, e] of this.state) d.set(k, { version: e.version, writer: e.writer }); return d; }
  /** Entries we hold that are newer than the given digest. */
  deltaFor(digest) { const out = []; for (const [k, e] of this.state) if (newer(e, digest.get(k))) out.push([k, e]); return out; }
  /** Keys the digest has newer than we do (we want them). */
  wants(digest) { const out = []; for (const [k, d] of digest) if (newer(d, this.state.get(k))) out.push(k); return out; }
  merge(entries) {
    let changed = 0;
    for (const [k, e] of entries) {
      this.clock = Math.max(this.clock, e.version); // Lamport: receive rule
      if (newer(e, this.state.get(k))) { this.state.set(k, { ...e }); changed++; }
    }
    return changed;
  }
}

class GossipCluster {
  /**
   * @param {object} o
   * @param {number} o.n            node count (>= 2)
   * @param {number} [o.fanout=1]   peers contacted by each node per round
   * @param {'push'|'pull'|'push-pull'} [o.mode='push-pull']
   * @param {number} [o.lossRate=0] probability that any single message is dropped
   * @param {number} [o.seed=1]
   */
  constructor({ n, fanout = 1, mode = 'push-pull', lossRate = 0, seed = 1 }) {
    if (!Number.isInteger(n) || n < 2) throw new RangeError('n must be an integer >= 2');
    if (!Number.isInteger(fanout) || fanout < 1 || fanout >= n) throw new RangeError('fanout must be an integer in [1, n-1]');
    if (!['push', 'pull', 'push-pull'].includes(mode)) throw new RangeError('bad mode');
    this.rng = mulberry32(seed);
    this.net = new Network({ rng: this.rng, lossRate });
    this.fanout = fanout; this.mode = mode;
    this.ids = Array.from({ length: n }, (_, i) => `n${String(i).padStart(4, '0')}`);
    this.nodes = new Map(this.ids.map((id) => [id, new KVNode(id)]));
    this.rounds = 0; this.entriesSent = 0;
  }
  node(id) { return this.nodes.get(id); }

  /**
   * One exchange initiated by p towards q. Messages are built from the start-of-round
   * snapshots (sp, sq), and merges go into the live nodes. That is the synchronous-round
   * model the O(log N) results assume: a rumour moves at most one hop per exchange, per round.
   */
  _exchange(p, q, sp, sq) {
    const { net } = this;
    if (this.mode === 'push') {                 // p -> q : p's whole state
      if (!net.send(p.id, q.id)) return;
      const d = sp.deltaFor(new Map()); this.entriesSent += d.length; q.merge(d);
      return;
    }
    if (!net.send(p.id, q.id)) return;          // SYN: p's digest (keys + versions, no values)
    const synDigest = sp.digest();
    const toP = sq.deltaFor(synDigest);
    const request = this.mode === 'push-pull' ? sq.wants(synDigest) : [];
    if (!net.send(q.id, p.id)) return;          // ACK: deltas for p + keys q wants
    this.entriesSent += toP.length; p.merge(toP);
    if (!request.length) return;
    if (!net.send(p.id, q.id)) return;          // ACK2: what q asked for
    const toQ = request.map((k) => [k, sp.state.get(k)]);
    this.entriesSent += toQ.length; q.merge(toQ);
  }

  round() {
    this.rounds++;
    const snap = new Map();
    for (const [id, nd] of this.nodes) { const c = new KVNode(id); c.state = new Map(nd.state); snap.set(id, c); }
    for (let i = 0; i < this.ids.length; i++) {
      const id = this.ids[i];
      if (!this.net.up(id)) continue;
      for (const peer of pickOthers(this.rng, this.ids, this.fanout, i)) {
        this._exchange(this.nodes.get(id), this.nodes.get(peer), snap.get(id), snap.get(peer));
      }
    }
  }

  /** Every live node holds exactly the same (version, writer) for every key. */
  converged() {
    const live = this.ids.filter((id) => this.net.up(id)).map((id) => this.nodes.get(id));
    const ref = live[0].state;
    return live.every((nd) => nd.state.size === ref.size && [...ref].every(([k, e]) => { const o = nd.state.get(k); return o && o.version === e.version && o.writer === e.writer; }));
  }

  runUntilConverged(maxRounds = 1000) {
    const start = this.rounds;
    while (!this.converged()) { if (this.rounds - start >= maxRounds) return -1; this.round(); }
    return this.rounds - start;
  }
}

/** Rounds for a single update written at one node to reach all N nodes, over several trials. */
function measureConvergence({ n, fanout = 1, mode = 'push-pull', lossRate = 0, trials = 20, seed = 1 }) {
  const rounds = [];
  for (let t = 0; t < trials; t++) {
    const c = new GossipCluster({ n, fanout, mode, lossRate, seed: seed * 1000 + t });
    c.node(c.ids[0]).set('rumor', t);
    rounds.push(c.runUntilConverged());
  }
  rounds.sort((a, b) => a - b);
  return { n, mean: rounds.reduce((s, x) => s + x, 0) / trials, p50: rounds[Math.floor(trials / 2)], max: rounds[trials - 1] };
}

// ------------------------------------------------------ SWIM detector ----
const ALIVE = 'alive'; const SUSPECT = 'suspect'; const DEAD = 'dead';

class SwimNode {
  constructor(id, ids) {
    this.id = id; this.incarnation = 0;
    this.members = new Map(ids.map((m) => [m, { status: ALIVE, inc: 0, since: 0 }]));
    this.updates = new Map(); // id -> {id, status, inc, tx}
    this.probeOrder = []; this.refutations = 0;
  }
  view(id) { return this.members.get(id); }
}

class SwimCluster {
  /**
   * @param {object} o
   * @param {number} o.n
   * @param {number} [o.indirectK=3]       helpers asked to ping-req after a failed direct ping
   * @param {number} [o.suspicionRounds]   periods a node stays SUSPECT before DEAD (0 = no suspicion)
   * @param {number} [o.retransmitMult=4]  retransmit each update retransmitMult*ceil(log10(n+1)) times (memberlist's rule)
   * @param {number} [o.maxPiggyback=6]    updates carried per message
   */
  constructor({ n, seed = 1, lossRate = 0, indirectK = 3, suspicionRounds, retransmitMult = 4, maxPiggyback = 6 }) {
    if (!Number.isInteger(n) || n < 3) throw new RangeError('SWIM needs n >= 3');
    if (!Number.isInteger(indirectK) || indirectK < 0) throw new RangeError('indirectK must be an integer >= 0');
    this.rng = mulberry32(seed);
    this.net = new Network({ rng: this.rng, lossRate });
    this.ids = Array.from({ length: n }, (_, i) => `m${String(i).padStart(3, '0')}`);
    this.nodes = new Map(this.ids.map((id) => [id, new SwimNode(id, this.ids)]));
    this.k = indirectK; this.maxPiggyback = maxPiggyback;
    this.suspicionRounds = suspicionRounds === undefined ? 2 * Math.ceil(Math.log2(n + 1)) : suspicionRounds;
    this.txLimit = retransmitMult * Math.ceil(Math.log10(n + 1));
    this.round = 0;
    this.log = []; // {round, observer, subject, status, inc}
  }

  crash(id) { this.net.crashed.add(id); }

  _enqueue(node, id, status, inc) { node.updates.set(id, { id, status, inc, tx: 0 }); }

  /** A message from a to b that also carries a's freshest membership updates. */
  _send(a, b) {
    if (!this.net.send(a.id, b.id)) return false;
    const batch = [...a.updates.values()].sort((x, y) => x.tx - y.tx).slice(0, this.maxPiggyback);
    for (const u of batch) { if (++u.tx >= this.txLimit) a.updates.delete(u.id); }
    for (const u of batch) this._apply(b, u);
    return true;
  }

  /** SWIM precedence rules; returns true if the update changed our view. */
  _apply(node, { id, status, inc }) {
    if (id === node.id) {
      // Someone thinks we are suspect/dead: refute with a higher incarnation.
      if (status !== ALIVE && inc >= node.incarnation) {
        node.incarnation = inc + 1; node.refutations++;
        node.members.set(id, { status: ALIVE, inc: node.incarnation, since: this.round });
        this._enqueue(node, id, ALIVE, node.incarnation);
      }
      return false;
    }
    const cur = node.members.get(id);
    const accept =
      status === ALIVE ? inc > cur.inc :
      status === SUSPECT ? (cur.status === ALIVE && inc >= cur.inc) || (cur.status === SUSPECT && inc > cur.inc) :
      /* DEAD */ cur.status !== DEAD && inc >= cur.inc;
    if (!accept) return false;
    node.members.set(id, { status, inc, since: this.round });
    this._enqueue(node, id, status, inc);
    if (status !== ALIVE || cur.status !== ALIVE) this.log.push({ round: this.round, observer: node.id, subject: id, status, inc });
    return true;
  }

  _nextTarget(node) {
    // Round-robin over a shuffled member list: every member is probed within 2N-1 periods
    // (worst case), versus an unbounded wait with purely random target choice.
    for (let tries = 0; tries < 2; tries++) {
      while (node.probeOrder.length) {
        const t = node.probeOrder.pop();
        if (node.view(t) && node.view(t).status !== DEAD) return t;
      }
      node.probeOrder = sample(this.rng, this.ids, this.ids.length, new Set([node.id]));
    }
    return null;
  }

  _probe(node) {
    const tId = this._nextTarget(node);
    if (!tId) return;
    const t = this.nodes.get(tId);
    if (this._send(node, t) && this._send(t, node)) return;                     // ping / ack
    const candidates = this.ids.filter((h) => h !== node.id && h !== tId && node.view(h).status !== DEAD);
    for (const hId of sample(this.rng, candidates, this.k)) {                  // ping-req via k helpers
      const h = this.nodes.get(hId);
      if (this._send(node, h) && this._send(h, t) && this._send(t, h) && this._send(h, node)) return;
    }
    const v = node.view(tId);
    if (v.status === ALIVE) {
      const status = this.suspicionRounds === 0 ? DEAD : SUSPECT;
      this._apply(node, { id: tId, status, inc: v.inc });
    }
  }

  step() {
    this.round++;
    const live = this.ids.filter((id) => this.net.up(id));
    for (const id of sample(this.rng, live, live.length)) this._probe(this.nodes.get(id));
    // Suspicion timeouts: each node independently confirms suspects that never refuted.
    for (const id of live) {
      const node = this.nodes.get(id);
      for (const [m, v] of node.members) {
        if (v.status === SUSPECT && this.round - v.since >= this.suspicionRounds) this._apply(node, { id: m, status: DEAD, inc: v.inc });
      }
    }
  }

  /** How many live nodes currently see `id` with the given status. */
  countViews(id, status) { return this.ids.filter((o) => o !== id && this.net.up(o) && this.nodes.get(o).view(id).status === status).length; }

  /** DEAD declarations (observer, subject) about members that never crashed. */
  falsePositives() {
    const bad = this.log.filter((e) => e.status === DEAD && this.net.up(e.subject));
    return { declarations: bad.length, subjects: new Set(bad.map((e) => e.subject)).size };
  }
}

test.js 
'use strict';
const assert = require('node:assert');
const { mulberry32, KVNode, GossipCluster, measureConvergence, SwimCluster, ALIVE, SUSPECT, DEAD } = require('./gossip');

let failed = 0; let count = 0;
function test(name, fn) {
  count++;
  try { fn(); console.log(`✓ ${name}`); } catch (err) { failed++; console.log(`✗ ${name}\n  ${err.stack}`); }
}

test('seeded PRNG is deterministic and in [0, 1)', () => {
  const a = mulberry32(42); const b = mulberry32(42); const c = mulberry32(43);
  const xs = Array.from({ length: 1000 }, a);
  assert.deepStrictEqual(xs, Array.from({ length: 1000 }, b));
  assert.notStrictEqual(xs[0], c());
  assert.ok(xs.every((x) => x >= 0 && x < 1));
  const mean = xs.reduce((s, x) => s + x, 0) / xs.length;
  assert.ok(Math.abs(mean - 0.5) < 0.05);
});

test('LWW merge: higher version wins, ties broken by writer id, merge is idempotent', () => {
  const n = new KVNode('z');
  n.merge([['k', { value: 'a', version: 3, writer: 'a' }]]);
  n.merge([['k', { value: 'old', version: 2, writer: 'zz' }]]);
  assert.strictEqual(n.get('k'), 'a');
  n.merge([['k', { value: 'b', version: 3, writer: 'b' }]]);
  assert.strictEqual(n.get('k'), 'b');
  assert.strictEqual(n.merge([['k', { value: 'b', version: 3, writer: 'b' }]]), 0); // idempotent
});

test('merge is order-independent (commutative/associative) over random updates', () => {
  const rnd = mulberry32(9);
  // (version, writer) identifies one write, so the same pair always carries the same value.
  const updates = Array.from({ length: 200 }, () => {
    const key = `k${Math.floor(rnd() * 10)}`; const version = Math.floor(rnd() * 20); const writer = `w${Math.floor(rnd() * 3)}`;
    return [key, { value: `${key}@${version}/${writer}`, version, writer }];
  });
  const ref = new KVNode('r'); ref.merge(updates);
  for (let t = 0; t < 5; t++) {
    const shuffled = [...updates].sort(() => rnd() - 0.5);
    const x = new KVNode('x');
    for (let i = 0; i < shuffled.length; i += 7) x.merge(shuffled.slice(i, i + 7));
    assert.deepStrictEqual([...x.state].sort(), [...ref.state].sort());
  }
});

test('Lamport clock: a write after seeing a newer remote version supersedes it', () => {
  const a = new KVNode('a');
  a.merge([['cfg', { value: 'remote', version: 41, writer: 'b' }]]);
  a.set('cfg', 'local');
  assert.strictEqual(a.state.get('cfg').version, 42);
  const b = new KVNode('b'); b.merge([['cfg', { value: 'remote', version: 41, writer: 'b' }]]);
  b.merge([...a.state]);
  assert.strictEqual(b.get('cfg'), 'local');
});

test('push-pull exchange moves data both ways; in-sync peers exchange digests only', () => {
  const c = new GossipCluster({ n: 2, seed: 1 });
  const [a, b] = c.ids.map((id) => c.node(id));
  a.set('x', 1); b.set('y', 2);
  c._exchange(a, b, a, b);
  assert.strictEqual(c.net.sent, 3);          // SYN, ACK, ACK2
  assert.deepStrictEqual([a.get('y'), b.get('x')], [2, 1]);
  const before = c.entriesSent;
  c._exchange(a, b, a, b);
  assert.strictEqual(c.entriesSent, before);   // nothing to ship
  assert.strictEqual(c.net.sent, 5);           // SYN + ACK, no ACK2 needed
});

test('concurrent writes to one key converge to the same winner everywhere', () => {
  const c = new GossipCluster({ n: 50, seed: 3 });
  c.ids.forEach((id, i) => { c.node(id).set('leader', id); if (i % 5 === 0) c.node(id).set(`own-${id}`, i); });
  assert.ok(c.runUntilConverged(100) > 0);
  const winners = new Set(c.ids.map((id) => c.node(id).get('leader')));
  assert.strictEqual(winners.size, 1);
  assert.strictEqual([...winners][0], c.ids[c.ids.length - 1]); // all version 1: highest writer id wins
  assert.strictEqual(c.node(c.ids[7]).state.size, 11);
});

test('rounds to convergence grow like log N (push-pull, fanout 1)', () => {
  const r64 = measureConvergence({ n: 64, trials: 20 });
  const r1024 = measureConvergence({ n: 1024, trials: 20 });
  // Theory: log3 N + O(log log N) for push-pull. 16x the nodes adds only a few rounds.
  assert.ok(r1024.mean <= Math.log2(1024) + 1, `N=1024 took ${r1024.mean}`);
  assert.ok(r1024.mean - r64.mean < 5, `${r64.mean} -> ${r1024.mean}`);
  assert.ok(r1024.mean > Math.log(1024) / Math.log(3), 'sanity: no faster than log3 N in practice');
});

test('push-pull beats push-only and pull-only; higher fanout needs fewer rounds', () => {
  const pp = measureConvergence({ n: 256, mode: 'push-pull' }).mean;
  const push = measureConvergence({ n: 256, mode: 'push' }).mean;
  const pull = measureConvergence({ n: 256, mode: 'pull' }).mean;
  assert.ok(pp < pull && pull < push, `pp ${pp}, pull ${pull}, push ${push}`);
  // push-only needs about log2 N + ln N rounds (Pittel 1987)
  assert.ok(Math.abs(push - (Math.log2(256) + Math.log(256))) < 3, `push ${push}`);
  const f1 = measureConvergence({ n: 256, fanout: 1 }).mean;
  const f3 = measureConvergence({ n: 256, fanout: 3 }).mean;
  assert.ok(f3 < f1);
});

test('message loss slows convergence but does not prevent it', () => {
  const clean = measureConvergence({ n: 128, lossRate: 0 }).mean;
  const lossy = measureConvergence({ n: 128, lossRate: 0.3 }).mean;
  assert.ok(lossy > clean);
  const c = new GossipCluster({ n: 128, lossRate: 0.3, seed: 5 });
  c.node(c.ids[0]).set('k', 'v');
  assert.ok(c.runUntilConverged(200) > 0);
  assert.ok(c.net.dropped > 0);
});

test('crashed nodes do not block convergence of the live ones; runs are reproducible', () => {
  const run = () => {
    const c = new GossipCluster({ n: 40, seed: 11, lossRate: 0.1 });
    for (let i = 0; i < 10; i++) c.net.crashed.add(c.ids[30 + i]);
    c.node(c.ids[0]).set('k', 1);
    return [c.runUntilConverged(), c.net.sent, c.node(c.ids[35]).get('k')];
  };
  const a = run();
  assert.ok(a[0] > 0);
  assert.strictEqual(a[2], undefined);
  assert.deepStrictEqual(run(), a);
});

test('SWIM: healthy lossless cluster never suspects anyone', () => {
  const s = new SwimCluster({ n: 20, seed: 1 });
  for (let r = 0; r < 60; r++) s.step();
  assert.strictEqual(s.log.length, 0);
  assert.ok(s.ids.every((id) => s.countViews(id, ALIVE) === 19));
});

test('SWIM: a crashed member is suspected quickly and declared dead by everyone', () => {
  const s = new SwimCluster({ n: 32, seed: 2, lossRate: 0.05 });
  s.crash('m007');
  let firstSuspect = -1; let allDead = -1;
  for (let r = 0; r < 60 && allDead < 0; r++) {
    s.step();
    if (firstSuspect < 0 && s.countViews('m007', SUSPECT) + s.countViews('m007', DEAD) > 0) firstSuspect = s.round;
    if (s.countViews('m007', DEAD) === 31) allDead = s.round;
  }
  assert.ok(firstSuspect > 0 && firstSuspect <= 4, `first suspicion at ${firstSuspect}`); // expected ~e/(e-1) periods
  assert.ok(allDead >= s.suspicionRounds && allDead <= s.suspicionRounds + 8, `all dead at ${allDead}`);
});

test('SWIM: a briefly unreachable member refutes suspicion by bumping its incarnation', () => {
  const s = new SwimCluster({ n: 16, seed: 4 });
  s.net.isolated.add('m003');
  s.step(); s.step();
  assert.ok(s.countViews('m003', SUSPECT) > 0);
  s.net.isolated.delete('m003');
  for (let r = 0; r < 20; r++) s.step();
  const me = s.nodes.get('m003');
  assert.ok(me.incarnation >= 1 && me.refutations >= 1);
  assert.strictEqual(s.countViews('m003', ALIVE), 15);
  assert.ok(s.ids.filter((id) => id !== 'm003').every((id) => s.nodes.get(id).view('m003').inc === me.incarnation));
  assert.strictEqual(s.falsePositives().declarations, 0);
});

test('SWIM precedence: suspect(i) beats alive(i); alive needs a higher incarnation; dead is sticky', () => {
  const s = new SwimCluster({ n: 3, seed: 1 });
  const a = s.nodes.get('m000');
  assert.ok(s._apply(a, { id: 'm001', status: SUSPECT, inc: 0 }));
  assert.ok(!s._apply(a, { id: 'm001', status: ALIVE, inc: 0 }));
  assert.ok(s._apply(a, { id: 'm001', status: ALIVE, inc: 1 }));
  assert.ok(!s._apply(a, { id: 'm001', status: SUSPECT, inc: 0 }));   // stale suspicion
  assert.ok(s._apply(a, { id: 'm001', status: DEAD, inc: 1 }));
  assert.ok(!s._apply(a, { id: 'm001', status: SUSPECT, inc: 5 }));
  assert.ok(!s._apply(a, { id: 'm001', status: DEAD, inc: 1 }));      // idempotent
  s._apply(a, { id: 'm000', status: SUSPECT, inc: 0 });              // about ourselves
  assert.strictEqual(a.incarnation, 1);
  assert.strictEqual(a.updates.get('m000').status, ALIVE);
});

test('SWIM: indirect probes + suspicion cut false positives under packet loss', () => {
  const falseDeaths = (indirectK, suspicionRounds) => {
    let total = 0;
    for (const seed of [1, 2, 3]) {
      const s = new SwimCluster({ n: 32, seed, lossRate: 0.05, indirectK, suspicionRounds });
      for (let r = 0; r < 60; r++) s.step();
      total += s.falsePositives().declarations;
    }
    return total;
  };
  const naive = falseDeaths(0, 0);      // ping once, declare dead on the first miss
  const indirect = falseDeaths(3, 0);
  const full = falseDeaths(3, undefined);
  assert.ok(naive > indirect && indirect > full, `${naive} > ${indirect} > ${full}`);
  assert.strictEqual(full, 0);
});
