Sliding Window Rate Limiter: Log, Counter, Token Bucket

Three per-key limiters with one result shape, so you can swap them and compare:

const r = limiter.consume('api-key:123', cost = 1);
// { allowed, limit, remaining, retryAfterMs, resetMs }
res.set(toHeaders(r)); // RateLimit-Limit / -Remaining / -Reset, Retry-After on 429

The problem and where it shows up

A rate limiter caps how much work one principal can cause per unit of time. It protects

shared capacity, enforces pricing tiers, and slows abuse such as credential stuffing and scraping.

You'll find it in API gateways (Kong, AWS API Gateway usage plans), edge proxies (Envoy

local_ratelimit and the global ratelimit service, NGINX limit_req), CDNs (Cloudflare Rate

Limiting), and public APIs (GitHub's x-ratelimit-* headers, Stripe's per-account limits).

The naive fixed window ("reset the counter every minute") admits up to 2x the limit in a short

burst that straddles a boundary. demo.js section 1 shows 20 requests admitted in 2 s against a

10/min limit. All three algorithms here avoid that.

The three algorithms

1. Sliding log (SlidingLogLimiter): exact

Store one timestamp per admitted unit and count the ones in (now - W, now].

  • Invariant: in every interval of length W, admitted ≤ limit. A randomized test checks all windows.
  • Retry-After is exact. For a request of cost c with n entries logged, the k = n + c - limit
    • oldest entries must leave, and the k-th oldest leaves at log[k-1] + W.
  • Cost: O(limit) memory per key, which gets expensive for "10 000 / hour" limits across millions of keys.

2. Sliding-window counter (SlidingWindowCounter): O(1) approximation

Keep only the counts for the current and previous fixed windows:

estimate = prev * (1 - elapsed / W) + curr        admit if estimate + cost <= limit

This assumes the previous window's hits were spread uniformly. Retry-After is solved in closed form

for two cases. (A) Room opens later in this window as prev decays:

f >= 1 - (L - curr - cost) / prev. (B) curr alone is too full, so wait into the next window, where prev := curr: g >= 1 - (L - cost) / curr. The result is rounded up to whole ms and nudged

forward if floating-point error left it a hair short. A randomized test checks that it is never early and never late.

  • Error: when traffic in the previous window was not uniform (bunched at its end), the counter
    • under-estimates and over-admits. In the demo's Poisson workload it admits about 0.6% more overall, and its worst true 60 s window reaches 113 against a limit of 100. Cloudflare has reported very low error on real traffic. The trade is exactness for 3 numbers per key.

3. Token bucket (TokenBucketLimiter): burst plus sustained rate

Tokens refill continuously at refillRate / refillIntervalMs, up to capacity. A request spends cost tokens.

  • Invariant: over any interval T, admitted ≤ capacity + rate * T (randomized test).
  • Tokens are stored as integer units (tokens * refillIntervalMs) and each ms adds refillRate
    • units, so integer clocks give exact arithmetic. A test runs 30 000 ms at 0.3 tok/ms and expects exactly 9000.
  • Retry-After = ceil(missingUnits / refillRate) ms. A clock that moves backwards adds nothing.
  • Semantics differ from a window: a bucket allows an immediate burst of capacity, then smooths to the rate.

Shared behaviour

  • Per-key state lives in a Map. sweep() drops keys whose state carries no information (empty
    • log, both counters zero, full bucket), so memory is bounded by the active keys.
  • Denied requests don't consume quota. Some systems do count them, to penalize clients that ignore 429s.
  • cost > limit can never succeed and returns retryAfterMs: Infinity (no Retry-After header).
  • Injectable clock (now): tests and the demo never sleep.
  • Validation: non-positive or non-integer limits, costs and windows, and empty keys, all throw.

Failure modes and trade-offs

  • Distributed enforcement: these are single-process. With N gateway replicas, each enforcing
    • L gives an effective limit of N*L. Options: a central store (Redis + Lua script for atomic check-and-increment), sticky routing by key, or splitting the budget per node (L/N, which is unfair when load is uneven).
  • Race conditions in a central store: a non-atomic GET-then-SET lets concurrent requests all pass.
    • Use INCR + EXPIRE or a Lua script. For the log, use a sorted set with ZREMRANGEBYSCORE + ZCARD + ZADD in MULTI/Lua.
  • Clock skew across nodes shifts windows. Use the store's clock (TIME in Redis Lua), not each client's.
  • Key choice: per-IP punishes NAT and CGNAT users. Per-user needs authentication before limiting.
    • Hot keys in a shared store become a hotspot.
  • Fail open vs fail closed when the limiter store is down. Most APIs fail open, so an outage of
    • the limiter doesn't become an outage of the API. Login endpoints often fail closed.
  • Memory: an attacker rotating keys creates unbounded state. Sweep idle keys, cap the tracked-key
    • count, or use a probabilistic structure (a Count-Min sketch) for coarse limits.

How production systems do it

  • NGINX limit_req uses a leaky bucket per key in a shared-memory zone (rate=10r/s,
    • burst=, nodelay). Requests within burst are queued and delayed to the rate unless nodelay is set. Anything beyond the burst is rejected (503 by default, configurable via limit_req_status).
  • Envoy does token-bucket local rate limiting per listener or route (local_ratelimit). Global limits go
    • through an external gRPC Rate Limit Service (Lyft's ratelimit, backed by Redis) that uses fixed windows keyed by descriptors.
  • Cloudflare described the sliding-window counter in its 2017 blog post on rate limiting,
    • choosing it for O(1) memory per key at edge scale.
  • Stripe runs several limiters in Redis, including a request rate limiter (token bucket) and a
    • concurrent-requests limiter, and adds load shedders that prioritize critical traffic.
  • Redis patterns: INCR+EXPIRE (fixed window), sorted sets (sliding log), and GCRA (redis-cell
    • module's CL.THROTTLE), which is a token bucket stored as a single "theoretical arrival time".
  • Headers: Retry-After is defined in RFC 9110 (delay-seconds or HTTP-date). RateLimit-* come
    • from the IETF httpapi RateLimit header fields draft. GitHub uses its own x-ratelimit-* names.

    2. makes the same decisions as TokenBucketLimiter on random traffic.
  2. Redis-backed log: port SlidingLogLimiter to a Lua script over a sorted set. Explain why the
    3. ZREMRANGEBYSCORE/ZCARD/ZADD sequence must be atomic.
  3. Multi-tier limits: enforce 10/s and 1000/h on the same key. When the second tier denies, the
    4. first must not have been charged, so check both before committing either.
  4. Ring-buffer log: replace the array plus splice with a fixed ring of limit slots, making trim O(expired).
  5. Adversarial counter: build the input pattern that maximizes the counter's over-admission (bunch the
    6. previous window's hits at its end) and derive the worst-case bound.
limiter.js 
'use strict';
/**
 * Three per-key rate limiters that share one result shape:
 *
 *   SlidingLogLimiter     exact: store every admitted timestamp, count those in (now - W, now].
 *   SlidingWindowCounter  approximate: two fixed-window counters, previous one weighted by overlap.
 *   TokenBucketLimiter    bursts up to `capacity`, sustained rate `refillRate / refillIntervalMs`.
 *
 * consume(key, cost = 1) -> {
 *   allowed, limit, remaining, retryAfterMs, resetMs
 * }
 *   retryAfterMs: 0 when allowed; otherwise the earliest wait after which the SAME request
 *                 would be allowed (Infinity if cost can never fit).
 *   resetMs:      time until the key's quota is fully restored.
 *
 * Denied requests are NOT recorded (they don't consume quota). All clocks are injectable.
 */

function checkPosInt(name, v) {
  if (!Number.isInteger(v) || v <= 0) throw new RangeError(`${name} must be a positive integer`);
}
function checkClock(now) {
  if (typeof now !== 'function') throw new TypeError('now must be a function returning ms');
}
function checkCost(cost) {
  if (!Number.isInteger(cost) || cost <= 0) throw new RangeError('cost must be a positive integer');
}
function checkKey(key) {
  if (typeof key !== 'string' || key.length === 0) throw new TypeError('key must be a non-empty string');
}

// ---------------------------------------------------------------------------
// 1. Sliding log: exact, O(limit) memory per key.
// ---------------------------------------------------------------------------
class SlidingLogLimiter {
  constructor({ limit, windowMs, now = Date.now } = {}) {
    checkPosInt('limit', limit);
    checkPosInt('windowMs', windowMs);
    checkClock(now);
    this.limit = limit;
    this.windowMs = windowMs;
    this.now = now;
    this.logs = new Map(); // key -> sorted array of admitted timestamps (one entry per unit of cost)
  }

  /** Drop timestamps that are out of the window. A hit at ts counts while now < ts + W. */
  _trim(log, t) {
    const cutoff = t - this.windowMs;
    let i = 0;
    while (i < log.length && log[i] <= cutoff) i++;
    // splice shifts the array, O(limit) worst case; a ring buffer would make this O(expired).
    if (i > 0) log.splice(0, i);
    return log;
  }

  consume(key, cost = 1) {
    checkKey(key); checkCost(cost);
    const t = this.now();
    const log = this._trim(this.logs.get(key) || [], t);
    const base = { limit: this.limit };

    if (cost > this.limit) {
      this._store(key, log);
      return { ...base, allowed: false, remaining: this.limit - log.length, retryAfterMs: Infinity, resetMs: this._reset(log, t) };
    }
    if (log.length + cost <= this.limit) {
      for (let i = 0; i < cost; i++) log.push(t);
      this._store(key, log);
      return { ...base, allowed: true, remaining: this.limit - log.length, retryAfterMs: 0, resetMs: this._reset(log, t) };
    }
    // Need k = n + cost - limit oldest entries to leave; the k-th oldest leaves at log[k-1] + W.
    const k = log.length + cost - this.limit;
    const retryAfterMs = log[k - 1] + this.windowMs - t;
    this._store(key, log);
    return { ...base, allowed: false, remaining: this.limit - log.length, retryAfterMs, resetMs: this._reset(log, t) };
  }

  _reset(log, t) { return log.length ? log[log.length - 1] + this.windowMs - t : 0; }
  _store(key, log) { if (log.length) this.logs.set(key, log); else this.logs.delete(key); }

  /** Remove idle keys (memory hygiene). Returns number removed. */
  sweep() {
    const t = this.now();
    let n = 0;
    for (const [k, log] of this.logs) if (this._trim(log, t).length === 0) { this.logs.delete(k); n++; }
    return n;
  }
  reset(key) { this.logs.delete(key); }
  get trackedKeys() { return this.logs.size; }
}

// ---------------------------------------------------------------------------
// 2. Sliding-window counter (a.k.a. "sliding window approximation", Cloudflare).
//    estimate = prevCount * (1 - elapsed/W) + currCount
//    O(1) memory per key; assumes the previous window's hits were spread uniformly.
// ---------------------------------------------------------------------------
class SlidingWindowCounter {
  constructor({ limit, windowMs, now = Date.now } = {}) {
    checkPosInt('limit', limit);
    checkPosInt('windowMs', windowMs);
    checkClock(now);
    this.limit = limit;
    this.windowMs = windowMs;
    this.now = now;
    this.state = new Map(); // key -> { start, prev, curr }
  }

  /** Roll fixed windows forward so that `start` is the window containing t. */
  _roll(s, t) {
    const W = this.windowMs;
    const start = Math.floor(t / W) * W;
    if (start === s.start) return s;
    s.prev = start - s.start === W ? s.curr : 0; // skipped >= 1 whole window -> previous is empty
    s.curr = 0;
    s.start = start;
    return s;
  }

  _estimate(s, t) {
    const weight = 1 - (t - s.start) / this.windowMs; // share of previous window still inside (t-W, t]
    return s.prev * weight + s.curr;
  }

  consume(key, cost = 1) {
    checkKey(key); checkCost(cost);
    const t = this.now();
    const W = this.windowMs, L = this.limit;
    const s = this._roll(this.state.get(key) || { start: Math.floor(t / W) * W, prev: 0, curr: 0 }, t);
    const est = this._estimate(s, t);
    const base = { limit: L };

    if (cost <= L && est + cost <= L) {
      s.curr += cost;
      this.state.set(key, s);
      return { ...base, allowed: true, remaining: Math.max(0, Math.floor(L - est - cost)), retryAfterMs: 0, resetMs: this._resetMs(s, t) };
    }
    this.state.set(key, s);
    return { ...base, allowed: false, remaining: Math.max(0, Math.floor(L - est)), retryAfterMs: this._retryAfter(s, t, cost), resetMs: this._resetMs(s, t) };
  }

  /**
   * Solve for the earliest t' >= t with estimate(t') + cost <= limit.
   * Case A (still in this window): prev*(1-f) + curr + cost <= L  =>  f >= 1 - (L-curr-cost)/prev
   * Case B (next window, prev := curr, curr := 0): curr*(1-g) + cost <= L  =>  g >= 1 - (L-cost)/curr
   */
  _retryAfter(s, t, cost) {
    const W = this.windowMs, L = this.limit;
    if (cost > L) return Infinity;
    const slack = L - s.curr - cost;
    let at;
    if (slack >= 0 && s.prev > 0) {
      at = s.start + W * (1 - slack / s.prev);
    } else {
      at = s.start + W + W * Math.max(0, 1 - (L - cost) / s.curr);
    }
    // Round up to whole ms; nudge forward if float error leaves us a hair short.
    let wait = Math.max(1, Math.ceil(at - t));
    while (!this._fitsAt(s, t + wait, cost)) wait++;
    return wait;
  }

  _fitsAt(s, t2, cost) {
    const copy = this._roll({ ...s }, t2);
    return this._estimate(copy, t2) + cost <= this.limit;
  }

  _resetMs(s, t) {
    if (s.curr > 0) return s.start + 2 * this.windowMs - t; // curr fully decays at end of next window
    if (s.prev > 0) return s.start + this.windowMs - t;
    return 0;
  }

  sweep() {
    const t = this.now();
    let n = 0;
    for (const [k, s] of this.state) {
      this._roll(s, t);
      if (s.prev === 0 && s.curr === 0) { this.state.delete(k); n++; }
    }
    return n;
  }
  reset(key) { this.state.delete(key); }
  get trackedKeys() { return this.state.size; }
}

// ---------------------------------------------------------------------------
// 3. Token bucket. Internally tokens are stored in "units" = tokens * refillIntervalMs
//    so that integer clocks give exact integer arithmetic (no 0.1 + 0.2 drift).
// ---------------------------------------------------------------------------
class TokenBucketLimiter {
  /**
   * @param {number} capacity           max burst (tokens)
   * @param {number} refillRate         tokens added per refillIntervalMs
   * @param {number} refillIntervalMs   default 1000 (i.e. refillRate is tokens/second)
   */
  constructor({ capacity, refillRate, refillIntervalMs = 1000, now = Date.now } = {}) {
    checkPosInt('capacity', capacity);
    checkPosInt('refillRate', refillRate);
    checkPosInt('refillIntervalMs', refillIntervalMs);
    checkClock(now);
    this.capacity = capacity;
    this.refillRate = refillRate;
    this.interval = refillIntervalMs;
    this.now = now;
    this.maxUnits = capacity * refillIntervalMs;
    this.buckets = new Map(); // key -> { units, last }
  }

  _refill(b, t) {
    if (t > b.last) {
      // Each ms adds refillRate units (= refillRate / interval tokens).
      b.units = Math.min(this.maxUnits, b.units + (t - b.last) * this.refillRate);
      b.last = t;
    } // a clock that goes backwards simply adds nothing
    return b;
  }

  consume(key, cost = 1) {
    checkKey(key); checkCost(cost);
    const t = this.now();
    const b = this._refill(this.buckets.get(key) || { units: this.maxUnits, last: t }, t);
    this.buckets.set(key, b);
    const need = cost * this.interval;
    const base = { limit: this.capacity };

    if (cost > this.capacity) {
      return { ...base, allowed: false, remaining: Math.floor(b.units / this.interval), retryAfterMs: Infinity, resetMs: this._resetMs(b) };
    }
    if (b.units >= need) {
      b.units -= need;
      return { ...base, allowed: true, remaining: Math.floor(b.units / this.interval), retryAfterMs: 0, resetMs: this._resetMs(b) };
    }
    const retryAfterMs = Math.ceil((need - b.units) / this.refillRate);
    return { ...base, allowed: false, remaining: Math.floor(b.units / this.interval), retryAfterMs, resetMs: this._resetMs(b) };
  }

  _resetMs(b) { return Math.ceil((this.maxUnits - b.units) / this.refillRate); }

  /** Full buckets carry no information; drop them. */
  sweep() {
    const t = this.now();
    let n = 0;
    for (const [k, b] of this.buckets) {
      if (this._refill(b, t).units >= this.maxUnits) { this.buckets.delete(k); n++; }
    }
    return n;
  }
  reset(key) { this.buckets.delete(key); }
  get trackedKeys() { return this.buckets.size; }
}

/**
 * HTTP headers for a result. Retry-After is delay-seconds (RFC 9110 §10.2.3), rounded UP so a
 * client that obeys it is never early. RateLimit-* follow the IETF httpapi ratelimit-headers draft.
 */
function toHeaders(result) {
  const h = {
    'RateLimit-Limit': String(result.limit),
    'RateLimit-Remaining': String(result.remaining),
    'RateLimit-Reset': String(Math.ceil(result.resetMs / 1000)),
  };
  if (!result.allowed && Number.isFinite(result.retryAfterMs)) {
    h['Retry-After'] = String(Math.max(1, Math.ceil(result.retryAfterMs / 1000)));
  }
  return h;
}

module.exports = { SlidingLogLimiter, SlidingWindowCounter, TokenBucketLimiter, toHeaders };

function mulberry32(seed) {
  return () => {
    seed |= 0; seed = (seed + 0x6d2b79f5) | 0;
    let x = Math.imul(seed ^ (seed >>> 15), 1 | seed);
    x = (x + Math.imul(x ^ (x >>> 7), 61 | x)) ^ x;
    return ((x ^ (x >>> 14)) >>> 0) / 4294967296;
  };
}
const rand = mulberry32(2024);
t = 0;

while (t < 60 * W) {                         // one simulated hour

// Worst true sliding-window count among the counter's admissions (two-pointer scan).
function maxInWindow(ts) {
  let best = 0;
  for (let i = 0, j = 0; j < ts.length; j++) {
    while (ts[i] <= ts[j] - W) i++;
    best = Math.max(best, j - i + 1);
  }

const assert = require('node:assert/strict');
const { SlidingLogLimiter, SlidingWindowCounter, TokenBucketLimiter, toHeaders } = require('./limiter');

let failed = 0, passed = 0;
function test(name, fn) {
  try { fn(); passed++; console.log('✓ ' + name); }
  catch (e) { failed++; console.log('✗ ' + name + '\n    ' + (e && e.stack || e)); }
}
function clock(start = 0) { const c = { t: start }; c.now = () => c.t; return c; }
function lcg(seed) { return () => (seed = (seed * 1103515245 + 12345) >>> 0) / 2 ** 32; }

// ---- sliding log ---------------------------------------------------------
test('sliding log: admits exactly `limit` in a window, denies the next', () => {
  const c = clock();
  const l = new SlidingLogLimiter({ limit: 3, windowMs: 1000, now: c.now });
  const r = [1, 2, 3, 4].map(() => l.consume('k'));
  assert.deepEqual(r.map((x) => x.allowed), [true, true, true, false]);
  assert.deepEqual(r.map((x) => x.remaining), [2, 1, 0, 0]);
});

test('sliding log: retryAfterMs is exact to the millisecond (and denials are not recorded)', () => {
  const c = clock();
  const l = new SlidingLogLimiter({ limit: 2, windowMs: 1000, now: c.now });
  c.t = 100; l.consume('k'); c.t = 300; l.consume('k');
  c.t = 500; const d = l.consume('k');
  assert.equal(d.allowed, false);
  assert.equal(d.retryAfterMs, 600);      // hit at 100 leaves at 1100
  c.t = 1099; assert.equal(l.consume('k').allowed, false);
  c.t = 1100; assert.equal(l.consume('k').allowed, true);
});

test('sliding log: multi-unit cost needs several entries to expire', () => {
  const c = clock();
  const l = new SlidingLogLimiter({ limit: 5, windowMs: 1000, now: c.now });
  for (const at of [0, 100, 200, 300, 400]) { c.t = at; l.consume('k'); }
  c.t = 500;
  const d = l.consume('k', 3);            // need 3 to leave: the one at 200 leaves at 1200
  assert.equal(d.retryAfterMs, 700);
  c.t = 1200; assert.equal(l.consume('k', 3).allowed, true);
  assert.equal(l.consume('k', 6).retryAfterMs, Infinity);
});

test('sliding log: randomized traffic never exceeds limit in ANY window', () => {
  const c = clock(); const rnd = lcg(1);
  const W = 1000, L = 7;
  const l = new SlidingLogLimiter({ limit: L, windowMs: W, now: c.now });
  const admitted = [];
  for (let i = 0; i < 20000; i++) {
    c.t += Math.floor(rnd() * 60);
    if (l.consume('k').allowed) admitted.push(c.t);
  }
  for (let i = 0, j = 0; j < admitted.length; j++) {
    while (admitted[i] <= admitted[j] - W) i++;
    assert.ok(j - i + 1 <= L, `window ending ${admitted[j]} had ${j - i + 1}`);
  }
});

// ---- sliding window counter ---------------------------------------------
test('counter: estimate weights previous window by remaining overlap', () => {
  const c = clock();
  const l = new SlidingWindowCounter({ limit: 10, windowMs: 1000, now: c.now });
  c.t = 900; for (let i = 0; i < 8; i++) l.consume('k'); // prev window: 8
  c.t = 1250;                                            // est = 8 * 0.75 = 6 -> room for 4
  const ok = [1, 2, 3, 4, 5].map(() => l.consume('k').allowed);
  assert.deepEqual(ok, [true, true, true, true, false]);
});

test('counter: retryAfterMs lands on the first allowed ms (both solve cases)', () => {
  // Case A: room appears later in the current window as prev decays.
  let c = clock();
  let l = new SlidingWindowCounter({ limit: 10, windowMs: 1000, now: c.now });
  c.t = 999; for (let i = 0; i < 10; i++) l.consume('k');
  c.t = 1000; const a = l.consume('k');
  assert.equal(a.allowed, false);
  assert.equal(a.retryAfterMs, 100);    // 10*(1-f)+1 <= 10  ->  f >= 0.1
  c.t = 1000 + a.retryAfterMs - 1; assert.equal(l.consume('k').allowed, false);
  c.t = 1000 + a.retryAfterMs; assert.equal(l.consume('k').allowed, true);

  // Case B: current window already full, must wait into the next window.
  c = clock();
  l = new SlidingWindowCounter({ limit: 4, windowMs: 1000, now: c.now });
  c.t = 0; for (let i = 0; i < 4; i++) l.consume('k');
  c.t = 10; const b = l.consume('k');
  assert.equal(b.retryAfterMs, 1240);   // next window: 4*(1-g)+1 <= 4 -> g >= .25 -> t=1250
  c.t = 1249; assert.equal(l.consume('k').allowed, false);
  c.t = 1250; assert.equal(l.consume('k').allowed, true);
});

test('counter: randomized retryAfter is always tight (never early, never late)', () => {
  const c = clock(); const rnd = lcg(99);
  const l = new SlidingWindowCounter({ limit: 13, windowMs: 700, now: c.now });
  let checked = 0;
  for (let i = 0; i < 3000; i++) {
    c.t += Math.floor(rnd() * 40);
    const r = l.consume('k');
    if (!r.allowed && Number.isFinite(r.retryAfterMs)) {
      const probe = new SlidingWindowCounter({ limit: 13, windowMs: 700, now: () => c.t + r.retryAfterMs - 1 });
      probe.state.set('k', { ...l.state.get('k') });
      if (r.retryAfterMs > 1) assert.equal(probe.consume('k').allowed, false, 'retryAfter was late');
      probe.now = () => c.t + r.retryAfterMs;
      probe.state.set('k', { ...l.state.get('k') });
      assert.equal(probe.consume('k').allowed, true, 'retryAfter was early');
      checked++;
    }
  }
  assert.ok(checked > 100);
});

test('token bucket: burst to capacity then sustained refill rate', () => {
  const c = clock();
  const b = new TokenBucketLimiter({ capacity: 5, refillRate: 1, refillIntervalMs: 100, now: c.now });
  assert.equal([...Array(7)].filter(() => b.consume('k').allowed).length, 5);

test('token bucket: integer arithmetic has no floating drift', () => {
  const c = clock();
  const b = new TokenBucketLimiter({ capacity: 2, refillRate: 3, refillIntervalMs: 10, now: c.now }); // 0.3 tok/ms
  // capacity 2 so the cap never discards tokens (residual < 1 token + 0.3 per step)
  b.consume('k', 2);
  let admitted = 0;
  for (let i = 0; i < 30000; i++) { c.t++; if (b.consume('k').allowed) admitted++; }
  assert.equal(admitted, 9000); // 30000 ms * 0.3 tokens/ms exactly
});

test('token bucket: admitted <= capacity + rate*T for any interval (randomized)', () => {
  const c = clock(); const rnd = lcg(5);
  const cap = 4, rate = 2, I = 100; // 0.02 tokens/ms
  const b = new TokenBucketLimiter({ capacity: cap, refillRate: rate, refillIntervalMs: I, now: c.now });
  const adm = [];
  for (let i = 0; i < 4000; i++) { c.t += Math.floor(rnd() * 30); if (b.consume('k').allowed) adm.push(c.t); }
  for (let i = 0; i < adm.length; i += 7) {
    for (let j = i; j < Math.min(adm.length, i + 200); j++) {
      const T = adm[j] - adm[i];
      assert.ok(j - i + 1 <= cap + (T * rate) / I + 1e-9, `interval ${T}ms had ${j - i + 1}`);
    }
  }
  assert.equal(b.consume('k', cap + 1).retryAfterMs, Infinity);
});

const makers = {
  log: (now) => new SlidingLogLimiter({ limit: 2, windowMs: 1000, now }),

  bucket: (now) => new TokenBucketLimiter({ capacity: 2, refillRate: 2, refillIntervalMs: 1000, now }),

test('all algorithms: keys are isolated and sweep() frees idle keys', () => {
  for (const [name, make] of Object.entries(makers)) {
    const c = clock();
    const l = make(c.now);
    l.consume('a'); l.consume('a');
    assert.equal(l.consume('a').allowed, false, name);
    assert.equal(l.consume('b').allowed, true, name + ': b unaffected by a');
    assert.equal(l.trackedKeys, 2, name);
    c.t = 10_000;
    assert.equal(l.sweep(), 2, name);
    assert.equal(l.trackedKeys, 0, name);
  }
});

test('all algorithms: reject invalid config, keys and costs', () => {
  assert.throws(() => new SlidingLogLimiter({ limit: 0, windowMs: 1 }), RangeError);

  assert.throws(() => new TokenBucketLimiter({ capacity: 1, refillRate: -1 }), RangeError);
  assert.throws(() => new SlidingLogLimiter({ limit: 1, windowMs: 1, now: 5 }), TypeError);
  for (const make of Object.values(makers)) {
    const l = make(() => 0);
    assert.throws(() => l.consume(''), TypeError);
    assert.throws(() => l.consume(42), TypeError);
    assert.throws(() => l.consume('k', 0), RangeError);

  }
});
