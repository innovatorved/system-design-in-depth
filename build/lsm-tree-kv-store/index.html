LSM-Tree Key/Value Store

A log-structured merge tree built from scratch in Node: a write-ahead log, a sorted memtable, immutable

on-disk SSTables (sparse index, Bloom filter, checksummed footer), newest-to-oldest point reads, tombstones,

merge-iterator range scans, size-tiered compaction with write-amplification accounting, and crash

recovery from the WAL plus an atomically replaced manifest.

The problem

B-trees update pages in place. Every random write turns into a random read-modify-write of a page, and

on SSDs it also costs page-level write amplification. An LSM tree turns random writes into sequential

ones. It buffers writes in memory, writes them out as sorted immutable files, and merges those files in

the background. The price is paid on reads (you may have to check several files) and in compaction I/O.

Where it shows up: Google Bigtable (which coined the terms memtable and SSTable), LevelDB, RocksDB (used under

MyRocks, TiKV, CockroachDB's former engine, Kafka Streams state stores), CockroachDB's Pebble, Apache

Cassandra, ScyllaDB, HBase, InfluxDB's TSM engine and many time-series stores.

Design

put/delete ──► WAL append (CRC-framed) ──► Memtable (sorted) ──full──► flush ──► 000123.sst (newest)
                                                                               │
get:  memtable ─► sst[0] ─► sst[1] ─► ... first hit wins (a tombstone counts as a hit)
scan: k-way merge(memtable, sst[0..n]) — newest source wins ties, tombstones suppressed
compaction: pick ≥4 age-adjacent, similar-sized tables ─► merge ─► one table in their place
SSTable layout (writeSSTable / SSTable in lsm.js): 
[data block 0][data block 1] ... [bloom filter][sparse index][footer: 32 bytes]
entry  : type u8 (1=put, 0=tombstone) | klen u32 | key | vlen u32 | value
index  : one entry per block: klen u32 | first key | offset u32 | length u32 | crc32(block) u32
bloom  : m u32 | k u8 | bit array
footer : indexOff, indexLen, bloomOff, bloomLen, entryCount, crc32(bloom+index+footer[0..20)), MAGIC "LSMT", VERSION

Opening a table reads only the footer, the index and the Bloom filter. A point lookup checks the filter, binary-searches

the sparse index for the last block whose first key is <= key, reads and verifies one block, and

scans it.

WAL record: len u32 | crc32 u32 | entry. On replay, a record whose length runs past EOF or whose CRC doesn't

match marks the torn tail. Replay stops there and the file is truncated back to the last good record.

Key invariants
  1. Durability ordering. A write is appended to the WAL before it is applied to the memtable. On flush, the SSTable is
    2. written to *.tmp, fsynced and renamed. Only after that is the MANIFEST rewritten (tmp + fsync + rename), and only after that is the WAL reset. A crash at any point leaves either the old state plus the WAL, or the new state. If the crash comes between the manifest and the WAL reset, replay re-applies writes the newest table already has, which is idempotent.
  2. Age order. tables[0] is the newest. Entries carry no sequence numbers, so correctness depends on this order.
    3. That is why compaction only merges age-adjacent runs and puts the output back in the same position. Merging tables 1 and 3 around table 2 could let an old value jump ahead of a newer one.
  3. Tombstones are data until the bottom. A delete is a record that shadows older versions. Compaction may drop a
    4. tombstone only when the run includes the oldest table, because otherwise an older copy could be resurrected.
  4. Orphans are garbage. Any .sst that isn't in the manifest (left by a crash mid-flush or mid-compaction) is
    5. unreachable by construction and gets deleted on open.
Compaction strategy: size-tiered (STCS). Walking newest to oldest, tables are grouped into a bucket while

each one's size is within [0.5x, 1.5x] of the bucket's running average (Cassandra's bucket_low/bucket_high).

A bucket with at least minThreshold tables (default 4, max 32) gets merged. Each byte is rewritten about once per

tier, roughly log_4(total / memtable) times.

Complexity

OperationCost
put / deleteWAL append O(entry) + memtable insert O(log n) search + O(n) array splice (skip list: O(log n))
getO(log n) memtable + per table: k Bloom probes, O(log blocks) index search, ≤1 block read
scan of K results over T sourcesO((K + T) · T) with linear head selection (O(log T) per step with a heap)
flushO(n) sequential write
memory per table1 index key per block + ~1.25 bytes/key of Bloom filter (10 bits/key → ~0.8% FPR, k=7)
Measured in node demo.js: 6,000 writes → 23 flushes, 6 compactions, about 5.5x total write

amplification (WAL + flush + compaction bytes over user bytes). 500 lookups for absent keys did 3,000 table

probes and only ~20 block reads.

Failure modes and trade-offs

  • Read amplification: a miss probes every table. Bloom filters make that cheap for point reads, but range scans
    • can't use them and must merge every table whose key range overlaps.
  • Space amplification: STCS keeps multiple versions until a merge and needs up to 2x free space for a large
    • compaction. The oldest, biggest tier may go a long time without being compacted. The demo shows a tiny early table with no size peers.
  • Durability knob: sync: false (the default here) relies on the OS page cache, so a process crash loses nothing
    • but a power loss can. sync: true fsyncs every write. Real engines use group commit to amortise the fsync.
  • Tombstone build-up: delete-heavy workloads leave shadowing tombstones that slow scans until they reach the bottom.
  • No snapshots or concurrency control: a scan that is running while compaction deletes a file will fail. Real engines
    • pin files with reference counts or versions.
  • Compaction materialises its input in memory for simplicity. Real engines stream the merge block by block.
  • On Windows, a virus scanner can briefly lock a file being renamed. renameAtomic retries on EPERM/EBUSY.

How production systems do it

  • LevelDB / RocksDB: skip-list memtable, WAL, SSTables with data blocks, an index block, a filter block, and a
    • fixed-size footer that ends in a magic number. Internal keys carry a 56-bit sequence number and a type, which gives snapshots and lets compaction merge any files. RocksDB defaults to leveled compaction (L0 plus levels that grow about 10x each). That means lower space and read amplification but higher write amplification, often 10–30x. "Universal" compaction is its size-tiered variant. RocksDB also offers partitioned filters/indexes and a block cache.
  • Cassandra: a commit log plus memtable, then an immutable SSTable made of several component files (Data, Index,
    • Summary, Filter, Statistics). Conflicts are resolved by per-cell timestamps, so STCS can merge any similar-sized tables without the adjacency rule used here. The options are STCS (min_threshold 4, max 32), LCS, TWCS for time series, and since 5.0 the Unified Compaction Strategy. Tombstones are kept at least gc_grace_seconds (10 days by default) so repair can spread deletes before they are purged.
  • HBase: WAL, MemStore, HFiles; minor and major compactions. Bigtable: commit log, memtable, SSTables in GFS/Colossus.
  • Pebble (CockroachDB): a RocksDB-compatible Go LSM with range-deletion tombstones and L0 sublevels.

lsm.js 
'use strict';
// A small but real LSM-tree key/value store.
//   write path: WAL append -> sorted memtable -> (full) flush to an immutable SSTable
//   read path:  memtable -> SSTables newest-to-oldest (Bloom filter, sparse index, one block read)
//   background: size-tiered compaction of *age-contiguous* runs of similar-sized tables
// Keys and values are strings. A delete writes a tombstone (value === null).
const fs = require('fs');
const os = require('os');
const path = require('path');

// ---------------------------------------------------------------- checksums & hashing
const CRC_TABLE = (() => {
  const t = new Uint32Array(256);
  for (let n = 0; n < 256; n++) {
    let c = n;
    for (let k = 0; k < 8; k++) c = c & 1 ? 0xedb88320 ^ (c >>> 1) : c >>> 1;
    t[n] = c >>> 0;
  }
  return t;
})();
function crc32(buf) {
  let c = 0xffffffff;
  for (let i = 0; i < buf.length; i++) c = CRC_TABLE[(c ^ buf[i]) & 0xff] ^ (c >>> 8);
  return (c ^ 0xffffffff) >>> 0;
}
function hash32(buf, seed) { // FNV-1a with a seed, then murmur3's fmix32 finalizer for avalanche
  let h = (0x811c9dc5 ^ seed) >>> 0;
  for (let i = 0; i < buf.length; i++) { h ^= buf[i]; h = Math.imul(h, 0x01000193); }
  h ^= h >>> 16; h = Math.imul(h, 0x85ebca6b); h ^= h >>> 13; h = Math.imul(h, 0xc2b2ae35); h ^= h >>> 16;
  return h >>> 0;
}

// rename() is atomic on POSIX and (via MoveFileEx REPLACE_EXISTING) on NTFS, but on Windows a virus
// scanner or indexer briefly holding the target makes it fail with EPERM/EBUSY; retry a few times.
function renameAtomic(from, to) {
  for (let attempt = 0; ; attempt++) {
    try { return fs.renameSync(from, to); } catch (e) {
      if (attempt >= 20 || !["EPERM", "EBUSY", "EACCES"].includes(e.code)) throw e;
      Atomics.wait(new Int32Array(new SharedArrayBuffer(4)), 0, 0, 5 * (attempt + 1)); // short synchronous back-off
    }
  }
}

// ---------------------------------------------------------------- Bloom filter (one per SSTable)
class BloomFilter {
  constructor(nKeys, bitsPerKey = 10) {
    this.m = Math.max(64, Math.ceil(nKeys * bitsPerKey));
    this.k = Math.min(30, Math.max(1, Math.round(bitsPerKey * Math.LN2))); // optimal k = (m/n) ln 2
    this.bits = new Uint8Array(Math.ceil(this.m / 8));
  }
  // Kirsch-Mitzenmacher double hashing: g_i(x) = h1 + i*h2 (mod m) is as good as k independent hashes.
  _positions(key, fn) {
    const b = Buffer.from(key, 'utf8');
    const h1 = hash32(b, 0), h2 = (hash32(b, 0x9e3779b9) | 1) >>> 0; // odd, unsigned
    for (let i = 0; i < this.k; i++) fn((h1 + i * h2) % this.m);
  }
  add(key) { this._positions(key, (p) => { this.bits[p >> 3] |= 1 << (p & 7); }); }
  mayContain(key) {
    let ok = true;
    this._positions(key, (p) => { if (!(this.bits[p >> 3] & (1 << (p & 7)))) ok = false; });
    return ok;
  }
  toBuffer() {
    const hdr = Buffer.alloc(5); hdr.writeUInt32LE(this.m, 0); hdr.writeUInt8(this.k, 4);
    return Buffer.concat([hdr, Buffer.from(this.bits)]);
  }
  static fromBuffer(buf) {
    const bf = Object.create(BloomFilter.prototype);
    bf.m = buf.readUInt32LE(0); bf.k = buf.readUInt8(4);
    bf.bits = new Uint8Array(buf.subarray(5));
    return bf;
  }
}

// ---------------------------------------------------------------- entry encoding (shared by WAL and SSTable)
// [type u8: 1=put 0=tombstone][klen u32][key][vlen u32][value]
function encodeEntry(key, value) {
  const k = Buffer.from(key, 'utf8'), v = value === null ? Buffer.alloc(0) : Buffer.from(value, 'utf8');
  const out = Buffer.alloc(9 + k.length + v.length);
  out.writeUInt8(value === null ? 0 : 1, 0);
  out.writeUInt32LE(k.length, 1); k.copy(out, 5);
  out.writeUInt32LE(v.length, 5 + k.length); v.copy(out, 9 + k.length);
  return out;
}
function decodeEntry(buf, off) {
  const type = buf.readUInt8(off);
  const klen = buf.readUInt32LE(off + 1);
  const key = buf.toString('utf8', off + 5, off + 5 + klen);
  const vlen = buf.readUInt32LE(off + 5 + klen);
  const vs = off + 9 + klen;
  return { key, value: type === 1 ? buf.toString('utf8', vs, vs + vlen) : null, next: vs + vlen };
}

// ---------------------------------------------------------------- memtable: sorted parallel arrays
// Binary-search insert is O(n) per write because of splice; fine for a bounded memtable of a few
// thousand keys. Production engines use a skip list (LevelDB/RocksDB) for O(log n) concurrent inserts.
class Memtable {
  constructor() { this.keys = []; this.vals = []; this.bytes = 0; }
  _find(key) {
    let lo = 0, hi = this.keys.length;
    while (lo < hi) { const mid = (lo + hi) >>> 1; if (this.keys[mid] < key) lo = mid + 1; else hi = mid; }
    return lo; // first index with keys[i] >= key
  }
  put(key, value) {
    const i = this._find(key);
    if (this.keys[i] === key) { this.vals[i] = value; }
    else { this.keys.splice(i, 0, key); this.vals.splice(i, 0, value); }
    this.bytes += key.length + (value === null ? 0 : value.length) + 16;
  }
  lookup(key) { const i = this._find(key); return this.keys[i] === key ? { value: this.vals[i] } : undefined; }
  get size() { return this.keys.length; }
  *entries(start) {
    for (let i = start === undefined ? 0 : this._find(start); i < this.keys.length; i++) yield { key: this.keys[i], value: this.vals[i] };
  }
}

// ---------------------------------------------------------------- write-ahead log
// Record: [payloadLen u32][crc32(payload) u32][payload = encoded entry]. A torn tail (crash mid-write)
// fails the length or CRC check; replay stops there and truncates the file to the last good record.
class WAL {
  constructor(file, sync) { this.file = file; this.sync = sync; this.fd = fs.openSync(file, 'a'); }
  append(key, value) {
    const payload = encodeEntry(key, value), hdr = Buffer.alloc(8);
    hdr.writeUInt32LE(payload.length, 0); hdr.writeUInt32LE(crc32(payload), 4);
    const rec = Buffer.concat([hdr, payload]);
    fs.writeSync(this.fd, rec);
    if (this.sync) fs.fsyncSync(this.fd); // group commit would amortise this across writers
    return rec.length;
  }
  close() { if (this.fd !== null) { fs.closeSync(this.fd); this.fd = null; } }
  static replay(file, onEntry) {
    if (!fs.existsSync(file)) return { records: 0, truncatedBytes: 0 };
    const buf = fs.readFileSync(file);
    let off = 0, records = 0;
    while (off + 8 <= buf.length) {
      const len = buf.readUInt32LE(off), crc = buf.readUInt32LE(off + 4);
      if (off + 8 + len > buf.length) break;
      const payload = buf.subarray(off + 8, off + 8 + len);
      if (crc32(payload) !== crc) break;
      const e = decodeEntry(payload, 0);
      onEntry(e.key, e.value);
      off += 8 + len; records++;
    }
    const truncatedBytes = buf.length - off;
    if (truncatedBytes > 0) fs.truncateSync(file, off);
    return { records, truncatedBytes };
  }
}

// ---------------------------------------------------------------- SSTable
// File layout:  [data block 0][data block 1]...[bloom][sparse index][footer 32 B]
// index entry:  [klen u32][first key of block][offset u32][length u32][crc32(block) u32]
// footer:       indexOff, indexLen, bloomOff, bloomLen, entryCount, footerCrc, MAGIC, VERSION  (8 x u32 LE)
const MAGIC = 0x4c534d54; // "LSMT"
const VERSION = 1;
const FOOTER = 32;

function writeSSTable(file, entries, { blockSize = 4096, bitsPerKey = 10 } = {}) {
  const parts = [], index = [], bloom = new BloomFilter(entries.length, bitsPerKey);
  let off = 0, block = [], blockLen = 0, first = null, prev = null;
  const cut = () => {
    if (!block.length) return;
    const b = Buffer.concat(block);
    index.push({ key: first, off, len: b.length, crc: crc32(b) });
    parts.push(b); off += b.length; block = []; blockLen = 0; first = null;
  };
  for (const { key, value } of entries) {
    if (prev !== null && !(prev < key)) throw new Error('SSTable entries must be strictly ascending');
    prev = key;
    const enc = encodeEntry(key, value);
    if (first === null) first = key;
    block.push(enc); blockLen += enc.length; bloom.add(key);
    if (blockLen >= blockSize) cut();
  }
  cut();
  const bloomBuf = bloom.toBuffer(), bloomOff = off;
  const idxParts = index.map(({ key, off: o, len, crc }) => {
    const k = Buffer.from(key, 'utf8'), b = Buffer.alloc(16 + k.length);
    b.writeUInt32LE(k.length, 0); k.copy(b, 4);
    b.writeUInt32LE(o, 4 + k.length); b.writeUInt32LE(len, 8 + k.length); b.writeUInt32LE(crc, 12 + k.length);
    return b;
  });
  const idxBuf = Buffer.concat(idxParts), indexOff = bloomOff + bloomBuf.length;
  const footer = Buffer.alloc(FOOTER);
  [indexOff, idxBuf.length, bloomOff, bloomBuf.length, entries.length].forEach((v, i) => footer.writeUInt32LE(v, i * 4));
  footer.writeUInt32LE(crc32(Buffer.concat([bloomBuf, idxBuf, footer.subarray(0, 20)])), 20);
  footer.writeUInt32LE(MAGIC, 24); footer.writeUInt32LE(VERSION, 28);
  const all = Buffer.concat([...parts, bloomBuf, idxBuf, footer]);
  const tmp = file + '.tmp', fd = fs.openSync(tmp, 'w');
  fs.writeSync(fd, all); fs.fsyncSync(fd); fs.closeSync(fd);
  renameAtomic(tmp, file); // atomic publish: readers never see a half-written table
  return all.length;
}

class SSTable {
  constructor(file, stats) {
    this.file = file; this.name = path.basename(file); this.stats = stats;
    this.fd = fs.openSync(file, 'r');
    this.bytes = fs.fstatSync(this.fd).size;
    if (this.bytes < FOOTER) throw new Error(`${this.name}: too small to be an SSTable`);
    const f = this._read(this.bytes - FOOTER, FOOTER);
    if (f.readUInt32LE(24) !== MAGIC || f.readUInt32LE(28) !== VERSION) throw new Error(`${this.name}: bad magic/version`);
    const [indexOff, indexLen, bloomOff, bloomLen, count, fcrc] = [0, 1, 2, 3, 4, 5].map((i) => f.readUInt32LE(i * 4));
    const bloomBuf = this._read(bloomOff, bloomLen), idxBuf = this._read(indexOff, indexLen);
    if (crc32(Buffer.concat([bloomBuf, idxBuf, f.subarray(0, 20)])) !== fcrc) throw new Error(`${this.name}: footer checksum mismatch`);
    this.count = count; this.bloom = BloomFilter.fromBuffer(bloomBuf); this.index = [];
    for (let o = 0; o < idxBuf.length;) {
      const klen = idxBuf.readUInt32LE(o), key = idxBuf.toString('utf8', o + 4, o + 4 + klen);
      this.index.push({ key, off: idxBuf.readUInt32LE(o + 4 + klen), len: idxBuf.readUInt32LE(o + 8 + klen), crc: idxBuf.readUInt32LE(o + 12 + klen) });
      o += 16 + klen;
    }
  }
  _read(pos, len) { const b = Buffer.alloc(len); fs.readSync(this.fd, b, 0, len, pos); return b; }
  _block(i) {
    const { off, len, crc } = this.index[i], b = this._read(off, len);
    if (crc32(b) !== crc) throw new Error(`${this.name}: block ${i} checksum mismatch`);
    this.stats.blockReads++;
    return b;
  }
  _blockFor(key) { // last block whose first key <= key, or -1
    let lo = 0, hi = this.index.length - 1, ans = -1;
    while (lo <= hi) { const mid = (lo + hi) >>> 1; if (this.index[mid].key <= key) { ans = mid; lo = mid + 1; } else hi = mid - 1; }
    return ans;
  }
  lookup(key) { // -> {value} (value may be null = tombstone) or undefined
    if (!this.bloom.mayContain(key)) { this.stats.bloomNegatives++; return undefined; }
    const bi = this._blockFor(key);
    if (bi >= 0) {
      const b = this._block(bi);
      for (let o = 0; o < b.length;) {
        const e = decodeEntry(b, o);
        if (e.key === key) return { value: e.value };
        if (e.key > key) break;
        o = e.next;
      }
    }
    this.stats.bloomFalsePositives++;
    return undefined;
  }
  *entries(start) {
    for (let bi = start === undefined ? 0 : Math.max(0, this._blockFor(start)); bi < this.index.length; bi++) {
      const b = this._block(bi);
      for (let o = 0; o < b.length;) {
        const e = decodeEntry(b, o); o = e.next;
        if (start === undefined || e.key >= start) yield { key: e.key, value: e.value };
      }
    }
  }
  close() { if (this.fd !== null) { fs.closeSync(this.fd); this.fd = null; } }
}

// ---------------------------------------------------------------- k-way merge
// sources[0] is the NEWEST. For equal keys the newest source wins and older copies are skipped.
// Linear min-selection over k heads: O(k) per output key, fine for tens of sources (RocksDB uses a heap).
function* mergeSources(sources, { dropTombstones = true, end } = {}) {
  const its = sources.map((s) => s[Symbol.iterator]()), heads = its.map((it) => it.next());
  for (;;) {
    let min = -1;
    for (let i = 0; i < heads.length; i++) if (!heads[i].done && (min < 0 || heads[i].value.key < heads[min].value.key)) min = i;
    if (min < 0) return;
    const winner = heads[min].value;
    if (end !== undefined && winner.key >= end) return;
    for (let i = 0; i < heads.length; i++) while (!heads[i].done && heads[i].value.key === winner.key) heads[i] = its[i].next();
    if (!(dropTombstones && winner.value === null)) yield winner;
  }
}

// ---------------------------------------------------------------- the store
class LSMTree {
  constructor(opts = {}) {
    this.dir = opts.dir || fs.mkdtempSync(path.join(os.tmpdir(), 'lsm-'));
    this.memtableBytes = opts.memtableBytes ?? 64 * 1024;
    this.blockSize = opts.blockSize ?? 4096;
    this.bitsPerKey = opts.bitsPerKey ?? 10;
    this.minThreshold = opts.minThreshold ?? 4;   // Cassandra STCS default min_threshold
    this.maxThreshold = opts.maxThreshold ?? 32;  // ... and max_threshold
    this.autoCompact = opts.autoCompact ?? true;
    this.sync = !!opts.sync;
    if (!(this.memtableBytes > 0) || this.minThreshold < 2) throw new Error('invalid options');
    fs.mkdirSync(this.dir, { recursive: true });
    this.stats = { userBytes: 0, walBytes: 0, flushBytes: 0, compactionBytesRead: 0, compactionBytesWritten: 0,
      flushes: 0, compactions: 0, gets: 0, tablesProbed: 0, blockReads: 0, bloomNegatives: 0, bloomFalsePositives: 0 };
    this._recover();
  }

  _recover() {
    const mf = path.join(this.dir, 'MANIFEST');
    const manifest = fs.existsSync(mf) ? JSON.parse(fs.readFileSync(mf, 'utf8')) : { nextId: 1, tables: [] };
    this.nextId = manifest.nextId;
    this.tables = manifest.tables.map((n) => new SSTable(path.join(this.dir, n), this.stats)); // newest first
    const live = new Set(manifest.tables);
    for (const f of fs.readdirSync(this.dir)) // orphans from a crash mid-flush/compaction are unreachable: delete
      if ((f.endsWith('.sst') && !live.has(f)) || f.endsWith('.tmp')) fs.unlinkSync(path.join(this.dir, f));
    this.mem = new Memtable();
    this.recovery = WAL.replay(path.join(this.dir, 'wal.log'), (k, v) => this.mem.put(k, v));
    this.wal = new WAL(path.join(this.dir, 'wal.log'), this.sync);
  }
  _writeManifest() {
    const mf = path.join(this.dir, 'MANIFEST'), tmp = mf + '.tmp';
    const fd = fs.openSync(tmp, 'w');
    fs.writeSync(fd, JSON.stringify({ nextId: this.nextId, tables: this.tables.map((t) => t.name) }));
    fs.fsyncSync(fd); fs.closeSync(fd); renameAtomic(tmp, mf);
  }
  _check(key, value) {
    if (this.wal.fd === null) throw new Error('store is closed');
    if (typeof key !== 'string' || key.length === 0) throw new TypeError('key must be a non-empty string');
    if (value !== null && typeof value !== 'string') throw new TypeError('value must be a string');
  }
  put(key, value) { this._write(key, value); }
  delete(key) { this._write(key, null); }
  _write(key, value) {
    this._check(key, value);
    this.stats.walBytes += this.wal.append(key, value); // durability first, then the in-memory apply
    this.mem.put(key, value);
    this.stats.userBytes += Buffer.byteLength(key) + (value === null ? 0 : Buffer.byteLength(value));
    if (this.mem.bytes >= this.memtableBytes) this.flush();
  }

  get(key) {
    if (typeof key !== 'string' || key.length === 0) throw new TypeError('key must be a non-empty string');
    this.stats.gets++;
    const m = this.mem.lookup(key);
    if (m) return m.value === null ? undefined : m.value;
    for (const t of this.tables) { // newest to oldest: the first hit (value or tombstone) is authoritative
      this.stats.tablesProbed++;
      const r = t.lookup(key);
      if (r) return r.value === null ? undefined : r.value;
    }
    return undefined;
  }
  // Ordered [start, end) scan merging memtable + every table; tombstones hide older values.
  *scan(start, end) {
    yield* mergeSources([this.mem.entries(start), ...this.tables.map((t) => t.entries(start))], { end });
  }

  flush() {
    if (this.mem.size === 0) return null;
    const name = `${String(this.nextId++).padStart(6, '0')}.sst`;
    const bytes = writeSSTable(path.join(this.dir, name), [...this.mem.entries()], { blockSize: this.blockSize, bitsPerKey: this.bitsPerKey });
    this.tables.unshift(new SSTable(path.join(this.dir, name), this.stats));
    this._writeManifest();              // table is now durable and reachable ...
    this.wal.close();                   // ... so the WAL that covered it can be discarded
    fs.writeFileSync(path.join(this.dir, 'wal.log'), '');
    this.wal = new WAL(path.join(this.dir, 'wal.log'), this.sync);
    this.mem = new Memtable();
    this.stats.flushBytes += bytes; this.stats.flushes++;
    if (this.autoCompact) while (this.maybeCompact());
    return name;
  }

  // Size-tiered: find a run of >= minThreshold ADJACENT tables (by age) whose sizes are within
  // [0.5x, 1.5x] of the run's average (Cassandra's bucket_low/bucket_high). Adjacency matters because
  // entries carry no sequence numbers: merging non-adjacent tables would let an old value jump ahead
  // of a newer one in an unmerged table in between.
  pickCompaction() {
    const t = this.tables;
    for (let i = 0; i < t.length;) {
      let j = i + 1, sum = t[i].bytes;
      while (j < t.length && j - i < this.maxThreshold) {
        const avg = sum / (j - i);
        if (t[j].bytes < avg * 0.5 || t[j].bytes > avg * 1.5) break;
        sum += t[j].bytes; j++;
      }
      if (j - i >= this.minThreshold) return [i, j];
      i = j;
    }
    return null;
  }
  maybeCompact() { const r = this.pickCompaction(); if (!r) return false; this.compactRange(r[0], r[1]); return true; }
  compactAll() { this.flush(); if (this.tables.length > 1) this.compactRange(0, this.tables.length); }

  compactRange(i, j) {
    const inputs = this.tables.slice(i, j);
    const bottom = j === this.tables.length; // nothing older exists, so tombstones have nothing left to shadow
    const merged = [...mergeSources(inputs.map((t) => t.entries()), { dropTombstones: bottom })];
    const out = [];
    if (merged.length) {
      const name = `${String(this.nextId++).padStart(6, '0')}.sst`;
      this.stats.compactionBytesWritten += writeSSTable(path.join(this.dir, name), merged, { blockSize: this.blockSize, bitsPerKey: this.bitsPerKey });
      out.push(new SSTable(path.join(this.dir, name), this.stats));
    }
    this.tables.splice(i, j - i, ...out);   // the output takes the inputs' place in the age order
    this._writeManifest();
    for (const t of inputs) { this.stats.compactionBytesRead += t.bytes; t.close(); fs.unlinkSync(t.file); }
    this.stats.compactions++;
  }

  report() {
    const s = this.stats, disk = s.walBytes + s.flushBytes + s.compactionBytesWritten;
    return { ...s, tables: this.tables.map((t) => ({ name: t.name, bytes: t.bytes, entries: t.count })),
      memtableKeys: this.mem.size,
      writeAmplification: s.userBytes ? disk / s.userBytes : 0,             // all bytes written / user bytes
      sstWriteAmplification: s.flushBytes ? (s.flushBytes + s.compactionBytesWritten) / s.flushBytes : 0, // compaction rewrite factor
      tablesPerGet: s.gets ? s.tablesProbed / s.gets : 0 };
  }
  close() { this.wal.close(); for (const t of this.tables) t.close(); }
  crash() { this.close(); } // process dies: memtable lost, WAL (already written to the OS) survives
  destroy() { this.close(); fs.rmSync(this.dir, { recursive: true, force: true }); }
}

module.exports = { LSMTree, SSTable, BloomFilter, Memtable, WAL, writeSSTable, mergeSources, crc32 };

test('Bloom filter: no false negatives, FPR near (1-e^(-kn/m))^k at 10 bits/key', () => {
  const n = 20000, bf = new BloomFilter(n, 10);
  for (let i = 0; i < n; i++) bf.add('member-' + i);
  for (let i = 0; i < n; i++) assert.ok(bf.mayContain('member-' + i));
  let fp = 0; const trials = 50000;
  for (let i = 0; i < trials; i++) if (bf.mayContain('absent-' + i)) fp++;
  const theory = Math.pow(1 - Math.exp(-bf.k * n / bf.m), bf.k); // k=7 -> ~0.82%
  const rate = fp / trials;
  assert.equal(bf.k, 7);
  assert.ok(rate < theory * 2 && rate > theory / 3, `fpr ${rate} vs theory ${theory}`);
  const rt = BloomFilter.fromBuffer(bf.toBuffer());
  assert.equal(rt.mayContain('member-123'), true);
});
